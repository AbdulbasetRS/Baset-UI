JavaScriptجافاسكربت

Baset UI has no JavaScript yet. This page states that plainly and records the contracts that future component scripts must meet, so that no API is documented before it exists.

لا تحتوي Baset UI على جافاسكربت بعد. تذكر هذه الصفحة ذلك بوضوح، وتسجّل القواعد التي يجب أن تلتزم بها سكربتات المكونات مستقبلًا، حتى لا يُوثَّق أي API قبل وجوده.

No API to useلا يوجد API لتستخدمه

No file in the repository defines window.BUI or any component method, option or event. Any BUI.something() call you may see in planning documents is an illustration of a convention, not an available API.

لا يعرّف أي ملف في المستودع window.BUI ولا أي دالة أو خيار أو حدث لمكوّن. أي استدعاء مثل BUI.something() قد تراه في وثائق التخطيط هو توضيح لعرف وليس API متاحًا.

JavaScript installationتثبيت جافاسكربت

Not implemented yetغير منفَّذ بعد There is no script to install. The path assets/js/baset-ui.js is planned, but that file does not exist. Static CSS usage needs no JavaScript, so you can use the token stylesheet today without it. When scripts exist, they will be loadable per component, so using one component does not require loading all of them.

Not implemented yetغير منفَّذ بعد لا يوجد سكربت لتثبيته. المسار assets/js/baset-ui.js مخطَّط له، لكن الملف غير موجود. استخدام CSS الساكن لا يحتاج جافاسكربت، فيمكنك استخدام ملف الـ tokens اليوم بدونها. وحين توجد السكربتات ستكون قابلة للتحميل لكل مكوّن على حدة، فلا يتطلب استخدام مكوّن واحد تحميلها كلها.

Initializationالتهيئة

Plannedمخطَّط Rules every interactive component must follow:

Plannedمخطَّط قواعد يجب أن يلتزم بها كل مكوّن تفاعلي:

  • Initialization is predictable and scoped to one element.التهيئة متوقعة ومحصورة في عنصر واحد.
  • Initializing the same element twice is safe and never duplicates event listeners.تهيئة العنصر نفسه مرتين آمنة ولا تكرر مستمعات الأحداث.
  • Baset UI never assumes it owns the whole page or the lifetime of an element.لا تفترض Baset UI أنها تملك الصفحة كلها أو عمر العنصر.
  • Inside a framework, initialize after the framework has rendered the element and destroy before it removes it, so Baset UI does not compete with the framework's rendering.داخل الأطر: تُهيَّأ بعد أن يعرض الإطار العنصر وتُتلَف قبل أن يزيله، حتى لا تنافس Baset UI عملية العرض في الإطار.

Component APIsواجهات المكونات

Not implemented yetغير منفَّذ بعد لا توجد واجهة لأي مكوّن. سيحصل كل مكوّن تفاعلي على واجهته الموثَّقة، وستسرد صفحته هذه الأمور بالضبط:

  • How to create an instance.كيف تنشئ نسخة.
  • Options, their types, defaults and allowed values.الخيارات وأنواعها وقيمها الافتراضية والمسموح بها.
  • Methods, with parameters and results.الدوال مع معاملاتها ونتائجها.
  • Events and their payloads.الأحداث وحمولاتها.

Examples will be added only for APIs that have been implemented and run.

لن تُضاف أمثلة إلا للواجهات التي نُفِّذت وجُرِّبت.

Eventsالأحداث

Not implemented yetغير منفَّذ بعد No events exist. When they are added they must be named consistently, documented, dispatched from a predictable target, and useful both to vanilla JavaScript and to framework integrations, without exposing internal implementation details.

Not implemented yetغير منفَّذ بعد لا توجد أحداث. عند إضافتها يجب أن تُسمّى بشكل متسق، وتُوثَّق، وتُطلَق من هدف متوقع، وتفيد جافاسكربت الخالصة وتكاملات الأطر معًا، دون كشف تفاصيل التنفيذ الداخلية.

Lifecycleدورة الحياة

Plannedمخطَّط Interactive instances are intended to support creation, updates, public actions and destruction. Destroying an instance removes its listeners, observers, timers and any DOM it generated. Components that are only HTML and CSS have no instance and no lifecycle. See Approach.

Plannedمخطَّط يُقصد أن تدعم النسخ التفاعلية الإنشاء والتحديث والإجراءات العامة والإتلاف. يزيل إتلاف النسخة مستمعاتها ومراقِباتها ومؤقتاتها وأي DOM ولّدته. المكونات التي هي HTML وCSS فقط ليس لها نسخة ولا دورة حياة. راجع المنهجية.

Configurationالإعدادات

Plannedمخطَّط Every option will have a documented type, default and allowed values; invalid values are rejected or fall back to the documented default. The way options are passed (JavaScript object, HTML attributes, or both) is not decided yet and will be fixed with the first interactive component.

Plannedمخطَّط سيكون لكل خيار نوع وقيمة افتراضية وقيم مسموح بها موثَّقة؛ والقيم غير الصالحة تُرفض أو تعود إلى القيمة الافتراضية الموثَّقة. طريقة تمرير الخيارات (كائن جافاسكربت أو خصائص HTML أو كلاهما) لم تُحسم بعد وستُحدَّد مع أول مكوّن تفاعلي.

Multiple instancesالنسخ المتعددة

Plannedمخطَّط Several instances of a component on one page must not interfere with each other. Each works only inside its own element, and destroying one leaves the others untouched.

Plannedمخطَّط يجب ألا تتداخل عدة نسخ من المكوّن في صفحة واحدة. تعمل كل نسخة داخل عنصرها فقط، وإتلاف إحداها لا يمس الأخرى.

Error handlingمعالجة الأخطاء

Plannedمخطَّط Options are validated and problems are reported clearly. Missing optional browser APIs are handled gracefully rather than breaking the page. The library never uses eval() and never builds executable code from user input.

Plannedمخطَّط تُتحقَّق من الخيارات وتُبلَّغ المشكلات بوضوح. يُتعامل مع غياب واجهات المتصفح الاختيارية بسلاسة بدل كسر الصفحة. لا تستخدم المكتبة eval() ولا تبني شيفرة قابلة للتنفيذ من مدخلات المستخدم.

About the scripts on this siteعن السكربتات في هذا الموقع

The scripts in docs-assets/js/ power this documentation site (menu, search, copy buttons, theme switch). They live in a global named BUIDocs and are documentation tooling only. They are not part of the Baset UI library, are not a model for its API, and should not be copied into applications.

السكربتات في docs-assets/js/ تشغّل موقع التوثيق هذا (القائمة والبحث وأزرار النسخ وتبديل الثيم). وهي تعيش في كائن عام اسمه BUIDocs وهي أدوات للتوثيق فقط. ليست جزءًا من مكتبة Baset UI ولا نموذجًا لواجهتها، ولا ينبغي نسخها إلى التطبيقات.

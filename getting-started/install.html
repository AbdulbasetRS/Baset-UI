Installالتثبيت

Only one installation method exists today: downloading the source files from GitHub. CDN and npm are not available yet, and this page lists what must be done before they can be announced.

توجد اليوم طريقة تثبيت واحدة فقط: تحميل ملفات المصدر من GitHub. CDN وnpm غير متاحين بعد، وتسرد هذه الصفحة ما يجب إنجازه قبل الإعلان عنهما.

Downloading source filesتحميل ملفات المصدر

This is the only supported way to get Baset UI today.

هذه هي الطريقة الوحيدة المدعومة للحصول على Baset UI اليوم.

Clone the repositoryاستنساخ المستودع

git clone https://github.com/AbdulbasetRS/Baset-UI.git
cd Baset-UI
git rev-parse HEAD   # note this commit hash

Then copy assets/css/baset-ui.css (and, if you use the layout classes, assets/css/baset-ui-layout.css) into your project.

ثم انسخ الملف assets/css/baset-ui.css (وassets/css/baset-ui-layout.css إن استخدمت أصناف التخطيط) إلى مشروعك.

Download a ZIPتحميل ملف ZIP

On the GitHub repository page choose Code then Download ZIP. You get the current state of the default branch.

في صفحة المستودع على GitHub اختر Code ثم Download ZIP. ستحصل على الحالة الحالية للفرع الافتراضي.

No versions to pin yetلا توجد إصدارات لتثبيتها بعد

The repository has no version tags or releases, so there is no stable version number. Token names and values may still change. Record the commit hash you copied from.

لا يحتوي المستودع على وسوم إصدارات (tags) ولا Releases، فلا يوجد رقم إصدار مستقر. قد تتغير أسماء الـ tokens وقيمها. سجّل رمز الـ commit الذي نسخت منه.

No license file yetلا يوجد ملف ترخيص بعد

The repository does not contain a LICENSE file, so the terms of use are not defined. The project owner needs to add one.

لا يحتوي المستودع على ملف LICENSE، لذلك شروط الاستخدام غير محددة. على مالك المشروع إضافة ملف ترخيص.

Installation examplesأمثلة التثبيت

Plain HTMLHTML عادي

Copy the file to your project, then link it before your own styles:

انسخ الملف إلى مشروعك ثم اربطه قبل أنماطك الخاصة:

<link rel="stylesheet" href="./css/baset-ui.css">
<!-- optional: layout classes (container, row, col, utilities) -->
<link rel="stylesheet" href="./css/baset-ui-layout.css">

Framework projectsمشاريع الأطر

Untestedلم يُختبر

These show the generic way of loading a plain stylesheet in each environment. They have not been verified in sample Baset UI applications, and no framework-specific package exists.

تعرض هذه الأمثلة الطريقة العامة لتحميل ملف أنماط عادي في كل بيئة. لم يُتحقق منها في تطبيقات تجريبية لـ Baset UI، ولا توجد حزمة خاصة بأي إطار.

Laravel Blade: copy the file to public/css/.

Laravel Blade: انسخ الملف إلى public/css/.

<link rel="stylesheet" href="{{ asset('css/baset-ui.css') }}">

React and Vue with a bundler that supports CSS imports: import the file once in your entry module.

React وVue مع أداة تجميع تدعم استيراد CSS: استورد الملف مرة واحدة في وحدة المدخل.

import './baset-ui.css';

Angular: add the file to the styles array of your project in angular.json.

Angular: أضف الملف إلى مصفوفة styles الخاصة بمشروعك في angular.json.

"styles": ["src/baset-ui.css", "src/styles.css"]

Before CDN and npm can be announcedقبل الإعلان عن CDN وnpm

Neither method is documented as available because neither is implemented. These are the things that must exist first. Items marked Decision needed belong to the project owner.

لم يُوثَّق أي من الطريقتين كمتاح لأن أيًّا منهما لم يُنفَّذ. هذه الأمور يجب أن تتوفر أولًا. البنود الموسومة Decision needed تعود لمالك المشروع.

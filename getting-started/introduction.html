What is Baset UI?ما هي Baset UI؟

Baset UI is a framework-agnostic UI library based on standard HTML, CSS and vanilla JavaScript. The same core styles and behavior are meant to be reused in plain HTML pages, Laravel Blade applications, React, Vue, Angular and any other environment that can render standard HTML.

Baset UI مكتبة واجهات مستقلة عن أي إطار عمل، قائمة على HTML وCSS وJavaScript القياسية. الهدف أن تُستخدم الأنماط الأساسية والسلوك نفسه في صفحات HTML العادية، وتطبيقات Laravel Blade، وReact وVue وAngular، وأي بيئة تستطيع عرض HTML قياسي.

It is not a React library, an Angular library or a Laravel-only package. When framework integrations are needed they are separate and optional.

وهي ليست مكتبة React ولا Angular ولا حزمة خاصة بـ Laravel. وعند الحاجة إلى تكاملات مع الأطر فستكون منفصلة واختيارية.

Where the project is todayأين وصل المشروع اليوم

Available now: a stylesheet of design tokens with light and dark themes (CSS Variables), an optional layout stylesheet (Grid System) and this documentation site. Everything else on this page is a goal, marked Planned or Not implemented yet.

المتاح الآن: ملف أنماط يحتوي Design Tokens مع ثيمين فاتح وداكن (متغيرات CSS)، وملف تخطيط اختياري (نظام الشبكة)، وموقع التوثيق هذا. كل ما عدا ذلك في هذه الصفحة هدف مستقبلي موسوم بـ Planned أو Not implemented yet.

Why Baset UI?لماذا Baset UI؟

  • Simple adoption. The simplest use case stays simple: link a stylesheet, write HTML.تبنٍّ بسيط. أبسط حالة استخدام تبقى بسيطة: اربط ملف أنماط واكتب HTML.
  • One core, many environments. One implementation instead of a fork per framework.نواة واحدة لبيئات كثيرة. تنفيذ واحد بدل نسخة لكل إطار.
  • Consistent design language. Shared tokens drive color, type, spacing and shape.لغة تصميم موحّدة. Tokens مشتركة تتحكم في اللون والخط والمسافة والشكل.
  • Arabic and English from the start. RTL and LTR are a foundation requirement, not an afterthought; so is this documentation.العربية والإنجليزية من البداية. دعم RTL وLTR شرط تأسيسي وليس إضافة لاحقة، وكذلك هذا التوثيق.
  • Honest support claims. A feature is documented as available only after it is implemented and verified.صدق في ادّعاءات الدعم. لا تُوثَّق ميزة كمتاحة إلا بعد تنفيذها والتحقق منها.
  • Small and modular. You should never have to load every interactive component to use one.صغيرة ومقسَّمة. لا ينبغي أن تضطر لتحميل كل المكونات التفاعلية كي تستخدم مكوّنًا واحدًا.

Framework agnostic approachنهج الاستقلال عن الأطر

Compatibility comes from using standard HTML attributes and classes. Differences such as class in HTML and className in React JSX are rendering rules of each framework, not separate implementations of Baset UI.

يأتي التوافق من استخدام خصائص HTML وأصناف CSS القياسية. اختلافات مثل class في HTML وclassName في React JSX هي قواعد عرض خاصة بكل إطار، وليست تنفيذات منفصلة من Baset UI.

Loading a plain stylesheet works the same way in every framework, which is why the middle column is expected to work. It is labeled Untested because it has not yet been verified in a sample application of each framework. Dedicated adapters are optional, are planned only if demand appears, and will depend on the core instead of copying it.

تحميل ملف أنماط عادي يعمل بالطريقة نفسها في كل إطار، ولهذا يُتوقع أن يعمل العمود الأوسط. وُسم Untested لأنه لم يُتحقق منه بعد في تطبيق تجريبي لكل إطار. المحوّلات المخصصة اختيارية، ومخططة فقط عند ظهور طلب فعلي، وستعتمد على النواة بدل نسخها.

Basic usage exampleمثال استخدام أساسي

What you can do today is load the token stylesheet and use the tokens in your own CSS. This is a complete working page (adjust the path to where you copied baset-ui.css):

ما يمكنك فعله اليوم هو تحميل ملف الـ tokens واستخدامها في CSS الخاص بك. هذه صفحة كاملة تعمل (عدّل المسار إلى المكان الذي نسخت إليه baset-ui.css):

<!doctype html>
<html lang="en" dir="ltr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Baset UI starter</title>
  <link rel="stylesheet" href="./assets/css/baset-ui.css">
  <style>
    body {
      margin: 0;
      padding: var(--bui-space-6);
      background: var(--bui-color-bg);
      color: var(--bui-color-text);
      font-family: var(--bui-font-family-base);
    }
    .notice {
      padding: var(--bui-space-4);
      border: var(--bui-border-width) solid var(--bui-color-primary);
      border-radius: var(--bui-radius-md);
      background: var(--bui-color-primary-subtle);
    }
  </style>
</head>
<body>
  <p class="notice">Styled with Baset UI design tokens.</p>
</body>
</html>

For the dark theme add the bui-dark class to <html>. For right-to-left layout set dir="rtl":

للثيم الداكن أضف الصنف bui-dark إلى <html>. وللتخطيط من اليمين إلى اليسار اضبط dir="rtl":

<html lang="ar" dir="rtl" class="bui-dark">

No component markup yetلا توجد مكونات بعد

There is no bui- component class to copy, and there is no Button component yet. When Button is implemented, its page will show its real markup.

لا يوجد أي صنف مكوّن بادئته bui- لتنسخه، ولا يوجد مكوّن Button بعد. عند تنفيذ Button ستعرض صفحته الشيفرة الفعلية.

To see the tokens in action, open the live demo in CSS Variables.

لرؤية الـ tokens عمليًا، افتح العرض الحي في متغيرات CSS.

CSS Variables

Every design value in Baset-UI is a CSS variable with the bui- prefix. This is the reference for all of them.

Introduction

Design tokens are CSS custom properties on :root. Base and Layout read them, so overriding a token changes everything that uses it, with no build step. Names follow --bui-{category}-{name}.

CategoryPatternWhere documented
Palette--bui-palette-{hue}-{step}Colors
Semantic colors--bui-color-{name}Colors
Typography--bui-font-*, --bui-line-height-*, --bui-letter-spacing-*, --bui-heading-*Typography
Spacing--bui-space-{step}Spacing
Breakpoints--bui-bp-{name}Breakpoints
Container and Grid--bui-container-*, --bui-grid-*Below

Usage

Read a token in CSS with var(), optionally with a fallback.

.my-card {
    padding: var(--bui-space-4);
    border: var(--bui-border-width) solid var(--bui-color-border);
    border-radius: var(--bui-radius-md);
    box-shadow: var(--bui-shadow-sm);
    transition: box-shadow var(--bui-transition-duration-base) var(--bui-transition-timing-standard);
}

Customization

Override tokens after baset-ui.css. On :root for the whole site, on a selector for a region, or inline for one element.

Override on one element

Rounder corners and a thicker border, only here. 
<div style="--bui-radius-md: 1.5rem; --bui-border-width: 2px; padding: var(--bui-space-3); border: var(--bui-border-width) solid var(--bui-color-border-strong); border-radius: var(--bui-radius-md)">
    Rounder corners and a thicker border, only here.
</div>

Light and Dark values

Color and shadow tokens are declared per mode. Light values apply by default (and with data-bui-mode="light"), Dark values with data-bui-mode="dark", on <html> or on any container. All other tokens are the same in both modes. To override a mode dependent token for Dark mode only, use :root[data-bui-mode="dark"] after the library file.

Responsive behavior

Tokens are constant across viewport widths. Breakpoint tokens are values for reference; CSS variables cannot be used inside media queries.

RTL and LTR

No token encodes a direction. Use logical properties (margin-inline-start, padding-inline, inset-inline-end) with the spacing tokens so layouts flip with dir.

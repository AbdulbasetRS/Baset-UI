CSS Variables

Every token, how the layers derive from each other, and how to override them on any element.

Overview

All tokens are CSS custom properties with the --bui- prefix. They are public, documented and stable within a major version. Properties that start with --bui-docs- belong to this documentation site and are not part of the library.

Layers and scopes

Token layers
LayerSelector in baset-ui.cssContentsRule
1. Raw, mode-dependent:root, [data-bui-mode="light"] and [data-bui-mode="dark"]Neutral scale, semantic colors, shadows, overlayLiteral values only. A Theme overrides these.
2. Static global:rootTypography, spacing, radius, borders, motion, z-index, breakpoints, container widthsIdentical in both modes. Inherited by every element.
3. Aliases and Component tokens:root, [data-bui-mode], [data-bui-theme]--bui-color-text, --bui-color-link, --bui-grid-gutter, --bui-heading-1-size and similarDefined with var() only. Components read this layer.

Derivation rules

  1. Layer 3 tokens are derived from Layer 1 or 2 with var(). They never contain a literal color or length.
  2. Layer 3 is declared on :root and on [data-bui-mode] and [data-bui-theme]. A custom property that refers to another is resolved where it is declared, so an inherited alias would keep the page value. Re-declaring it on the scope element makes it follow that scope.
  3. Component tokens are named --bui-{component}-{property} and default to a global token (for example --bui-grid-gutter: var(--bui-space-4)). Components read Component tokens and never read Layer 1 directly.
  4. To restyle one component, override its Component token. To restyle a whole Theme, override Layer 1 or 2 on the Theme scope.
  5. Do not use !important on tokens.
  6. Dark mode must define every Layer 1 token. A token with no Dark value is a defect.

Overriding on any element

Set a token on any element and everything inside follows. The attribute data-bui-theme marks the element as a scope so Layer 3 tokens are recalculated there (the value is only a name; no Theme Manager exists yet). Here --bui-color-primary is pointed at the success color, and the link and focus tokens follow.

Link color inside this scope: --bui-color-link. Press Tab to a focusable element to see the focus color.

Responsive behavior

Tokens are not responsive by themselves. To change a token at a breakpoint, set it inside a min-width media query on the element or scope that needs it.

@media (min-width: 768px) {
    .my-section { --bui-grid-gutter: var(--bui-space-5); }
}

Accessibility

Changing color tokens can break contrast. After overriding colors, check the pairs listed on the Colors page again. Keep --bui-focus-ring-width at 2px or more and keep the ring color at 3:1 against the surrounding background (WCAG 1.4.11, 2.4.11). Do not set durations to non-zero values in a reduced-motion context.

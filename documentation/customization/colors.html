Colors

A neutral scale, six semantic palettes and aliases, each with Light and Dark values.

Overview

Colors are tokens named --bui-color-{name}[-{form}]. There are three groups: a neutral scale, six semantic palettes (primary, secondary, success, warning, danger, info) and aliases for text, backgrounds and borders. Every color token has a Light and a Dark value. Values in the tables on this page are read live from baset-ui.css.

Neutral scale

Twelve steps from 0 to 950. In Dark mode the scale is reversed, so step 0 is always the page background and step 900 the body text. Use the aliases below rather than a fixed step where one exists.

Semantic palettes

Each semantic color has six forms. The base form has no suffix (--bui-color-primary).

Semantic color forms
FormTokenUse
base--bui-color-{name}Fills, icons, and text on the page background (3:1 or more against it)
hover--bui-color-{name}-hoverHover state of a filled element
active--bui-color-{name}-activePressed state of a filled element
subtle--bui-color-{name}-subtleTinted background (alerts, badges). Body text stays readable on it
contrast--bui-color-{name}-contrastText and icons placed on base, hover and active
border--bui-color-{name}-borderDecorative border next to a subtle background (not a control boundary)

Dark mode on any element

Dark mode is selected with data-bui-mode="dark" on <html> or on any element. The element paints its own background and text color, so a dark block can sit inside a light page and the reverse. The panels above use exactly this.

This block is dark inside a page that may be light.

Tokens resolve here

The documentation toggle in the navbar sets data-bui-mode on <html> for the whole page. A color-scheme declaration is set with each mode so native controls follow.

Responsive behavior

Color tokens do not change with the viewport width.

Accessibility

Meaning must not depend on color alone (WCAG 1.4.1): pair a semantic color with text, an icon or a pattern. Focus uses --bui-color-focus, which is checked at 3:1 against both the background and the surface. In forced-colors mode the browser replaces these values; this has not been tested yet. Color-blindness simulation was not performed.

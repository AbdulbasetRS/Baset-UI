Colors

A two layer color system: a raw palette, and semantic tokens that point to it and change with Light and Dark mode.

Introduction

Colors are CSS variables in two layers:

  • Palette (--bui-palette-{hue}-{step}): raw values that never change with the mode. Hues: blue, gray, green, red, amber, cyan, plus --bui-palette-white and --bui-palette-black.
  • Semantic colors (--bui-color-*): what Base styles and future components consume. They point to palette values and are redefined for Dark mode.

Use semantic tokens in your own CSS. Reach for a palette token only when you need a fixed color that must not change with the mode.

Usage

Reference a token with var(). The pairs shown are designed to be used together: a solid color with its -contrast text, and a -subtle background with its -on-subtle text.

Toggle Dark mode in the navbar: every sample follows the mode because it uses semantic tokens.

Light and Dark mode

Set data-bui-mode="dark" on <html> to switch the whole page. The attribute also works on any container, which makes a scoped Light or Dark region. data-bui-theme="default" may be omitted. See CSS Variables for the full list.

Customization

Override a token on an element to change it for that subtree. Tokens that depend on another (--bui-color-link follows --bui-color-primary inside each mode block), so inside a scope set both when you need both.

Scoped override

Custom primary 
<div style="--bui-color-primary: #0f766e; --bui-color-primary-contrast: #ffffff">
    <span style="display: inline-block; padding: var(--bui-space-1) var(--bui-space-3); color: var(--bui-color-primary-contrast); background: var(--bui-color-primary)">Custom primary</span>
</div>

To change a role for the whole site, override its tokens after baset-ui.css. Light and Dark need separate values.

:root {
    --bui-color-primary: #0f766e;
    --bui-color-primary-hover: #115e59;
    --bui-color-primary-active: #134e4a;
}

:root[data-bui-mode="dark"] {
    --bui-color-primary: #2dd4bf;
    --bui-color-primary-hover: #5eead4;
    --bui-color-primary-active: #99f6e4;
    --bui-color-primary-contrast: #0f141c;
}

Known limit: in Light mode the solid warning fill (amber) is only 1.89:1 against a white background. Its text is readable (dark text on amber), but a warning surface should also have a border or other cue and must not rely on its fill color alone to stand out.

Meaning must never rely on color alone: pair a role color with text or an icon.

Typography

One typography scale defined as tokens and applied by the Base styles to headings and body text.

Introduction

The Base stylesheet sets the page font, size and line height from tokens and styles h1 to h6, small, code and friends. No class is needed. Everything below is a CSS variable, so the scale can be changed in one place.

Line height

Tight. The line height controls the vertical rhythm of a paragraph, and tighter values suit large headings better than running text.

Relaxed. The line height controls the vertical rhythm of a paragraph, and looser values suit long form reading better than headings.

<div class="bui-grid bui-grid-cols-1 bui-grid-cols-md-2 bui-gap-3">
    <p style="line-height: var(--bui-line-height-tight)">Tight. The line height controls the vertical rhythm of a paragraph, and tighter values suit large headings better than running text.</p>
    <p style="line-height: var(--bui-line-height-relaxed)">Relaxed. The line height controls the vertical rhythm of a paragraph, and looser values suit long form reading better than headings.</p>
</div>

--bui-letter-spacing-wide0.025em

Do not apply letter spacing to Arabic text. Arabic letters join each other, and any added or removed spacing breaks the joins. Headings use --bui-letter-spacing-normal for this reason. Use the wide values only for short Latin labels.

Body and small text

Paragraph, small and inline code

Body text uses --bui-font-size-base and --bui-line-height-base, with bold text and a link.

Small text uses --bui-font-size-sm.

<p>Body text uses <code>--bui-font-size-base</code> and <code>--bui-line-height-base</code>, with <strong>bold</strong> text and a <a href="#">link</a>.</p>
<p><small>Small text uses <code>--bui-font-size-sm</code>.</small></p>

Customization

Change a token for the whole site, or for one element.

Scoped override

This block uses larger text and a more relaxed line height than the rest of the page. 
<div style="--bui-font-size-base: 1.125rem; --bui-line-height-base: 1.75; font-size: var(--bui-font-size-base); line-height: var(--bui-line-height-base)">
    This block uses larger text and a more relaxed line height than the rest of the page.
</div>

Responsive behavior

Typography tokens are fixed values and do not change with the viewport. To change a size at a breakpoint, assign a different token inside a min-width media query (see Breakpoints).

RTL and LTR

Text direction and alignment follow the dir attribute. The default font stack lists Noto Sans Arabic before generic fallbacks so Arabic text uses it where installed.

Same markup in dir="rtl"

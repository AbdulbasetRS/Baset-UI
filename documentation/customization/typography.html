Typography

Font families, a rem-based scale and base styles for headings, body, small and code.

Overview

Typography tokens cover font families, a size scale, weights and line heights, plus per-element tokens for headings, body text, small text and code. Base styles apply them to h1 to h6, p, small, code, kbd, samp and pre. Values in the tables are read live from baset-ui.css.

Note

No web font is loaded, because adding fonts is a dependency that needs approval. The sans family falls back to system fonts, including Arabic-capable ones (Noto Sans Arabic, Geeza Pro, Tahoma). If none is installed the browser chooses its own Arabic font.

Sizes are in rem, so they follow the browser font size setting. There is no fluid (clamp) type: sizes are identical at every breakpoint.

Heading sizes map to the scale: h1 is 4xl, h2 3xl, h3 2xl, h4 xl, h5 lg, h6 base. The documentation site overrides some heading styles inside its own content, but not inside the live previews.

Responsive behavior

Type sizes do not change with the breakpoint. Long words in headings should be allowed to wrap by the component that uses them.

Accessibility

Sizes in rem support text resizing up to 200% (WCAG 1.4.4). The body line height is 1.6, which meets the 1.5 guidance of WCAG 1.4.12 (Text Spacing). Set lang on content in another language (as in the Arabic sample) so screen readers pick the right voice. Use heading levels for structure, not for size: the size tokens exist for visual choices.

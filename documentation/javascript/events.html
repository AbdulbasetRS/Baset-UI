Events

Two channels: DOM events on elements and a global publish and subscribe bus.

Overview

There are two separate event channels. DOM events are CustomEvents dispatched on a component element, named bui:{component}:{event}. The global bus is a plain publish and subscribe object for code that is not tied to an element. A DOM event is not copied to the bus and the reverse.

Note

The core ships no component. The examples use my-widget as a placeholder name for a component that you register yourself. The snippets are not live demos. A runnable check of every behavior described here is tests/manual/core.html in the repository.

DOM events

BUI.trigger(element, component, event, detail?, options?) dispatches bui:{component}:{event} and returns true when no listener canceled it. Both names are kebab-case; an invalid call logs a warning, dispatches nothing and returns false.

Cancelable before-events

An event that announces something about to happen is named with the before- prefix and is cancelable. The component checks the return value and stops when it is false. Names are kebab-case, so the event is bui:my-widget:before-open, not beforeOpen.

// inside a component: context.trigger is trigger() bound to the element and component
if (!context.trigger('before-open', { size: options.size }, { cancelable: true })) return;
open();
context.trigger('open', { size: options.size });

A page listens with the standard API:

document.addEventListener('bui:my-widget:before-open', (event) => {
    if (!isAllowed(event.detail)) event.preventDefault();
});

preventDefault() on an event that was not triggered with cancelable: true has no effect, and trigger() still returns true.

Global bus

Bus functions
FunctionReturnsDescription
BUI.on(name, handler)functionSubscribes. Returns a function that unsubscribes. The same handler is subscribed once per name. handler(detail, name).
BUI.off(name, handler?)nothingRemoves the handler, or every handler of name when no handler is given.
BUI.emit(name, detail?)numberCalls the handlers synchronously and returns how many were called. A handler that throws is logged and does not stop the others.

Bus names are free-form non-empty strings. The core itself emits three:

Events emitted by the core
NameDetailWhen
register{ name }A component was registered.
init{ root, count }BUI.init() created at least one instance. Not emitted when nothing was created.
destroy{ root, count }BUI.destroy() or BUI.destroyAll() destroyed at least one instance. root is null for destroyAll(). Not emitted for instance.destroy() called directly.

Examples

const stop = BUI.on('register', ({ name }) => console.log('registered', name));
BUI.register('my-widget', { create: () => ({ destroy() {} }) });
stop();
const probe = (event) => console.log(event.type, event.detail);
document.body.addEventListener('bui:my-widget:open', probe);
BUI.trigger(document.body, 'my-widget', 'open', { id: 1 });   // logs: bui:my-widget:open { id: 1 }
document.body.removeEventListener('bui:my-widget:open', probe);

Responsive behavior

Events do not depend on the viewport width.

Accessibility

Events do not move focus and are not announced to assistive technology. A component that reacts to its own events, for example by opening a dialog, is responsible for focus management and live regions. Do not use a cancelable event as the only way to explain to a user why an action was blocked: show a visible message.

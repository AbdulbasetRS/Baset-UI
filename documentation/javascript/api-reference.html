API Reference

All members of window.BUI as implemented.

Overview

Every member of window.BUI as implemented. Anything not listed here does not exist. Members whose name starts with an underscore are not provided.

DOM helpers (BUI.dom)

An invalid selector logs a warning and returns null, an empty array or false. Functions that take an element accept only elements and are safe to call with null. In the data helpers name is the kebab-case part after data-bui-.

Logger (BUI.log)

Messages are written to the console as [BUI] Component: message with the console method of the same name. Levels from quiet to verbose: silent, error, warn (default), info, debug. A message is written when its level is at or below the current level.

BUI.log
FunctionReturnsDescription
error(component, message, extra?)nothingconsole.error.
warn(component, message, extra?)nothingconsole.warn.
info(component, message, extra?)nothingconsole.info.
debug(component, message, extra?)nothingconsole.debug.
getLevel()stringCurrent level.
setLevel(level)booleanChanges the level. false with a warning when the level is invalid. BUI.config({ logLevel }) does the same.

The core reports problems with a warning, for example a missing target or an invalid option, and with an error when a component fails to initialize or destroy.

Examples

BUI.utils.deepMerge({ a: { x: 1 }, list: [1] }, { a: { y: 2 }, list: [9] });
// { a: { x: 1, y: 2 }, list: [9] }

BUI.utils.kebabToCamel('no-results');      // "noResults"
BUI.dom.isRTL(document.querySelector('#menu'));

BUI.log.warn('MyWidget', 'Something is off');   // console.warn("[BUI] MyWidget: Something is off")

Responsive behavior

None of these functions depends on the viewport width.

Accessibility

The helpers do not change the accessibility tree. isRTL() reflects the page direction so components can mirror keyboard handling of horizontal arrow keys in RTL. uid() is meant for generating ids that connect elements through aria-labelledby, aria-controls and similar attributes.

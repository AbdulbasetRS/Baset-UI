Grid

A 12 column flexbox grid that mirrors automatically in RTL.

Overview

A 12 column grid built on flexbox. Put columns inside a bui-row. The row and its columns create the gutters, so the row may sit directly in a bui-container. Columns use logical properties and flexbox, so the same markup mirrors in RTL with no extra classes.

Note

Classes that start with bui-docs- in the live previews belong to this documentation site (demo boxes and frames). They are not part of the library.

Gutters

The default gutter is --bui-grid-gutter. Override it for one row with bui-g-{0..5} (both axes), bui-gx-{0..5} (horizontal) or bui-gy-{0..5} (vertical). Gutter classes are not generated per breakpoint.

Warning

A row has a negative inline margin of half the horizontal gutter. Keep the gutter at or below twice --bui-container-padding-x when the row sits directly in a container, or the page scrolls sideways. That is why the gutter classes stop at 5.

Offset and order

bui-offset-{0..11} adds that many twelfths of space at the inline start (the right in LTR, the left in RTL). bui-order-first, bui-order-{0..5} and bui-order-last change the visual order.

bui-rowFlex row. Defines the gutters.
bui-colEqual-width column (flex: 1 0 0%).
bui-col-autoWidth of the content.
bui-col-{1..12}Width in twelfths.
bui-offset-{0..11}Inline-start margin in twelfths.

bui-g-{0..5}, bui-gx-*, bui-gy-*Gutter size (no breakpoint variants).

Every class except the gutter classes has a breakpoint variant: bui-col-md-6, bui-offset-lg-2, bui-order-xl-last, bui-row-cols-sm-3. Variants exist for XS, SM, MD, LG, XL, XXL and XXXL.

Grid tokens
TokenDefaultDescription
--bui-grid-gutterDefault gutter (both axes read from it on bui-row).
--bui-grid-gutter-x, --bui-grid-gutter-yset by bui-rowSet per row by the gutter classes. Do not set them on ancestors: bui-row redefines them.

Responsive behavior

Without an infix a column rule applies at every width. With an infix it applies from that breakpoint upward, so list the smallest width first (bui-col-12 bui-col-md-6). Columns that have no width class below their breakpoint are 100% wide.

Accessibility

bui-order-* changes only the visual order. Keyboard focus and screen readers follow the DOM order, so a mismatch breaks WCAG 1.3.2 (Meaningful Sequence) and 2.4.3 (Focus Order). Use order only where the DOM order is still logical. The grid adds no roles. If the content is tabular, use a real table. Do not use gutters as the only separation between pieces of information.

Grid

A 12 column system with bui-row and bui-col, plus a CSS Grid layer for two-dimensional layouts.

Introduction

Baset-UI has two layout layers. Row and Column (bui-row, bui-col) is a 12 column Flexbox system for page layouts, built the same way as the Bootstrap grid. CSS Grid (bui-grid) is for two-dimensional layouts and is documented further down this page.

Columns must be direct children of a bui-row, and a row goes inside a container. The container padding absorbs the negative margin of the row, so the page never scrolls sideways. Gutters are limited to spacing step 5 for the same reason.

Row and Column: naming convention

PatternMeaning
bui-rowFlexbox row that holds columns. Wraps, and cancels the edge gutters with a negative inline margin
bui-colEqual-width column that fills the space left in the row
bui-col-autoColumn sized to its content
bui-col-{n}Column of n out of 12, n = 1 to 12
bui-col-{bp}, bui-col-{bp}-auto, bui-col-{bp}-{n}Same, from that breakpoint upward
bui-row-cols-{n}, bui-row-cols-autoSet on the row: columns per line, n = 1 to 6 (bui-row-cols-{bp}-{n} for breakpoints)
bui-offset-{n}, bui-offset-{bp}-{n}Start margin of n columns, n = 0 to 11
bui-order-{first|0-5|last}, bui-order-{bp}-{value}Visual order of a column
bui-g-{k}, bui-gx-{k}, bui-gy-{k}Both gutters, horizontal gutter, vertical gutter. k = 0 to 5 (spacing steps)
bui-items-*, bui-justify-*, bui-content-*Alignment, shared with Flexbox

Breakpoint infixes: xs, sm, md, lg, xl, xxl, xxxl. Classes without an infix apply from the smallest screen; see Breakpoints.

Row and Column: responsive behavior

Every column, row-cols, offset and order class has variants for all seven breakpoints, applied from the breakpoint upward. Write the smallest-screen value without an infix first, then add larger overrides, for example bui-col-12 bui-col-md-6 bui-col-xl-4. Gutters have no breakpoint variants. Columns have max-width: 100%, and long content wraps inside its column.

Row and Column: RTL and LTR

Rows follow the page direction: the first column is on the right in RTL and on the left in LTR, and offsets use margin-inline-start. No class changes. See the last example above.

Row and Column: tokens used

--bui-row-gutter (default horizontal gutter), --bui-gutter-x and --bui-gutter-y (set per row by the gutter classes), --bui-space-0 to --bui-space-5

CSS Grid: introduction

Add bui-grid to a container and choose the number of columns with bui-grid-cols-{n} (1 to 12). Direct children become grid items. Every column is minmax(0, 1fr), so long content never pushes a column wider than its share.

Default gap is --bui-grid-gap (--bui-space-4). Items stretch to the full height of their row, so items in the same row have equal height without extra classes.

CSS Grid: naming convention

PatternMeaning
bui-gridTurns the element into a grid container
bui-grid-cols-{n}Number of columns, n = 1 to 12
bui-grid-cols-{bp}-{n}Same, from that breakpoint upward
bui-col-span-{n}Item spans n columns (bui-col-span-full spans all)
bui-row-span-{n}Item spans n rows, n = 1 to 6 (bui-row-span-full)
bui-gap-{k}, bui-gap-x-{k}, bui-gap-y-{k}Gap, column gap, row gap. k is a spacing token step: 0, 1, 2, 3, 4, 5, 6, 8, 10, 12
bui-grid-auto-fit, bui-grid-auto-fillAs many columns as fit, each at least --bui-grid-min
bui-grid-rows-{n}Explicit rows, n = 1 to 6
bui-grid-auto-rows-{auto|min|max|fr}Size of implicit rows
bui-grid-auto-cols-{auto|min|max|fr}Size of implicit columns
bui-grid-flow-{row|column|dense|row-dense|column-dense}Auto placement direction

Breakpoint infixes: xs, sm, md, lg, xl, xxl, xxxl. Spans and column counts have responsive variants; see Breakpoints.

CSS Grid: responsive behavior

Column counts, column spans and row spans have variants for all seven breakpoints (xs, sm, md, lg, xl, xxl, xxxl), applied from the breakpoint upward. Write the smallest-screen value without an infix first, then add larger overrides. Grid items have min-width: 0, so wide content scrolls or wraps inside its cell instead of overflowing the page.

Grid follows the page direction: the first column is on the right in RTL and on the left in LTR. No class needs to change.

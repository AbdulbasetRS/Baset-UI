Container

Centers content and limits its width. Three variants: fixed, fluid and responsive.

Introduction

A container centers its content with margin-inline: auto and keeps it off the screen edge with padding-inline. The maximum widths and the padding are CSS variables, so they can be changed per page or per element.

ClassBehavior
bui-containerFixed. Full width below 480px, then the maximum width steps up at every breakpoint (see the table below).
bui-container-fluidFluid. Always uses the full available width and keeps the padding.
bui-container-{breakpoint}Responsive. Fluid below that breakpoint, then follows the fixed steps from the breakpoint upward. Available: bui-container-xs, bui-container-sm, bui-container-md, bui-container-lg, bui-container-xl, bui-container-xxl, bui-container-xxxl.

Maximum widths

Widths include the padding (box-sizing: border-box is global).

BreakpointApplies fromMax widthToken
XS480px and up28rem (448px)--bui-container-xs
SM576px and up33.75rem (540px)--bui-container-sm
MD768px and up45rem (720px)--bui-container-md
LG992px and up60rem (960px)--bui-container-lg
XL1200px and up71.25rem (1140px)--bui-container-xl
XXL1600px and up90rem (1440px)--bui-container-xxl

Usage

Add one container class to the element that wraps your page content.

Fixed container

The dashed edges show the container box. Inside this preview the container cannot be wider than the preview frame; on a real page the full viewport applies. Viewport: -, container width: -.

Fixed container
<div class="bui-container" id="demo-fixed">Fixed container</div>

Fluid container

Always full width. Container width: -.

Fluid container
<div class="bui-container-fluid" id="demo-fluid">Fluid container</div>

Responsive container

Fluid below LG (992px), then fixed from LG upward. Container width: -.

Responsive container (lg)
<div class="bui-container-lg" id="demo-responsive">Responsive container (lg)</div>

Customization

The padding and every maximum width are tokens. Override them on :root for the whole site, or inline on one element.

Custom padding and width

Here the padding is raised to --bui-space-5 and the LG maximum width is lowered for this element only.

Custom container 
<div class="bui-container-lg" style="--bui-container-padding: var(--bui-space-5); --bui-container-lg: 40rem">
    Custom container
</div>

Responsive behavior

Containers use the standard breakpoints. Below 480px every container is full width with padding, so content never touches the screen edge. Resize the window and watch the widths above change at 480, 576, 768, 992, 1200, 1600 and 1920px.

RTL and LTR

The container is centered with margin-inline: auto and padded with padding-inline, which are symmetric, so the box is identical in both directions. The text inside follows the page direction.

Same markup in dir="rtl"

Container in a right-to-left page
<div dir="rtl">
    <div class="bui-container-fluid">Container in a right-to-left page</div>
</div>

Tokens used

--bui-container-xs, --bui-container-sm, --bui-container-md, --bui-container-lg, --bui-container-xl, --bui-container-xxl, --bui-container-xxxl, --bui-container-padding

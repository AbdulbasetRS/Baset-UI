Container

Center and pad page content, with a maximum width per breakpoint.

Overview

A container centers page content and gives it inline padding. bui-container is fixed: it is fluid below SM and gets a maximum width from SM upward. bui-container-fluid is always 100% wide.

Container classes
ClassBehavior
bui-containerWidth 100% below SM. From SM upward max-width follows the table below.
bui-container-fluidWidth 100% at every breakpoint.

Note

Classes that start with bui-docs- in the live previews belong to this documentation site (demo boxes and frames). They are not part of the library.

Custom padding

Set the component token on the element or on any ancestor.

--bui-container-padding-x: var(--bui-space-5)

Customization

Responsive behavior

Below SM the container is fluid. At SM and above the width steps up at each breakpoint and never shrinks. Padding uses padding-inline, so it mirrors correctly in RTL.

Accessibility

A container has no role and no ARIA. Maximum widths are in pixels but content inside should use relative units, so text can grow with browser zoom without clipping (WCAG 1.4.4, 1.4.10).

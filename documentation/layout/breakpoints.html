Breakpoints

Seven breakpoints on top of a mobile-first base, readable from CSS and JavaScript.

Overview

Baset-UI has one base state (below 480px) and seven breakpoints. Every responsive class uses the same infix, for example bui-col-md-6, bui-ms-lg-3 and bui-flex-xl-row. A class with an infix applies from that breakpoint upward.

Mobile first

Styles are written for the smallest screen first and widened with min-width media queries. The library does not use max-width queries.

Note

CSS variables do not work inside @media. The media queries in baset-ui.css contain the pixel values literally, and the --bui-bp-* tokens exist so JavaScript can read the same numbers. Both lists must change together.

/* Base (below 480px): one column */
.my-card { padding: var(--bui-space-3); }

/* From MD (768px) upward */
@media (min-width: 768px) {
    .my-card { padding: var(--bui-space-4); }
}

Reading the tokens from JavaScript

This is a plain CSS property read. It is not a BUI JavaScript API (none exists yet).

const md = parseInt(getComputedStyle(document.documentElement).getPropertyValue('--bui-bp-md'), 10);
const isMdUp = window.matchMedia('(min-width: ' + md + 'px)').matches;

Examples

Resize the window to see the active breakpoint. The value is computed from the tokens above.

const names = ['xs', 'sm', 'md', 'lg', 'xl', 'xxl', 'xxxl'];
const style = getComputedStyle(document.documentElement);
let current = 'base';
names.forEach(function (n) {
    const px = parseInt(style.getPropertyValue('--bui-bp-' + n), 10);
    if (window.innerWidth >= px) current = n;
});

Responsive behavior

Test layouts at 320, 480, 576, 768, 992, 1200, 1600 and 1920 pixels. Content must not scroll sideways at any width of 320px or more. Wide content (tables, code) scrolls inside its own container.

Accessibility

Layout must reflow without two-dimensional scrolling at a 320 CSS pixel width (WCAG 1.4.10). Because breakpoints are expressed in CSS pixels, browser zoom to 400% on a 1280px window reaches the 320px layout, so the base state is the one that zoomed users see. Do not hide essential content only at one breakpoint, and do not rely on :hover at any breakpoint.

Spacing

One scale, logical properties only, with a variant for every breakpoint.

Overview

One spacing scale (--bui-space-0 to --bui-space-6) drives margin, padding and gap utilities. All of them use logical properties: there are no left and right classes, so spacing flips in RTL by itself.

Note

Classes that start with bui-docs- in the live previews belong to this documentation site (demo boxes and frames). They are not part of the library.

Naming

Pattern: bui-{property}[-{bp}]-{size}, for example bui-ms-3, bui-px-md-4, bui-mx-auto.

Responsive behavior

Without an infix a class applies at every width. With an infix it applies from that breakpoint upward and overrides the base class. All spacing utilities use !important, so they also override future component styles; they are the one place the library allows it.

Accessibility

Use spacing to keep interactive targets apart: WCAG 2.2 requires targets of at least 24 by 24 CSS pixels (or enough spacing around smaller ones), and this library aims for 44 pixels (2.5.8). Do not use margins or padding to fake structure that needs real elements, such as empty paragraphs. Text spacing set by users (WCAG 1.4.12) must not clip, so avoid fixed heights.

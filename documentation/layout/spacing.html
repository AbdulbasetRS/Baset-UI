Spacing

One spacing scale used for every margin, padding and gap in the library.

Introduction

The spacing scale is a set of CSS variables, --bui-space-0 to --bui-space-12. Components and layout classes take their distances from it, so changing a token changes the rhythm of the whole interface. Values are in rem; the pixel column assumes a 16px root font size.

The scale grows in small steps first (0.25rem to 2rem for steps 1 to 5), then in 1rem steps (3rem to 6rem for steps 6 to 12).

Usage

Use the tokens anywhere a length is expected. Prefer logical properties (padding-inline, margin-block) so the result is correct in both directions.

Tokens in your own CSS

Inline styles are used here only to keep the example self-contained.

Padding block: space-3, inline: space-5.

Margin below the first line: space-2.

<div style="padding-block: var(--bui-space-3); padding-inline: var(--bui-space-5); border: var(--bui-border-width) solid var(--bui-color-border); border-radius: var(--bui-radius-md)">
    <p style="margin-block-end: var(--bui-space-2)">Padding block: space-3, inline: space-5.</p>
    <p style="margin-block-end: 0">Margin below the first line: space-2.</p>
</div>

Gap classes

Grid and Flexbox use the scale through gap classes: bui-gap-{k}, bui-gap-x-{k} and bui-gap-y-{k}, with k one of 0, 1, 2, 3, 4, 5, 6, 8, 10, 12. They are shared by Grid and Flexbox.

This release provides the spacing tokens and the gap classes. Margin and padding utility classes are not included.

Responsive behavior

Spacing tokens are fixed values and do not change with the viewport. To change spacing at a breakpoint, assign a different token inside a min-width media query (see Breakpoints).

RTL and LTR

Gap is direction independent. For margin and padding in your own CSS use logical properties such as margin-inline-start so the spacing flips with the page direction.

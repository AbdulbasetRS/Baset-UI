Flexbox

Direction, wrap, alignment, grow and shrink, with a variant for every breakpoint.

Overview

Flexbox layout utilities. Add bui-flex (or bui-inline-flex) to make a flex container, then combine the classes below. All of them have breakpoint variants: bui-flex-md-row, bui-justify-lg-between, bui-items-xl-center.

Note

bui-flex and bui-inline-flex are included here only because the other classes need a flex container. The general display utilities (d-* style) belong to a later task and are not part of this page. Like all utilities they use !important, so they also override the hidden attribute.

Note

Classes that start with bui-docs- in the live previews belong to this documentation site (demo boxes and frames). They are not part of the library.

Class reference

Flexbox classes
GroupClasses
Containerbui-flex, bui-inline-flex (no breakpoint variants)
Directionbui-flex[-bp]-{row, row-reverse, column, column-reverse}
Wrapbui-flex[-bp]-{wrap, nowrap, wrap-reverse}
Justifybui-justify[-bp]-{start, end, center, between, around, evenly}
Align itemsbui-items[-bp]-{start, end, center, baseline, stretch}
Align contentbui-content[-bp]-{start, end, center, between, around, stretch}
Align selfbui-self[-bp]-{auto, start, end, center, baseline, stretch}
Grow and shrinkbui-flex[-bp]-{grow-0, grow-1, shrink-0, shrink-1, fill}

[-bp] is optional: one of -xs, -sm, -md, -lg, -xl, -xxl, -xxxl.

Responsive behavior

Variants apply from their breakpoint upward and override the base class because section 7 of baset-ui.css comes after the base rules. Combine a base class with larger-breakpoint classes (bui-flex-column bui-flex-md-row).

Accessibility

row-reverse, column-reverse and wrap-reverse change only what is seen, not the DOM order used by keyboard focus and screen readers (WCAG 1.3.2, 2.4.3). Use them only when the reading order stays correct. Flex utilities add no roles or ARIA.

Flexbox

Flexbox layout classes with readable names: direction, wrap, grow and shrink, alignment, gap and responsive variants.

Introduction

Add bui-flex to a container (or bui-inline-flex for an inline one) and combine it with the classes below. Flex follows the page direction, so a row starts on the right in RTL without any extra class.

Naming convention

PatternCSSValues
bui-flex-{direction}flex-directionrow, column, row-reverse, column-reverse
bui-flex-{wrap}flex-wrapwrap, nowrap, wrap-reverse
bui-flex-1flex: 1 1 0%Item grows and shrinks, ignoring its content size
bui-flex-auto, bui-flex-noneflex: 1 1 auto, flex: noneGrow from content size, or do not flex at all
bui-flex-grow-{0|1}, bui-flex-shrink-{0|1}flex-grow, flex-shrink0 or 1
bui-items-{value}align-itemsstart, end, center, baseline, stretch
bui-content-{value}align-contentstart, end, center, between, around, evenly, stretch
bui-justify-{value}justify-contentstart, end, center, between, around, evenly
bui-gap-{k}, bui-gap-x-{k}, bui-gap-y-{k}gap, column-gap, row-gapSpacing token step: 0, 1, 2, 3, 4, 5, 6, 8, 10, 12

Responsive form: bui-{property}-{breakpoint}-{value}, for example bui-flex-md-row, bui-items-lg-center, bui-justify-xl-between. The variants cover direction, wrap, items, content and justify.

Responsive behavior

Direction, wrap, items, content and justify have variants for xs, sm, md, lg, xl, xxl, xxxl, applied from that breakpoint upward. A common pattern is a column on small screens and a row from MD, as in the examples above.

RTL and LTR

Flex containers read the page direction. bui-justify-start means the start edge (right in RTL, left in LTR) and bui-justify-between keeps the first item at the start. Do not use the reverse classes to mirror a layout.

Same markup in dir="rtl"

البداية
النهاية
<div dir="rtl" lang="ar">
    <div class="bui-flex bui-items-center bui-justify-between">
        <div>البداية</div>
        <div>النهاية</div>
    </div>
</div>

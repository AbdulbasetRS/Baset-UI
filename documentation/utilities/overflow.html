Overflow

Decide what happens to content that is larger than its box: scroll it, clip it, or let it spill out.

Introduction

Overflow utilities set the CSS overflow properties. Use the general classes for both axes, or the axis classes to control horizontal and vertical overflow separately. Pattern: bui-overflow-{value}, bui-overflow-x-{value}, bui-overflow-y-{value}.

Classes

ClassCSSDescription
bui-overflow-visibleoverflow: visibleThe default. Content that does not fit is drawn outside the box.
bui-overflow-hiddenoverflow: hiddenContent outside the box is cut. The box is still a scroll container (it can be scrolled by code or by focus), but has no scrollbar.
bui-overflow-clipoverflow: clipLike hidden, but the box never becomes a scroll container. Not scrollable at all, even by code.
bui-overflow-autooverflow: autoScrollbars appear only on the axis where the content does not fit.
bui-overflow-scrolloverflow: scrollScrollbars are always present on both axes, even when nothing overflows (on systems with classic scrollbars).
bui-overflow-x-{value}overflow-xSame five values (visible, hidden, clip, auto, scroll), horizontal axis only.
bui-overflow-y-{value}overflow-ySame five values, vertical axis only.

The axis classes are defined after the general ones, so bui-overflow-hidden bui-overflow-y-auto hides horizontal overflow and scrolls vertically.

ValueScrollbarUser can scrollUse for
autoOnly when neededYesScrollable containers. The usual choice.
scrollAlwaysYesWhen a stable layout matters, so the content does not shift when a scrollbar appears.
hiddenNeverNot with mouse or touchClipping rounded corners, cropping media, containing floats.
clipNeverNoClipping without a scroll container (keeps sticky children working against an outer scroller).

Mixing values. visible on one axis combined with hidden, auto or scroll on the other is computed by the browser as auto on the visible axis. If you need to clip one axis and leave the other visible, use clip (bui-overflow-x-clip with bui-overflow-y-visible).

Overflow and sticky

An element with position: sticky sticks against its nearest ancestor that has an overflow value other than visible. That ancestor is the scroll container, even if it does not scroll.

A scrolling ancestor (bui-overflow-auto with a height) is the reference, and the sticky element sticks inside it. This is the sticky example on the Position page. A non scrolling ancestor with bui-overflow-hidden is also treated as the scroll container, so a sticky child never sticks to the page and seems not to work. To clip an ancestor and keep sticky working against the page, use bui-overflow-clip, which does not create a scroll container.

<!-- Sticks to the scrolling box -->
<div class="bui-overflow-y-auto" style="block-size: 20rem">
    <div class="bui-position-sticky bui-inset-block-start-0">Header</div>
</div>

<!-- Does NOT stick to the page: the hidden ancestor is the scroll container -->
<div class="bui-overflow-hidden">
    <div class="bui-position-sticky bui-inset-block-start-0">Header</div>
</div>

<!-- Sticks to the page: clip does not create a scroll container -->
<div class="bui-overflow-clip">
    <div class="bui-position-sticky bui-inset-block-start-0">Header</div>
</div>

Responsive behavior

Overflow classes have no breakpoint variants in this release. To avoid unintended horizontal overflow on narrow screens, put wide content (tables, code, long strings) in a bui-overflow-x-auto container, as the documentation tables on this site do.

RTL and LTR

Overflow itself is direction independent. The horizontal scroll origin follows the page direction: a scroll container starts at the right edge in RTL and the content extends to the left.

Accessibility

A box that scrolls must be reachable with the keyboard. Browsers make scrollable regions focusable in some cases, but not reliably, so add tabindex="0", a role="region" and an aria-label that says what scrolls, as in the examples. Content clipped by hidden or clip is still in the accessibility tree, so screen readers read it even though it is not visible. Never clip content that users need to see.

Tokens used

None for the overflow classes. The clipping example also uses --bui-radius-lg and the border tokens through the Borders utilities.

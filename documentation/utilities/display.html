Display

Set the CSS display value of an element, optionally from a breakpoint upward.

Overview

Display utilities change the display property with a class. The pattern is bui-d-{value}, and bui-d-{bp}-{value} applies from that breakpoint upward. There are no classes for table, contents or flow-root.

Note

All utilities in the library use !important. This is the single place the library allows it (see CORE_ASSETS.md): utilities are declared before components, so without it a component style would win over a utility class. Only utilities may do this.

Note

Classes that start with bui-docs- in the live previews belong to this documentation site (demo boxes and frames). They are not part of the library.

Breakpoint variants exist for every class: bui-d-xs-*, bui-d-sm-*, bui-d-md-*, bui-d-lg-*, bui-d-xl-*, bui-d-xxl-* and bui-d-xxxl-*.

bui-flex and bui-inline-flex from the Flexbox page produce the same result as bui-d-flex and bui-d-inline-flex but have no breakpoint variants. They are kept so existing markup does not break. When a class must change with the viewport, use the bui-d- form.

Responsive behavior

A class without an infix applies at every width. A class with an infix applies from that breakpoint upward and overrides the base class, because the variants are declared in section 7 of baset-ui.css, after the base rules. Write the smallest width first: bui-d-none bui-d-md-block. When two display classes apply to the same element at the same width, the one declared later in baset-ui.css wins, not the one written last in the markup.

Accessibility

display: none removes the element from the accessibility tree and from the keyboard order, so a screen reader user does not get it either. Use bui-d-none only for content that is truly not relevant at that width. To hide something only visually, use bui-visually-hidden. Hiding content by breakpoint must not remove the only way to reach a function: when a control is hidden on small screens, another control must give access to the same function. The utilities also override the hidden attribute, so avoid mixing them on one element.

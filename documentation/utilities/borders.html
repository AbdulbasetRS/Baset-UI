Borders

Borders, logical sides, a radius scale with logical corners, and shadows, all from tokens.

Overview

Border utilities draw a border with the width, style and color tokens, on all sides or on one logical side. Radius and shadow utilities use the radius and shadow scales. Everything reads tokens, so it follows Light and Dark mode and any scope that overrides the tokens. There are no left and right classes: s is the inline start and e the inline end, which flip in RTL.

Note

All utilities use !important, the one place the library allows it (CORE_ASSETS.md). Borders have no breakpoint variants.

Width and style classes are modifiers of the bui-border, bui-border-t, -b, -s and -e classes: they change those borders and nothing else, and they work on one side as well as on all sides. They do not change borders that a component or your own CSS draws. A width or style class on a parent does not affect bordered children, because the internal --bui-util-border-* properties are registered as non-inherited (in a browser without @property support they would be inherited).

Responsive behavior

Border, radius and shadow classes have no breakpoint variants because they do not change the layout. To change one at a breakpoint, set the matching token in a min-width media query (see the CSS Variables page). Borders add to the size of an element only when it is not using box-sizing: border-box; the library base sets border-box on every element.

Accessibility

A border that marks the edge of an input, a button or another control must have a contrast of at least 3:1 against the background (WCAG 1.4.11). Use bui-border-strong or a semantic color for those, not bui-border-default, which is meant for decoration. Do not rely on a border color alone to give meaning, such as an error state (WCAG 1.4.1): add text or an icon. The -subtle border colors and shadows are decorative and have not been checked for contrast. Dashed and dotted styles are not an alternative to text. In forced-colors mode the browser replaces border colors with system colors and removes shadows; this has not been tested yet.

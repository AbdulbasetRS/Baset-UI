Position

Position types and logical offsets that mirror in RTL, plus z-index tokens.

Overview

Position utilities set the position type, place an element with offsets, center it with a translate, and choose a z-index from the library scale. Offsets are logical: start and end follow the text direction, so bui-start-0 is the left edge in LTR and the right edge in RTL. There are no left and right classes.

Note

All utilities use !important, the one place the library allows it (CORE_ASSETS.md). Only the position type has breakpoint variants. Offsets, translate and z-index do not, because changing them by breakpoint is rare and would add a large number of rules.

Offsets

Offset classes
ClassCSS propertySide
bui-top-{0, 50, 100}inset-block-startTop in horizontal writing modes
bui-bottom-{0, 50, 100}inset-block-endBottom
bui-start-{0, 50, 100}inset-inline-startLeft in LTR, right in RTL
bui-end-{0, 50, 100}inset-inline-endRight in LTR, left in RTL

0 is 0; 50 and 100 are 50% and 100% of the containing block. Offsets only take effect on a positioned element (any type except static).

Centering with translate

Translate classes
ClassLTRRTL
bui-translate-middletranslate(-50%, -50%)translate(50%, -50%)
bui-translate-middle-xtranslateX(-50%)translateX(50%)
bui-translate-middle-ytranslateY(-50%)same as LTR

transform has no logical form. With bui-start-50 the element starts at the right in RTL, so the horizontal part of the translate flips with the direction (the :dir(rtl) pseudo-class), and the element stays centered in both directions. This needs a browser that supports :dir() (all current evergreen browsers). Use bui-start-50 with these classes, not bui-end-50.

Fixed

A fixed element is positioned against the viewport, so it is not shown live here. It would cover this page. The markup for a fixed element at the bottom end of the screen:

<div class="bui-position-fixed bui-bottom-0 bui-end-0 bui-z-fixed">
    ...
</div>

Responsive behavior

The position type has a variant for every breakpoint, for example bui-position-relative bui-position-md-static makes an element relative below MD and static from MD upward. Variants apply from their breakpoint upward and override the base class. Offsets, translate and z-index are not responsive. Fixed and sticky elements must not hide content at a 320px width or when the page is zoomed to 400% (WCAG 1.4.10).

Accessibility

Positioning changes only the visual place of an element, not its place in the DOM order that keyboard focus and screen readers use (WCAG 1.3.2, 2.4.3). Keep the DOM order logical. A fixed or sticky element can cover a focused element: a focused control must not be completely hidden behind it (WCAG 2.4.11). Scrolling regions such as the sticky example need to be reachable with the keyboard, so they carry tabindex="0", a role and a label. Position utilities add no roles or ARIA.

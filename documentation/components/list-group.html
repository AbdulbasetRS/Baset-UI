List Group

A list of related items: plain, flush, numbered, links or buttons, with active and disabled states, badges, icons and responsive horizontal layouts. CSS only.

01. Installation & Include

List Group is part of the Core stylesheet, so assets/css/baset-ui.css is the only required file. Load the icons Extension only if an item contains an icon, and a Theme if you use one. Order: Core, then Extension, then Theme. No JavaScript is needed.

<!DOCTYPE html>
<html lang="en" dir="ltr" data-bui-theme="default" data-bui-mode="light">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>List Group</title>
    <link rel="stylesheet" href="assets/css/baset-ui.css">
    <!-- Only when the content contains an icon -->
    <link rel="stylesheet" href="assets/css/extensions/baset-ui-icons.css">
    <!-- Optional theme -->
    <link rel="stylesheet" href="assets/css/themes/ocean.css">
</head>
<body>
    <ul class="bui-list-group">
        <li class="bui-list-group__item">First item</li>
        <li class="bui-list-group__item">Second item</li>
    </ul>
</body>
</html>

The item texts, names and counts in the examples are sample text.

02. Customize

Every option below is a real class documented in section 04. Numbered needs an ordered list, so it applies only to the List type (links and buttons are not lists). Flush is for the column layout and is ignored when a horizontal layout is chosen. The active item is the second one and the disabled item is the third. The text is sample text.

06. JavaScript API

CSS only, no JavaScript API. List Group registers nothing with BUI.register, fires no events and does not manage the active item: your code sets or removes aria-current. It has no internal text, so it adds no translation key to assets/i18n/*.json.

07. Responsive Behavior

  • The default list is a column and as wide as its container; long words wrap inside the items (no horizontal scrolling).
  • bui-list-group--horizontal-sm, -md and -lg are a column below 576px, 768px and 992px and a row from there; bui-list-group--horizontal is a row at every width, with the items sharing the width and wrapping their text. These are viewport media queries.
  • On a touch pointer (pointer: coarse), link and button items are at least 44px high; plain items keep their size.
  • The border overlap and the corner radii are flipped by the layout, so a horizontal list keeps its rounded outer corners at the start and end sides, in LTR and RTL.

08. Accessibility

Keyboard

Plain items are not focusable. Link and button items are tab stops in source order, and activate with their native keys (Enter for a link, Enter and Space for a button). Disabled buttons are skipped natively; a disabled link needs tabindex="-1" and no href. The focus ring is drawn inside the item (the neighbours overlap its outside) and, on the active item, in the active text color so it stays visible on the primary fill.

ARIA and semantics

  • Use ul/li for plain items and ol for a numbered list, so the count and order are announced. A list of links or buttons is a div (use a nav with a label for navigation).
  • aria-current marks the current item ("page" for the current page, "true" otherwise). aria-disabled="true" marks a disabled link or plain item; use disabled on a button.
  • The list style is reset, which some versions of Safari with VoiceOver treat as removing the list role. This was not tested; if it matters in your project, add role="list" to the ul or ol.
  • Do not rely on color alone for the active item when meaning matters: the attribute carries the state for assistive technology, and you can add visible text or an icon.

Contrast

Measured in Chromium for plain, active and disabled items, and for items inside every card variant, in Light and Dark with the default and ocean themes (together with the Card samples: 524 samples, lowest 5.07:1 for the List Group). Hover and pressed states stay above 4.5:1 in cards of every variant (64 samples). Disabled items are exempt from the contrast requirement and still measure above 3:1.

Screen reader

Not tested with a screen reader (NVDA, VoiceOver or similar).

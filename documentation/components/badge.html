Badge

A small label or count in three variants, six semantic colors and three sizes, with pill, dot, icon and notification placement. CSS only.

01. Installation & Include

Badge is part of the Core stylesheet, so assets/css/baset-ui.css is the only required file. Load the icons Extension only if a badge or its host contains an icon, and a Theme if you use one. Order: Core, then Extension, then Theme. No JavaScript is needed.

<!DOCTYPE html>
<html lang="en" dir="ltr" data-bui-theme="default" data-bui-mode="light">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Badge</title>
    <link rel="stylesheet" href="assets/css/baset-ui.css">
    <!-- Only when a badge or its host contains an icon -->
    <link rel="stylesheet" href="assets/css/extensions/baset-ui-icons.css">
    <!-- Optional theme -->
    <link rel="stylesheet" href="assets/css/themes/ocean.css">
</head>
<body>
    <span class="bui-badge">New</span>

</body>
</html>

02. Customize

Every option below is a real class documented in section 04. The text in the examples is sample text. A dot has no text, so the text option is ignored when Dot is on. Notification places the badge on the corner of a sample icon button; its position options apply only then.

03. Default

New 
<span class="bui-badge">New</span>

With no modifier, .bui-badge is a solid, primary, medium badge with a small corner radius.

Component tokens

The tokens are declared on :root, on any [data-bui-mode] and on any [data-bui-theme] element, so a Theme or a container can override them. Colors are not component tokens: they follow the semantic color tokens through the color modifiers, so a Theme changes them by redefining the semantic colors.

06. JavaScript API

CSS only, no JavaScript API. Badge registers nothing with BUI.register, fires no events and has no options to parse. Change the text, classes or attributes with your own code when the count changes.

Badge adds no translation key: its text is whatever you write. For a visually hidden text inside a dot, use data-bui-i18n with a key you own, or one of the existing keys in assets/i18n/*.json.

07. Responsive Behavior

Badge has no breakpoint-specific styles; it follows its container and its font size.

  • A badge never wraps its text (white-space: nowrap), so keep the text short. A long text inside a narrow container overflows; shorten it or place the badge where it can wrap as a whole (a flex row with bui-flex-wrap).
  • A badge is inline-flex, so it sits in a line of text and takes its size from the font size of its size class, not from the surrounding text.
  • A floating badge sits partly outside its host. Leave room around the host (padding or margin) so it is not clipped by an ancestor with overflow: hidden.
  • Badge has no hover styles and no touch-target rule, because it is not interactive. If the badge is clickable, put it inside a button or a link instead.

08. Accessibility

Keyboard

Badge is not interactive: it is not focusable and has no keyboard behavior. A badge inside a button or link is part of that control.

ARIA

  • A badge with text is read as normal text, in document order. A bare number next to a label can be ambiguous, so write the meaning in the surrounding text or in a visually hidden text ("3 unread messages").
  • A dot has no text: put a visually hidden text inside it (bui-visually-hidden). Without it, assistive technology sees an empty element.
  • A badge that changes while the user is on the page (a live count) is not announced by itself. Put it in a role="status" region if the change matters.
  • Icons inside a badge are decorative (aria-hidden="true").
  • Meaning never depends on color alone: use text, an icon or a visually hidden text next to the color.

Screen reader

Not tested with a screen reader (NVDA, VoiceOver or similar). The semantics come from plain text and standard classes; how each reader announces a floating count after its host was not verified.

Contrast

Measured in Chromium for every variant, color and size, in Light and Dark, with the default and ocean themes, in both directions (432 samples). The lowest text contrast is 5.02:1 (solid warning, Light), above the 4.5:1 AA threshold. Dots (filled and outline) measure at least 5.02:1 against the page background, above the 3:1 non-text minimum. Badge has no animation.

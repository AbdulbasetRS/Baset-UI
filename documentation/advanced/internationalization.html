Internationalization

Language files, parameters, plurals and direction handled by BUI.locale. A new language is one JSON file.

Overview

BUI.locale loads translation files (JSON), translates keys with parameters and plurals, keeps lang and dir on <html> in sync with the active language and can translate HTML through attributes. Adding a language means adding one JSON file: no JavaScript or CSS changes.

Three languages ship: English (en), Arabic (ar) and French (fr), in assets/i18n/. The documentation shell itself (Navbar, Sidebar, Footer) stays in English: it does not use data-bui-i18n. The live examples below show the library.

Language files

One file per language, assets/i18n/{code}.json, with this structure:

{
    "meta": { "code": "fr", "name": "Français", "direction": "ltr" },
    "common": {
        "close": "Fermer",
        "showing": "Affichage de {from} à {to} sur {total}",
        "items": { "one": "{count} élément", "many": "{count} d'éléments", "other": "{count} éléments" }
    }
}
  • meta.code, meta.name (in its own language) and meta.direction (ltr or rtl) are required.
  • Keys are camelCase, nested at most 3 levels, grouped under the component name (common now; modal.close later).
  • Every file has exactly the same keys. node tests/i18n-keys.js checks it (see below).
  • A message may use {name} parameters. The parameter names must match across languages.
  • A plural message is an object whose keys are CLDR plural categories (zero, one, two, few, many, other) and must have other. Arabic needs six forms and English two, so the test treats a plural object as one key and does not compare its categories.

Load and use a language

use() loads the file (once; it is cached), sets lang and dir on <html>, updates the HTML bindings and fires bui:locale:change.

await BUI.locale.use('ar', { url: 'assets/i18n/ar.json', fallback: 'en' });

BUI.locale.t('common.close');                                        // 'إغلاق'
BUI.locale.t('common.showing', { from: 1, to: 10, total: 95 });
BUI.locale.t('common.items', { count: 3 });                          // plural
BUI.locale.get();                                                    // 'ar'
BUI.locale.getDirection();                                           // 'rtl'

Without url, the file is looked up next to the script, at ../i18n/{code}.json relative to baset-ui.js.

Warning

use() reads the file with fetch, so the page must be served over http or https (a local server or GitHub Pages). Browsers block fetch of local files opened with file://; the call then rejects, an error is logged and the active language does not change. Use BUI.locale.register() to provide messages without a request.

Live example

Choose a language: the whole page changes lang and dir (the Navbar and Sidebar flip in Arabic), and the elements below are translated from the real files. Choose English to return.

/ 

<strong data-bui-i18n="common.loading"></strong>
<button type="button" data-bui-i18n="common.close"
        data-bui-i18n-attr="aria-label:common.close; title:common.close"></button>
document.querySelectorAll('[data-locale-set]').forEach((button) => {
    button.addEventListener('click', () => {
        const code = button.dataset.localeSet;
        BUI.locale.use(code, { url: '../../assets/i18n/' + code + '.json' });
    });
});
const render = () => {
    showing.textContent = BUI.locale.t('common.showing', { from: 1, to: 10, total: 95 });
    plural.textContent = BUI.locale.t('common.items', { count: Number(count.value) });
};
document.documentElement.addEventListener('bui:locale:change', render);

The example uses bui-docs-btn and bui-docs-input, docs-only classes (no Button or Input component yet). The languages are loaded from the three real files of this repository: no sample data is typed into this page.

Parameters, plurals and missing keys

  • Parameters: {name} is replaced by params.name. A parameter that is not passed stays as {name}. Values are inserted as text, never as HTML.
  • Plurals: when the message is a plural object and params.count is a number, the form is chosen with Intl.PluralRules of the language that provided the message; if that category is missing, other is used. {count} can be used inside the text.
  • Fallback: a key is looked up in the active language, then in the fallback language (default en), then the key itself is returned and [BUI] Locale: Missing key "..." is logged once per key and language.
BUI.locale.t('common.unknown');   // returns 'common.unknown' and logs one warning

HTML binding

Binding attributes
AttributeExampleDescription
data-bui-i18ndata-bui-i18n="common.close"Replaces the element text (textContent, so any children are replaced). Use it on elements that contain only text.
data-bui-i18n-attrdata-bui-i18n-attr="aria-label:common.close; title:common.close"Sets attributes from keys: attribute:key pairs separated by ;. Event handler attributes (on...) are refused.

Bindings are applied after every successful use(). The text written in the HTML is what users see before a language is loaded and without JavaScript. For elements added later, call BUI.locale.apply(root).

Add a language

  1. Copy assets/i18n/en.json to assets/i18n/{code}.json and translate the values without changing keys.
  2. Set meta.code, meta.name and meta.direction.
  3. Add the plural categories the language needs (check them with new Intl.PluralRules('{code}').resolvedOptions().pluralCategories).
  4. Run node tests/i18n-keys.js. It fails when a key or a parameter is missing in any file.
  5. Use it with BUI.locale.use('{code}'). No other file changes.
node tests/i18n-keys.js

JavaScript API

Locale methods
NameReturnsDescription
BUI.locale.use(code, options?)Promise<string>Loads (or reuses from cache) the language and its fallback, then activates it. Resolves with the code. Rejects when the code is invalid or the file cannot be loaded; the active language is unchanged. If called again before the first call finishes, only the last call is applied.
BUI.locale.t(key, params?)stringTranslates a dotted key. Never throws; returns the key when it is missing.
BUI.locale.get()string or nullThe active language code, null until use() succeeds.
BUI.locale.getDirection()string"ltr" or "rtl".
BUI.locale.register(code, messages)booleanAdds a language object (same shape as the JSON file) to the cache without a request. Returns false and logs an error when meta.direction is missing or invalid. A later use(code) needs no url.
BUI.locale.apply(root?)numberApplies the HTML bindings inside root (default document) and returns the number of elements updated.

Accessibility

Changing the language updates lang and dir so assistive technology reads in the right language and direction. Translate aria-label and similar texts with data-bui-i18n-attr. Dates and numbers should use Intl with BUI.locale.get(). The language switch does not move focus. Screen reader pronunciation of the Arabic and French texts was not tested.

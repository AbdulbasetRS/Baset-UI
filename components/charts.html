Charts & data visualization

Line, bar, area, pie, doughnut, radar, scatter, mixed, radial and gauge charts drawn as SVG. No dependencies, responsive, with tooltips, a clickable legend, live updates, dark mode and RTL.

44 examples

Introduction

BasetChart draws charts as SVG with plain JavaScript: line, bar, area, pie, doughnut, radar, scatter, mixed, radial progress and gauge. It has no dependencies and does not use a CDN. Colors, text, grid lines and the tooltip come from the Baset UI tokens, so charts follow dark mode and RTL / LTR with no extra work. They resize with their container, animate smoothly (and not at all when the visitor prefers reduced motion), redraw only the chart that changed, and show a tooltip, a clickable legend and number formatting out of the box.

Getting started

Load baset-ui.css (the chart styles are section 20) and baset-charts.js. Then give a chart a container and describe it. The container needs only a width; the height is an option (default depends on the type).

index.html
<link rel="stylesheet" href="assets/css/baset-ui.css">
<script src="assets/js/baset-charts.js"></script>

<div id="sales-chart"></div>

<script>
  const chart = new BasetChart('#sales-chart', {
    type: 'line',
    data: {
      labels: ['Jan', 'Feb', 'Mar', 'Apr'],
      datasets: [{ label: 'Sales', data: [120, 190, 150, 250], color: '#6366f1' }]
    },
    options: { responsive: true, animation: true, showLegend: true, showGrid: true }
  });
</script>

Without JavaScript: a container with data-bui-chart becomes a chart on its own, also when it is added to the page later. Use data-bui-labels and data-bui-data (comma separated) for one series, or data-bui-config with JSON for everything.

Chart from attributes only data-bui-chart · data-bui-labels · data-bui-data
One series, no script. Other attributes: data-bui-color, -height, -width, -grid, -legend, -values, -rounded, -smooth, -animation, -format, -locale. Set ="false" to turn a switch off.
HTML
<div data-bui-chart="bar" data-bui-labels="Mon,Tue,Wed,Thu,Fri" data-bui-data="12,19,7,15,22" data-bui-label="Tickets" data-bui-color="#6658e8" data-bui-height="220" data-bui-rounded data-bui-values></div>
Chart from a JSON attribute data-bui-config
The same object you would pass to new BasetChart, as JSON. Use single quotes around the attribute.
HTML
<div data-bui-chart="doughnut" data-bui-height="240" data-bui-config='{"data":{"labels":["Paid","Pending","Overdue"],"datasets":[{"label":"Invoices","data":[68,22,10]}]},"options":{"centerText":{"label":"Invoices","value":"100"},"legendPosition":"bottom"}}'></div>

Pie & doughnut charts

These show parts of a whole, so they use one dataset and ignore negative values. Hover a slice to move it out and see its share; the legend lists every slice with its value and percentage, and clicking an item hides that slice (the others re-balance).

Basic pie chart type: "pie"
Traffic sources. The legend here shows only names (legendValues: false).
HTML
<div id="ch-pie-basic-chart"></div>
<script>
  new BasetChart('#ch-pie-basic-chart', {
    type: 'pie',
    data: {
      labels: ['Organic search', 'Direct', 'Social', 'Email', 'Referral'],
      datasets: [{ label: 'Visits', data: [4120, 2340, 1680, 960, 740] }]
    },
    options: { legendValues: false, height: 280 }
  });
</script>

Animations

Seven drawing styles and six easings. animationStyle decides how the chart appears the first time (and when you call replay()); update() always morphs smoothly from the old values to the new ones. Everything is skipped for visitors who prefer reduced motion. To try styles with your own options and copy the code, use the Chart playground.

animationStyleWhat it doesBest for
grow (default)Bars rise from the baseline, lines grow from it, slices and rings sweep aroundAny chart
riseLike grow, but item by item: left to right (right to left in RTL)Bars and points
fadeThe finished chart fades inQuiet dashboards
slideThe finished chart slides up while it fades inCards that appear on load
zoomThe finished chart scales up from the centerPie, doughnut and gauge
revealA wipe from the start side to the end sideTime series
drawLines are drawn along their path, then areas and points appear (bars still grow)Line, area and mixed charts

JavaScript API

The constructor takes a selector or an element. Calling it again on the same element replaces the old chart. Methods return the chart, so they can be chained.

MethodWhat it does
new BasetChart(target, { type, data, options })Creates a chart. target is a selector or an element.
chart.update(data)Replaces labels and/or datasets, e.g. { labels, datasets }. Only what changed is animated. Also accepts a plain array of numbers for the first dataset.
chart.setOptions(options)Merges options. May include type to change the chart type.
chart.setColors(array | null)Sets the palette. null returns to the default palette.
chart.toggle(index, visible?)Shows or hides a series (a slice, for pie and doughnut). Without visible it flips the state, like clicking the legend.
chart.replay()Plays the first animation again, with the current animationStyle, easing and duration.
chart.resize()Redraws at the current size. Needed only if you resize the container in a way the browser does not report.
chart.destroy()Removes the chart, its listeners and its observers. The container stays.
BUI.chart.init(root) · BUI.chart.get(el)Creates charts for every [data-bui-chart] inside root; returns the chart of an element (or null).
Event (on the container)detail
bui:chart-render{ chart } — after every draw, when the animation has finished
bui:chart-click{ chart, index, label, point } — a click on a bar, point, slice or ring
Methods and events update · setOptions · toggle · destroy · events

  const target = document.querySelector('#ch-api-chart');
  const log = (text) => { document.querySelector('#ch-api-log').textContent = text; };
  let chart, smooth = false;

  const create = () => {
    chart = new BasetChart(target, {
      type: 'line',
      data: {
        labels: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'],
        datasets: [
          { label: 'This week', data: [30, 44, 38, 52, 61, 40, 35] },
          { label: 'Last week', data: [25, 36, 41, 39, 48, 33, 30] }
        ]
      },
      options: { height: 260, points: true }
    });
  };
  create();

  target.addEventListener('bui:chart-render', () => log('bui:chart-render'));
  target.addEventListener('bui:chart-click', (e) => log('bui:chart-click  →  ' + e.detail.label + ' (index ' + e.detail.index + ')'));

  document.querySelector('#ch-api-tools').addEventListener('click', (e) => {
    const act = e.target.closest('[data-act]')?.dataset.act;
    if (act === 'update') {
      const random = () => Array.from({ length: 7 }, () => Math.round(20 + Math.random() * 50));
      chart?.update({ datasets: [{ label: 'This week', data: random() }, { label: 'Last week', data: random() }] });
    }
    if (act === 'options') { smooth = !smooth; chart?.setOptions({ smooth }); }
    if (act === 'toggle') chart?.toggle(1);
    if (act === 'destroy') { chart?.destroy(); chart = null; log('destroyed'); }
    if (act === 'create' && !chart?.el) create();
  });
</script>

Dynamic data

update() keeps the chart and animates from the old values to the new ones, so it is cheap enough to call every second. Use maxPoints for a feed that always shows the latest values.

Live feed update() · maxPoints
Requests per second. Press Start for a new value every second (it stops when the tab is hidden), or add one value yourself.
HTML
<div class="bui-chart-tools" id="ch-live-tools">
  <button type="button" class="bui-btn bui-btn-sm bui-btn-primary" data-act="toggle" aria-pressed="false">Start</button>
  <button type="button" class="bui-btn bui-btn-sm bui-btn-outline" data-act="add">Add a value</button>
</div>
<div id="ch-live-chart"></div>
<script>
  const labels = Array.from({ length: 12 }, (_, i) => String(i + 1));
  const values = [118, 124, 131, 127, 139, 146, 141, 152, 148, 160, 155, 163];
  let next = 13, timer = null;

  const chart = new BasetChart('#ch-live-chart', {
    type: 'area',
    data: { labels, datasets: [{ label: 'Requests / s', data: values }] },
    options: { smooth: true, maxPoints: 12, duration: 400, height: 240, showLegend: false }
  });

  const addValue = () => {
    if (document.hidden) return;
    const last = chart.data.datasets[0].data;
    const value = Math.max(60, Math.round(last[last.length - 1] + (Math.random() - 0.45) * 24));
    chart.update({
      labels: [...chart.data.labels, String(next++)],
      datasets: [{ label: 'Requests / s', data: [...last, value] }]    // maxPoints keeps only the last 12
    });
  };

  document.querySelector('#ch-live-tools').addEventListener('click', (e) => {
    const button = e.target.closest('[data-act]');
    if (!button) return;
    if (button.dataset.act === 'add') addValue();
    if (button.dataset.act === 'toggle') {
      const on = !timer;
      timer = on ? setInterval(addValue, 1000) : (clearInterval(timer), null);
      button.setAttribute('aria-pressed', String(on));
      button.textContent = on ? 'Stop' : 'Start';
    }
  });
</script>

RTL & LTR

A chart reads the writing direction of the place it is in (dir on itself or on any parent). In RTL the horizontal axis runs right to left, the value axis moves to the right, and pies, rings and gauges start from the other side. It redraws by itself when the page direction changes: use the RTL button in the top bar.

Accessibility and performance

Every chart is an <svg role="img"> with an accessible name (ariaLabel) and a visually hidden text summary of the labels and values for screen readers. The legend items are real buttons with aria-pressed, reachable with the keyboard and with a visible focus ring. Animation is skipped when the visitor prefers reduced motion. Resizing redraws only when the size changed, and update() reuses the layout, so frequent updates stay cheap.

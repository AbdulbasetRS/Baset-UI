Toasts & notifications

Short messages and rich notifications, as static markup or from JavaScript, with six positions, timing control, stacking and RTL support.

26 examples

Toast

A toast is a short message about something that just happened. It has an optional icon, a title, a message and a close button. Use the static markup in your HTML, or create it from JavaScript with BUI.toast().

Position and stacking

Pick one of six positions with position. Toasts of the same position share one container (.bui-toast-container). Top positions stack the newest toast first, bottom positions stack the newest last. start / end follow RTL / LTR.

Six positions position option
top-start | top-center | top-end (default) | bottom-start | bottom-center | bottom-end
HTML
<div class="bui-button-row">
  <button type="button" class="bui-btn bui-btn-outline bui-btn-sm" data-bui-toast='{"type":"info","title":"top-start","message":"Shown at top-start.","position":"top-start"}'>top-start</button>
  <button type="button" class="bui-btn bui-btn-outline bui-btn-sm" data-bui-toast='{"type":"info","title":"top-center","message":"Shown at top-center.","position":"top-center"}'>top-center</button>
  <button type="button" class="bui-btn bui-btn-outline bui-btn-sm" data-bui-toast='{"type":"info","title":"top-end","message":"Shown at top-end.","position":"top-end"}'>top-end</button>
  <button type="button" class="bui-btn bui-btn-outline bui-btn-sm" data-bui-toast='{"type":"info","title":"bottom-start","message":"Shown at bottom-start.","position":"bottom-start"}'>bottom-start</button>
  <button type="button" class="bui-btn bui-btn-outline bui-btn-sm" data-bui-toast='{"type":"info","title":"bottom-center","message":"Shown at bottom-center.","position":"bottom-center"}'>bottom-center</button>
  <button type="button" class="bui-btn bui-btn-outline bui-btn-sm" data-bui-toast='{"type":"info","title":"bottom-end","message":"Shown at bottom-end.","position":"bottom-end"}'>bottom-end</button>
</div>
Stack limit max option
JavaScript
for (let i = 1; i <= 8; i++) {
  BUI.toast({ message: 'Toast ' + i, max: 3, position: 'bottom-end', duration: 6000 });
}  // only the newest 3 stay; older ones close with the reason 'overflow'

Timing

duration is in milliseconds. Use 0 (or Infinity) for a toast that stays until it is closed. The progress bar shows the remaining time, and hovering or focusing a toast pauses its timer (pauseOnHover: true).

Duration duration in ms
Sticky toasts show no progress bar and must be closed by the user or by code.

Global defaults BUI.config()
JavaScript
// change the defaults once, for every toast and notification
BUI.config({ position: 'bottom-center', max: 3 });
// or only for one kind: 'toast' | 'notify'
BUI.config({ duration: 3000, progress: true }, 'toast');
BUI.toast({ type: 'success', message: 'Uses the new defaults' });
// restore the built-in defaults for this demo
BUI.config({ position: 'top-end', max: 5 });
BUI.config({ duration: 5000 }, 'toast');

Sound

Every toast and notification plays a sound. Put your audio files (mp3, ogg or wav) in assets/sounds/. By default the toast uses notification.mp3, and so do notifications. The library does not ship audio files, so these demos stay silent until you add yours. Change the sounds in one place (BUI.sounds in baset-ui.js), turn them off with BUI.config, or set sound on a single call. Browsers only play sound after the user has interacted with the page once.

Default sounds assets/sounds/notification.mp3
Add "sound": false to the JSON (or sound: false in JavaScript) to silence one toast.
HTML
<div class="bui-button-row">
  <button type="button" class="bui-btn bui-btn-soft-success bui-btn-sm" data-bui-toast='{"type":"success","message":"Plays the sound of the success type."}'>Success</button>
  <button type="button" class="bui-btn bui-btn-soft-info bui-btn-sm" data-bui-toast='{"type":"info","message":"Plays the sound of the info type."}'>Info</button>
  <button type="button" class="bui-btn bui-btn-soft-warning bui-btn-sm" data-bui-toast='{"type":"warning","message":"Plays the sound of the warning type."}'>Warning</button>
  <button type="button" class="bui-btn bui-btn-soft-danger bui-btn-sm" data-bui-toast='{"type":"danger","message":"Plays the sound of the danger type."}'>Danger</button>
  <button type="button" class="bui-btn bui-btn-outline bui-btn-sm" data-bui-notify='{"title":"New message","message":"Plays the notify sound.","logo":"N"}'>Notification</button>
  <button type="button" class="bui-btn bui-btn-ghost bui-btn-sm" data-bui-toast='{"message":"sound: false","sound":false}'>Silent</button>
</div>
Where the files go assets/sounds/

Create the folder next to assets/css and assets/js. Names that match the default settings are picked up automatically.

The file names in assets/sounds/ are only examples. Use any names and list them in BUI.sounds.
JavaScript
assets/
├── css/
├── js/
└── sounds/
    ├── notification.mp3   <- default sound (toasts and notifications)
    ├── success.mp3        <- optional, only if you enable it in BUI.sounds
    └── error.mp3          <- optional
Sound per call sound · soundVolume
A missing file stays silent. A path that starts with / is resolved from the site root.
JavaScript
BUI.toast({ message: 'Silent', sound: false });
BUI.toast({ message: 'Default sound' });                                     // assets/sounds/notification.mp3
BUI.toast({ message: 'Quiet', soundVolume: 0.2 });                           // volume 0 to 1, default 0.5
BUI.toast({ message: 'Another file', sound: 'pop.mp3' });                    // a file inside assets/sounds/
BUI.toast({ message: 'Custom path', sound: '/media/sounds/ding.ogg' });      // any path or URL that contains /
BUI.notify({ title: 'New message', sound: 'message.mp3' });
Change sounds in one place BUI.sounds · BUI.config · BUI.mute
This demo changes the sounds for the rest of the page visit. Reload to restore the defaults.
JavaScript
// 1. Set the sounds (or edit the BUI.sounds list at the top of the sounds block in baset-ui.js)
BUI.sounds.default = 'notification.mp3';   // toasts without a type-specific sound
BUI.sounds.notify  = 'message.mp3';        // notifications
BUI.sounds.success = 'success.mp3';        // by type: success | info | warning | danger | primary
BUI.sounds.danger  = 'error.mp3';

// 2. Global switches and volume
BUI.config({ soundVolume: 0.3 });          // both kinds
BUI.config({ sound: false }, 'toast');     // toasts silent, notifications keep their sound
BUI.config({ sound: true }, 'toast');

// 3. Mute / unmute (remembered in localStorage as bui-sound)
BUI.mute(true);
BUI.mute(false);
BUI.play('success.mp3');                   // play a sound without a toast
console.log('muted?', BUI.isMuted());

Notification

A notification is richer than a toast: an image, logo or icon, a title that is limited to one line, a text limited to two lines (longer text is cut with an ellipsis), the time, and a close button. It can also show an unread dot and action buttons.

JavaScript API

Everything is available from window.BUI once baset-ui.js is loaded. The "Run" button executes the exact code shown in the card.

BUI.toast() all options
JavaScript
BUI.toast({
  type: 'success',          // success | info | warning | danger | primary | (none)
  variant: 'soft',          // soft | solid | (default)
  title: 'Saved',
  message: 'Your changes were saved.',
  icon: '✓',                // text, emoji, 'bui-icon-bold bui-icon-check', or false
  position: 'top-end',      // top|bottom + start|center|end
  duration: 5000,           // ms, 0 = sticky
  progress: true,
  pauseOnHover: true,
  closable: true,
  max: 5,
  onClick: (event, toast) => console.log('clicked'),
  onClose: (reason) => console.log('closed:', reason), // timeout | close | api | overflow | clear
});

BUI.toast('Just a message');                  // a string is the message

BUI.notify() all options
JavaScript
BUI.notify({
  type: 'info',             // optional color of the media: success | info | warning | danger | primary
  title: 'New comment from Maya',   // one line, longer titles are cut
  message: 'She mentioned you in the design review thread.', // two lines max
  image: 'data:image/svg+xml,%3Csvg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 40 40'%3E%3Crect width='40' height='40' fill='%238b80ee'/%3E%3Ccircle cx='20' cy='16' r='7' fill='%23fff'/%3E%3Cpath d='M6 40c2-11 26-11 28 0z' fill='%23fff'/%3E%3C/svg%3E',
  // logo: 'B',             // or a logo / emoji, or icon: 'bui-icon-bold bui-icon-bell'
  round: true,              // round media
  unread: true,             // unread dot before the time
  time: Date.now() - 120000, // Date | timestamp (shown as 2m ago, updates itself) | 'Yesterday' | false
  position: 'top-end',
  duration: 8000,
  onClick: () => console.log('open the comment'),
});
Notify shorthands and actions BUI.notify.success() · actions
JavaScript
BUI.notify.success('Payment received', 'Invoice #1042 was paid.', { icon: 'bui-icon-bold bui-icon-check-circle' });

BUI.notify({
  title: 'Team invitation',
  message: 'Omar invited you to join the Design workspace.',
  logo: 'O',
  duration: 0,
  actions: [
    { label: 'Accept', variant: 'primary', onClick: () => BUI.toast.success('Joined') },
    { label: 'Decline', variant: 'outline' },                 // closes the notification
    { label: 'Later', variant: 'ghost', keep: true },         // keep: stay open
  ],
});
Control a toast from code close · pause · resume
JavaScript
const t = BUI.toast({ type: 'info', title: 'Uploading…', message: 'Please wait', duration: 0 });
setTimeout(() => {
  t.close();                          // close it yourself
  BUI.toast.success('Upload finished');
}, 2500);
// t.pause() and t.resume() stop and restart the timer; t.el is the DOM element
Clear BUI.clear()
JavaScript
BUI.toast.info('One', { position: 'top-end', duration: 0 });
BUI.toast.info('Two', { position: 'bottom-end', duration: 0 });
setTimeout(() => BUI.clear('top-end'), 1200);   // only one position
setTimeout(() => BUI.clear(), 2200);            // every position

1 Introduction

BasetDataTable turns an array of objects (or an HTML table, or a JSON API) into an interactive grid. Everything is plain JavaScript and CSS: no jQuery, no CDN, no build step. It follows the Baset UI tokens, so it is light, dark, LTR and RTL out of the box. Every button does what its label says: Excel is a real .xlsx file, PDF is a real PDF file, copy / CSV / JSON / print need nothing else.

2 Installation

Copy two files into your project: the stylesheet you already have (the DataTable styles are section 21 of baset-ui.css) and baset-datatable.js. baset-ui.js is optional: the table works without it (it only lends the toast for copy messages). datatable-docs.js is used by this documentation page only; do not ship it.

index.html
<link  rel="stylesheet"  href="assets/css/baset-ui.css">
<script  src="assets/js/baset-datatable.js" defer></script>

<div  id="users-table"></div>
<script>
  window.addEventListener('DOMContentLoaded', () => {
    new BasetDataTable('#users-table', { data: [{ id: 1, name: 'Sara' }], columns: [{ data: 'id', title: 'ID' }, { data: 'name', title: 'Name' }] });
  });
</script>

Class prefix is bui-dtbl-* (the older bui-dt-* prefix belongs to the date pickers). Nothing is applied globally: every rule is scoped to .bui-dtbl. The instance is also reachable as BUI.DataTable, and BasetDataTable.get("#users-table") returns the instance of an element.

In every example on this page users is a sample array of 96 objects (id, name, email, role, department, country, salary, joined, active, status) and BUIDocs holds a few demo helpers from datatable-docs.js; use your own data. buttonIconsfalse (default), true or "only". Adds the built-in icon to every toolbar button; "only" shows just the icon (the text becomes the tooltip and aria-label). Per button: icon (built-in name, an SVG string or an icon-font class), iconOnly.

bulkBarfalse removes the "N selected / Select all N filtered" bar; selection stays visual and drives the export.

8 Instant search

The search box filters as you type. It is case-insensitive, matches parts of words, requires every word you type (multi-word), ignores accents and Arabic diacritics / alef variants (searchNormalize), and highlights matches (searchHighlight). searchDelay (ms) debounces typing: 0 for local data, 400 by default for server-side tables. searchPlaceholder changes the hint. Esc or the × button clears. columnSearch: true adds a search box under every header, and dt.columnSearch(col, text) sets one from code. Set searching: false to remove the box.

BasetDataTable.adapters.pdf = (data, options, dt) => new Promise((resolve) => {
  const body = [data.headers, ...data.rows].map((r) => r.map((c) => String(c ?? '')));

    defaultStyle: { font: 'NotoNaskhArabic', alignment: dt.dir === 'rtl' ? 'right' : 'left' },
    content: [{ text: options.title || '', style: 'h' }, { table: { headerRows: 1, body } }],
  }).getBlob(resolve);
});

<?php
namespace App\Http\Controllers;

use App\Models\User;
use Illuminate\Http\Request;

class UserController extends Controller
{
    // Columns the table may sort or filter on: never trust the client's column names.
    private const SORTABLE = ['id', 'name', 'email', 'role', 'department', 'salary', 'joined'];
    private const FILTERABLE = ['role', 'department', 'status'];

    public function index(Request $request)
    {
        $data = $request->validate([
            'page' => 'integer|min:1', 'per_page' => 'integer|min:0|max:200',
            'search' => 'nullable|string|max:100', 'sort' => 'nullable|string|max:100',
            'filter' => 'array', 'filter_logic' => 'in:and,or',
        ]);

        $q = User::query();

        if ($s = $data['search'] ?? null) {
            $q->where(fn ($w) => $w->where('name', 'like', "%$s%")->orWhere('email', 'like', "%$s%")->orWhere('role', 'like', "%$s%"));
        }

        foreach (array_intersect_key($data['filter'] ?? [], array_flip(self::FILTERABLE)) as $col => $value) {
            is_array($value) ? $q->whereIn($col, $value) : $q->where($col, $value);
        }

        $total = User::count();
        $filtered = (clone $q)->count();

        foreach (array_filter(explode(',', $data['sort'] ?? 'id')) as $part) {          // "-salary,name"
            $col = ltrim($part, '-');
            if (in_array($col, self::SORTABLE, true)) $q->orderBy($col, str_starts_with($part, '-') ? 'desc' : 'asc');
        }

        $per = $data['per_page'] ?? 10;
        $rows = $per > 0 ? $q->forPage($data['page'] ?? 1, $per)->get() : $q->get();

        return response()->json(['data' => $rows, 'meta' => ['total' => $total, 'filtered' => $filtered]]);
    }

    public function store(Request $request)   { return User::create($this->rules($request)); }
    public function update(Request $request, User $user) { $user->update($this->rules($request)); return $user; }
    public function destroy(User $user)       { $user->delete(); return response()->noContent(); }

    private function rules(Request $r): array
    {
        return $r->validate(['name' => 'required|string|min:2|max:120', 'email' => 'required|email', 'role' => 'required|string', 'salary' => 'nullable|numeric|min:0']);
    }
}

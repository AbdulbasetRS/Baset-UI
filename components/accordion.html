Options

OptionDefaultDescription
multiplefalsetrue lets several items stay open; otherwise opening one closes the others.
collapsibletrueIn single mode, false keeps one item open at all times.
openmarkupAn index, an array of indexes or 'all'. Without it, items marked .bui-accordion-open start open.
animatetruefalse opens and closes instantly.
onTogglenull(index, open, accordion), called for every item that opens or closes.

Data attributes: data-bui-multiple, data-bui-collapsible="false", data-bui-animate="false", data-bui-open="0,2" or "all".

Methods and events

MemberWhat it does
BUI.accordion(target, options)Creates an accordion (new is optional) and returns it, or the existing one for that element.
BUI.accordion.get(el), .init(root)Find an instance; start every [data-bui-accordion] inside root (done automatically on load).
open(i), close(i), toggle(i)Return true when something changed. Disabled items are skipped.
openAll(), closeAll()Open every enabled item (multiple mode only) or close everything.
enable(i), disable(i), isDisabled(i), isOpen(i)Change or read the state of one item.
openIndexes, items, countIndexes that are open, the item elements, and how many there are.

[data-bui-accordion-expand="#id"], [data-bui-accordion-collapse="#id"]Buttons that call openAll() and closeAll().

Accessibility and keyboard

Each button has aria-expanded and aria-controls; each panel is a region labelled by its button. Closed panels are hidden with visibility, so their links and fields are skipped by Tab and by screen readers. Enter and Space toggle the item, ↓ ↑ move between the buttons of the same accordion, and Home / End go to the first and last. Disabled items are skipped.

Icons

1512 icons in 6 styles: thin, light, regular, solid, bold and duotone. Use the class names, or copy the inline SVG. For CSS loaders and the animated success check see Loaders.

6 examples
Setup CSS + fonts
index.html
<link rel="stylesheet" href="assets/css/baset-ui.css">
<link rel="stylesheet" href="assets/css/baset-icons.css">
Keep assets/fonts/ next to assets/css/ — the icon fonts are loaded from there.

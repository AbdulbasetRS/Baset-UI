COMPONENT

Rich text editor

A WYSIWYG editor built on contenteditable and the Selection / Range API. Every tool works on the selection, content is sanitized, and it follows dark mode and RTL.

16 examples
Installation
<link rel="stylesheet" href="assets/css/baset-ui.css">
<script src="assets/js/baset-editor.js" defer></script>

<div data-bui-editor data-bui-placeholder="Write something…"></div>

Shortcuts: Ctrl/Cmd + B, I, U (format), K (link), Z (undo), Y or Shift+Z (redo). Tab / Shift+Tab indent list items and move between table cells. Esc closes a panel or leaves fullscreen. Pasted content from Word, Google Docs and web pages is cleaned; scripts, event handlers, javascript: links and unknown tags are removed.

1. Basic Rich Text Editor

Add data-bui-editor to any div or textarea and load baset-editor.js. The default toolbar is basic.

index.html
<div data-bui-editor data-bui-placeholder="Write something…"></div>

2. Full Toolbar

data-bui-toolbar="full" turns on every tool. The content below is the initial content, written inside the element.

Welcome to Baset Editor

This is bold, italic and underlined text with a link.

  • First item
  • Second item

A short quote.

index.html
<div data-bui-editor data-bui-toolbar="full" data-bui-height="280">
  <h2>Welcome to Baset Editor</h2><p>This is <strong>bold</strong>, <em>italic</em> and <u>underlined</u> text with a <a href="https://example.com" target="_blank" rel="noopener noreferrer">link</a>.</p><ul><li>First item</li><li>Second item</li></ul><blockquote><p>A short quote.</p></blockquote>
</div>

3. Minimal Toolbar

data-bui-toolbar="minimal": bold, italic, underline, lists and a link. Use none (or false) to hide the toolbar completely.

No toolbar: shortcuts such as Ctrl+B and Ctrl+I still work.

index.html
<div data-bui-editor data-bui-toolbar="minimal" data-bui-placeholder="Short comment…" data-bui-min-height="90"></div>

<div data-bui-editor data-bui-toolbar="none" data-bui-min-height="70">
  <p>No toolbar: shortcuts such as Ctrl+B and Ctrl+I still work.</p>
</div>

4. Custom Toolbar

Name the tools you want. A space separates tools and | starts a new group.

index.html
<div data-bui-editor data-bui-toolbar="bold italic | link image | ul ol | undo redo" data-bui-placeholder="Custom toolbar…"></div>

5. Font Family & Font Size

Lists come from attributes: data-bui-fonts (separated by |, Label=css stack is allowed) and data-bui-sizes (px).

Select a word, then choose a font or a size.

index.html
<div data-bui-editor data-bui-toolbar="fontFamily fontSize | bold italic | clear"
     data-bui-fonts="Arial|Georgia|Courier New|Verdana|Display=Manrope, sans-serif"
     data-bui-sizes="12,16,20,28,40">
  <p>Select a word, then choose a font or a size.</p>
</div>

6. Text & Background Colors

The palette is data-bui-colors (comma separated). The color picker also has a custom color input and a reset button.

Color this text or highlight it.

index.html
<div data-bui-editor data-bui-toolbar="bold | color highlight | clear"
     data-bui-colors="#6658e8,#20ad7c,#d84b5d,#f2a33a,#368de5,#20213a,#ffffff,#6b7090">
  <p>Color <strong>this text</strong> or highlight it.</p>
</div>

7. RTL Editor

data-bui-dir="rtl" sets the direction; data-bui-locale="ar" translates the toolbar. Without them the editor follows the page direction.

مرحبًا بك في المحرر

هذا محرر نصوص غني يدعم الكتابة من اليمين إلى اليسار بالكامل، بما في ذلك القوائم والاقتباسات.

  • العنصر الأول
  • العنصر الثاني
index.html
<div data-bui-editor data-bui-toolbar="full" data-bui-dir="rtl" data-bui-locale="ar" data-bui-height="260">
  <h2>مرحبًا بك في المحرر</h2><p>هذا محرر نصوص غني يدعم <strong>الكتابة من اليمين إلى اليسار</strong> بالكامل، بما في ذلك القوائم والاقتباسات.</p><ul><li>العنصر الأول</li><li>العنصر الثاني</li></ul>
</div>

8. Dark Mode

The editor uses the --bui-* tokens, so it follows .bui-dark on the page (use the theme button above). Add .bui-editor-dark to force dark on one editor, or .bui-editor-light to force light.

This editor is always dark.

index.html
<div data-bui-editor class="bui-editor-dark" data-bui-toolbar="full">
  <p>This editor is always dark.</p>
</div>

9. Readonly Editor

Content stays selectable and copyable, editing tools are disabled. Select all, HTML source and fullscreen still work.

You can read and copy this text, but not change it.

index.html
<div data-bui-editor data-bui-readonly data-bui-toolbar="full">
  <p>You can read and copy this text, but not change it.</p>
</div>

10. Disabled Editor

data-bui-disabled (or disabled) turns everything off, and the editor is skipped by Tab.

Disabled editor.

index.html
<div data-bui-editor data-bui-disabled data-bui-toolbar="basic">
  <p>Disabled editor.</p>
</div>

11. HTML Source Code View

The source tool switches to a code view. When you switch back, the HTML is sanitized and loaded into the editor.

Open the </> view, edit the HTML and come back.

index.html
<div data-bui-editor data-bui-toolbar="bold italic underline | ul ol | link | source" data-bui-height="220">
  <p>Open the <strong>&lt;/&gt;</strong> view, edit the HTML and come back.</p>
</div>

12. Editor with Initial Content

Initial content is the HTML inside the element, or the value of a textarea. A textarea keeps its name, so a normal form submit sends the HTML.






 index.html
<form id="ed-form">
  <textarea name="message" data-bui-editor data-bui-toolbar="basic" data-bui-height="180">&lt;p&gt;Hello &lt;strong&gt;team&lt;/strong&gt;,&lt;/p&gt;&lt;p&gt;This content came from a textarea.&lt;/p&gt;</textarea>
  <button class="bui-btn bui-btn-primary bui-btn-sm" type="submit" style="margin-top:10px">Show submitted value</button>
  <pre id="ed-form-out" class="bui-muted" style="white-space:pre-wrap"></pre>
</form>
<script>
  document.getElementById('ed-form').addEventListener('submit', (e) => {
    e.preventDefault();
    document.getElementById('ed-form-out').textContent = new FormData(e.target).get('message');
  });
</script>

        
13. JavaScript API Examples
Create an editor with BUI.editor(target, options). Options override attributes. exec(name, value) runs any tool from code.





  
  
  
  
  
  




 index.html
<div id="api-ed"></div>
<div class="bui-button-row" style="margin-top:10px">
  <button class="bui-btn bui-btn-soft-primary bui-btn-sm" id="api-bold">exec('bold')</button>
  <button class="bui-btn bui-btn-soft-primary bui-btn-sm" id="api-h2">exec('heading', 'h2')</button>
  <button class="bui-btn bui-btn-soft-primary bui-btn-sm" id="api-color">exec('color', '#d84b5d')</button>
  <button class="bui-btn bui-btn-soft-primary bui-btn-sm" id="api-link">exec('link', {…})</button>
  <button class="bui-btn bui-btn-soft-primary bui-btn-sm" id="api-table">exec('table', {…})</button>
  <button class="bui-btn bui-btn-soft-secondary bui-btn-sm" id="api-ro">Toggle readonly</button>
</div>
<script>
  const apiEd = BUI.editor('#api-ed', {
    toolbar: 'full', height: 200, placeholder: 'Select some text, then click a button…',
    value: '<p>Select a few words and use the buttons below.</p>'
  });
  const $id = (id) => document.getElementById(id);
  $id('api-bold').onclick = () => apiEd.exec('bold');
  $id('api-h2').onclick = () => apiEd.exec('heading', 'h2');
  $id('api-color').onclick = () => apiEd.exec('color', '#d84b5d');
  $id('api-link').onclick = () => apiEd.exec('link', { href: 'https://example.com', newTab: true });
  $id('api-table').onclick = () => apiEd.exec('table', { rows: 2, cols: 3, header: true });
  $id('api-ro').onclick = () => apiEd.setReadonly(!apiEd.o.readonly);
</script>

        
14. Getting HTML Content
getHTML() returns clean, sanitized HTML (no helper characters, empty string when the editor is empty). getText(), getLength() and isEmpty() are also available. The bui:editor-change event fires on every change.



  
Type here and watch the HTML below.





  
  






 index.html
<div id="get-ed" data-bui-editor data-bui-toolbar="basic" data-bui-height="150">
  <p>Type here and watch the HTML below.</p>
</div>
<div class="bui-button-row" style="margin-top:10px">
  <button class="bui-btn bui-btn-primary bui-btn-sm" id="get-btn">getHTML()</button>
  <span class="bui-muted" id="get-len"></span>
</div>
<pre id="get-out" style="white-space:pre-wrap;overflow:auto"></pre>
<script>
  const getEd = BUI.editor.get('#get-ed');
  const show = () => {
    document.getElementById('get-out').textContent = getEd.getHTML();
    document.getElementById('get-len').textContent = getEd.getLength() + ' characters';
  };
  document.getElementById('get-btn').onclick = show;
  document.getElementById('get-ed').addEventListener('bui:editor-change', show);
  show();
</script>

        
15. Setting Editor Content
setHTML(html) replaces the content (it is sanitized), insertHTML(html) inserts at the caret, and clear() empties the editor. Undo and redo work after each of them.





  
  
  
  




 index.html
<div id="set-ed" data-bui-editor data-bui-toolbar="basic" data-bui-height="170"></div>
<div class="bui-button-row" style="margin-top:10px">
  <button class="bui-btn bui-btn-soft-primary bui-btn-sm" id="set-a">setHTML()</button>
  <button class="bui-btn bui-btn-soft-primary bui-btn-sm" id="set-b">insertHTML()</button>
  <button class="bui-btn bui-btn-soft-danger bui-btn-sm" id="set-c">clear()</button>
  <button class="bui-btn bui-btn-soft-secondary bui-btn-sm" id="set-d">Unsafe HTML</button>
</div>
<script>
  const setEd = BUI.editor.get('#set-ed');
  document.getElementById('set-a').onclick = () => setEd.setHTML('<h3>New content</h3><p>Replaced with <em>setHTML()</em>.</p>');
  document.getElementById('set-b').onclick = () => setEd.insertHTML('<strong> [inserted] </strong>');
  document.getElementById('set-c').onclick = () => setEd.clear();
  // scripts, event handlers and javascript: links are removed
  document.getElementById('set-d').onclick = () => setEd.setHTML('<p onclick="alert(1)">Safe <a href="javascript:alert(1)">link</a><script>alert(1)<\/script></p>');
</script>

        
16. Max Length, Height & Resize
data-bui-maxlength limits the characters (typing and paste) and shows a counter. data-bui-height, -min-height and -max-height set the size, data-bui-resize (vertical, horizontal, both) adds a resize handle, and data-bui-sticky keeps the toolbar visible while scrolling.




 index.html
<div data-bui-editor data-bui-toolbar="minimal" data-bui-maxlength="120" data-bui-height="140" data-bui-resize="vertical" data-bui-placeholder="Up to 120 characters…"></div>

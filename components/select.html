Select & dropdown

A custom select menu with search, avatars and options loaded from an API with infinite scroll, and a dropdown menu for actions. Both open below or above automatically.

39 examples

Select menu

Every <select> that uses .bui-float-input, .bui-input or .bui-float-prefix opens a custom menu instead of the browser one, with no extra markup. The native <select> stays in the page and stays the source of truth: its value, change event, required, disabled, label and form submit work as before. The menu is built from its <option> items each time it opens, so options added or changed with JavaScript are always up to date. It opens below or above the field automatically, depending on the free space in the window, and it needs baset-ui.js.

Floating select and plain select no extra classes or attributes
Click a field, or focus it and press Enter, Space or an arrow key. Type a letter to jump to an option. Esc, Tab or a click outside closes the menu.

Options and values from code select.add() · select.value · BUI.select.open()
Run it twice to add more options. The menu is rebuilt from the select every time it opens, and it follows changes made while it is open.
JavaScript
const select = document.getElementById('sel-rt');
select.add(new Option('Support', 'support'));      // add an option
select.options[1].disabled = true;                // disable one
select.value = 'design';                          // set the value: the field shows it at once
BUI.select.open(select);                          // open the menu from code
setTimeout(() => select.add(new Option('Legal', 'legal')), 900);   // an option added while the menu is open appears at once
Events change · bui:select-open · bui:select-close
A choice fires input and change on the select, like the native menu does. Closing without a choice fires only bui:select-close.
JavaScript
const select = document.getElementById('sel-ev');
select.addEventListener('bui:select-open', () => BUI.toast.info('Menu opened'), { once: true });
select.addEventListener('bui:select-close', () => BUI.toast.warning('Menu closed'), { once: true });
select.addEventListener('change', () => BUI.toast.success('Selected: ' + select.value), { once: true });
BUI.select.open(select);

Search in the menu

Add data-bui-search to a select and a search box becomes the first item of the menu. It filters while you type, ignores case and accents, highlights the match, hides groups with no result, and shows a message when nothing matches. The search also reads the option description and data-search keywords. Focus goes to the search box when the menu opens; the arrow keys, Enter and Esc still work from there.

Options from an API

Load the options from a URL, page by page. The menu asks for the first page when it opens, asks for the next page when you scroll to the end of the list (infinite scroll), and asks again from page 1 when you type in the search box (after a short delay, and an older request is cancelled). When you choose an item, it becomes a real <option> of the select, so select.value, the form and the validation keep working. The data of these examples is in assets/data/users.json (120 users).

A JSON file data-bui-url="assets/data/users.json"
A static file is the simplest source. When the response is a plain array, the select downloads it once and does the search and the pages in the browser (10 at a time), so it works on any static host. Open the menu and scroll: the log shows what was requested. The path is relative to the page, like an image src.
 HTML
<div style="display:grid;gap:18px;max-width:420px">
<div class="bui-float bui-float-select">
  <select class="bui-float-input" id="rm-1" data-bui-url="../assets/data/users.json" data-bui-rich data-bui-per-page="10" data-bui-value-key="id" data-bui-label-key="name" data-bui-description-key="email" data-bui-image-key="avatar">
    <option value=""></option>
  </select>
  <label class="bui-float-label" for="rm-1">User</label>
</div>
</div><pre class="bui-net-log" aria-label="Requests sent by the page" style="margin-top:14px"></pre>

Your own loader BUI.select.remote(select, { load })

  
  

Use your own function when you need a token, a POST request, GraphQL, or a different response shape. load() receives the search text, the page number (from 1) and an AbortSignal, and returns the items and whether there are more pages.
 JavaScript
const select = document.getElementById('rm-jssel');
BUI.select.remote(select, {
  perPage: 8,
  debounce: 250,                               // ms after the last key
  async load({ search, page, perPage, signal }) {
    const url = '/mock-api/users?search=' + encodeURIComponent(search) + '&page=' + page + '&per_page=' + perPage;
    const res = await fetch(url, { signal, headers: { Authorization: 'Bearer <token>' } });
    if (!res.ok) throw new Error('HTTP ' + res.status);        // shows the Retry row
    const json = await res.json();
    return {
      items: json.data.map((u) => ({ value: u.id, label: u.name, description: u.email, image: u.avatar })),
      hasMore: json.meta.has_more,                // false stops the infinite scroll
    };
  },
});
BUI.select.open(select);

Dropdown menu
A button that opens a list of actions. Wrap a toggle (data-bui-dropdown-toggle) and a .bui-dropdown-menu in .bui-dropdown. The menu is shown in the top layer, so no container clips it, and it opens below or above the button automatically (and stays inside the window at the sides) with the same placement as the select menu. It closes on a click outside, on Esc, on Tab, and after you choose an item. It is keyboard friendly: arrows, Home, End, type-to-jump, Enter and Space. It needs baset-ui.js.

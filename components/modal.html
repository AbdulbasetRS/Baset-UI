Modal

Dialogs, confirmations, forms and drawers built on the native dialog element, from plain HTML or the JavaScript API with Promises.

25 examples

Basic

A modal is a native <dialog class="bui-modal"> with a header, a body and a footer. Open it with data-bui-modal-open="#id" and close it with data-bui-modal-close on any button inside it. No JavaScript to write. The backdrop, focus trap, Esc key and animation are built in.

Basic modal data-bui-modal-open · data-bui-modal-close

Modal title

Modals focus attention on one task. The page behind is inert, Esc closes the modal, focus is trapped inside, and it returns to the button that opened it.

HTML
<button type="button" class="bui-btn bui-btn-primary" data-bui-modal-open="#m-basic">Open modal</button>
<dialog class="bui-modal" id="m-basic" aria-labelledby="m-basic-title">
  <div class="bui-modal-header"><h3 class="bui-modal-title" id="m-basic-title">Modal title</h3><button type="button" class="bui-modal-close" aria-label="Close" data-bui-modal-close>×</button></div>
  <div class="bui-modal-body"><p>Modals focus attention on one task. The page behind is inert, <b>Esc</b> closes the modal, focus is trapped inside, and it returns to the button that opened it.</p></div>
  <div class="bui-modal-footer"><button type="button" class="bui-btn bui-btn-outline" data-bui-modal-close>Cancel</button>
    <button type="button" class="bui-btn bui-btn-primary" data-bui-modal-close>Save changes</button></div>
</dialog>

JavaScript API

Everything lives in BUI.modal. confirm, alert, prompt and show create the modal for you and return a Promise, so you can use await. The "Run" button executes the exact code shown in the card.

Open and close by code BUI.modal.open() · close()
Uses the Basic modal above. Opening an open modal, or closing a closed one, does nothing.
JavaScript
BUI.modal.open('m-basic');                 // an id (with or without #) or the element
setTimeout(() => BUI.modal.close('m-basic', 'timeout'), 2000);   // the 2nd argument becomes dialog.returnValue
BUI.modal.confirm() Promise
JavaScript
const ok = await BUI.modal.confirm({
  type: 'danger',                    // warning (default) | danger | info | success
  title: 'Delete this file?',
  message: 'You cannot undo this action.',
  confirmText: 'Delete',
  cancelText: 'Cancel',
});
if (ok) BUI.toast.success('File deleted');
else BUI.toast.info('Cancelled');          // Esc, backdrop click and Cancel all give false
Confirm with loading onConfirm returns a Promise
While onConfirm runs, the buttons are disabled and a spinner shows. The modal closes when the Promise resolves.
JavaScript
const ok = await BUI.modal.confirm({
  type: 'danger',
  title: 'Delete account?',
  message: 'Your data will be removed from our servers.',
  confirmText: 'Delete',
  onConfirm: async () => {
    await new Promise((resolve) => setTimeout(resolve, 1500));   // your fetch() call
    // return false here to keep the modal open (for example after an error)
  },
});
if (ok) BUI.toast.success('Account deleted');
BUI.modal.alert() one button
JavaScript
await BUI.modal.alert({
  type: 'success',                   // info (default) | success | warning | danger
  title: 'Profile updated',
  message: 'Your changes are live.',
  okText: 'Great',
});
BUI.toast.info('The alert was closed');
BUI.modal.prompt() Promise
Pressing Enter in the field confirms. inputType: "email" | "number" | ... and rows: 4 (a textarea) are supported.
JavaScript
const name = await BUI.modal.prompt({
  title: 'Rename file',
  label: 'File name',
  value: 'report.pdf',
  placeholder: 'Type a name',
  required: true,                    // blocks empty values
  confirmText: 'Rename',
});
if (name !== null) BUI.toast.success('Renamed to ' + name);   // null = cancelled
BUI.modal.show() custom actions
JavaScript
const choice = await BUI.modal.show({
  icon: 'warning',
  title: 'Save before closing?',
  message: 'Your changes will be lost if you do not save them.',
  size: 'sm',
  static: true,                       // ignore Esc and backdrop clicks
  actions: [
    { label: 'Discard', value: 'discard', variant: 'ghost' },
    { label: 'Cancel', value: 'cancel' },
    { label: 'Save', value: 'save', variant: 'primary', autofocus: true },
  ],
});
BUI.toast.info('You chose: ' + choice);
show() without an icon header, form-like body
JavaScript
const answer = await BUI.modal.show({
  title: 'Share feedback',
  message: 'Tell us what we can improve.',
  position: 'end',                    // top | bottom | start | end (a drawer)
  closable: true,                     // the × button in the header (default)
  actions: [
    { label: 'Later', value: 'later' },
    { label: 'Send', value: 'send', variant: 'success' },
  ],
});
console.log(answer);                    // 'later' | 'send' | null when dismissed
Events bui:modal-open · bui:modal-close
The native close and cancel events work too. dialog.returnValue holds the value of the button or the argument of close().
JavaScript
const dialog = document.getElementById('m-basic');
dialog.addEventListener('bui:modal-open', () => BUI.toast.info('Opened'), { once: true });
dialog.addEventListener('bui:modal-close', (e) => BUI.toast.success('Closed with: ' + e.detail.returnValue), { once: true });
BUI.modal.open(dialog);
setTimeout(() => BUI.modal.close(dialog, 'demo'), 1500);

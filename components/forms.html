Floating label

Wrap an input and its label in .bui-float. The label sits inside the field and floats up on focus or when the field has a value. Always add placeholder=" " (one space): the CSS uses :placeholder-shown to know if the field is empty. Pure CSS, no JavaScript.

Validation states

Add a state class to .bui-float: -error, -success, -warning, -notice (blue) or -loading. Put a message in the field and an i button at its end: clicking the i opens the message under the field (click again, click outside or press Esc to close). The button works with baset-ui.js.

Error .bui-float-error
Enter a valid email address, like you@example.com.
Your password must have at least 8 characters.
Click the i at the end of each field.

Password fields

Add a show / hide button with .bui-float-toggle (an eye drawn in CSS, no icon font needed). It switches the input between password and text, keeps the caret, and updates aria-pressed and aria-label. It sits next to the i button, and it needs baset-ui.js.

Show / hide password .bui-float-toggle

The state class and the i message are set for you, from data-error-* and data-success. On submit, the first invalid field gets focus and its message opens. Try submitting the empty forms.

JavaScript API

Set a state from your own code, for example after a server check. BUI.float.setState(field, state, message, { open }) takes the input (or its selector) and does everything: state class, message, i button and aria-*. The "Run" button executes the code shown in the card.

Check a username on the server loading → error | success
Edit the value, then run it again. The message of a state is created for you when the field has none.
JavaScript
const input = document.getElementById('api-user');
BUI.float.setState(input, 'loading');                       // spinner instead of the i
await new Promise((resolve) => setTimeout(resolve, 1200));  // your fetch() call
const taken = ['admin', 'baset'].includes(input.value.trim().toLowerCase());
if (taken) BUI.float.setState(input, 'error', 'This username is already taken.', { open: true });
else BUI.float.setState(input, 'success', 'This username is available.');
All states from code setState · open · clear
BUI.float.open(field, false) closes a message, BUI.float.clear(field) removes the state and the i button it created.
JavaScript
const input = document.getElementById('api-demo');
const steps = [
  ['error', 'The value is not valid.'],
  ['warning', 'This value is unusual.'],
  ['notice', 'Remember to save your changes.'],
  ['success', 'Saved.'],
];
for (const [state, message] of steps) {
  BUI.float.setState(input, state, message, { open: true });
  await new Promise((resolve) => setTimeout(resolve, 1400));
}
BUI.float.clear(input);                                      // back to the neutral field
Validate a form and listen to the result BUI.float.validate() · bui:valid · bui:invalid
Leave the email empty, run the code and see the warning. Type a valid email, run it again.
JavaScript
const form = document.getElementById('api-form');

form.addEventListener('bui:valid', (event) => {
  event.preventDefault();                       // stop the normal submit, then send with fetch()
  BUI.toast.success('Valid: sending the form');
}, { once: true });
form.addEventListener('bui:invalid', (event) => {
  BUI.toast.warning('Fix the highlighted field');   // event.detail.field is the first invalid input
}, { once: true });

form.requestSubmit();                           // validates and fires one of the events
// BUI.float.validate(form) returns true or false without submitting; BUI.float.reset(form) clears every state

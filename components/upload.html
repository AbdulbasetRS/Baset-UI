File upload

An accessible file picker with drag-and-drop, image previews, validation, and the original native input.

Drag & dropImage previewsValidationRTL ready
01 · INTERACTIVE

Image and document dropzone

Try real local files. The demo does not send files to a server.

Multiple filesPNG, JPG, WebP, PDF · max 3 files · 5 MB each

Accepted: PNG, JPG, GIF, WebP and PDF. Use Ctrl/Cmd to select multiple files.

No files selected
Demonstration only · no network request
HTML
<div class="bui-upload" data-bui-upload data-max-files="3" data-max-size="5242880">
  <input class="bui-upload-input" id="attachments" name="attachments[]"
    type="file" accept="image/png,image/jpeg,application/pdf" multiple>
  <label class="bui-upload-dropzone" for="attachments" tabindex="0">
    <span class="bui-upload-title">Drop files here, or <span>browse</span></span>
    <span class="bui-upload-subtitle">Up to 3 files · 5 MB each</span>
  </label>
  <div class="bui-upload-feedback" aria-live="polite"></div>
  <div class="bui-upload-files"></div>
</div>

04 · API

Attributes and methods

OptionPurpose
acceptNative filter using extensions, MIME types or wildcards like image/*. No file types are assumed by default.
id, name, multiple, required, disabled, capture, formKeep these native attributes on the input; normal multipart forms remain supported.
data-max-files / data-min-filesOptional file count limits.
data-max-size / data-min-sizePer-file byte limits.
data-error-language="ar"Arabic validation messages. Otherwise uses the page language.
.bui-upload-sm / .bui-upload-lgSmall, medium (default) and large presentations.
BUI.upload.validate(input)Validate current selection and show feedback.
BUI.upload.clear(input)Clear the input and selected-file list.
BUI.upload.setStatus(input, status, message)Set real integration status to uploading, success or error. Selection alone never means upload success.
bui:upload-changeBubbling custom event with selected files in event.detail.files.
Customization tokens
.my-upload {
  --bui-upload-accent: var(--bui-primary-base);
  --bui-upload-border: var(--bui-line);
  --bui-upload-surface: var(--bui-surface);
  --bui-upload-radius: 1rem;
  --bui-upload-dropzone-min-height: 12rem;
  --bui-upload-icon-size: 2rem;
  --bui-upload-gap: .75rem;
}

The component inherits light/dark theme colors and RTL/LTR direction from its surrounding page. Use your server framework to validate file content, size and authorization again on upload.

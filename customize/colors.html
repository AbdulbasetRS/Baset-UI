Colorsالألوان

The color tokens that exist today, their light and dark values, and how to use and change them. For the full token reference see CSS Variables under Getting Started; for measured contrast see Accessibility.

رموز الألوان الموجودة اليوم، وقيمها في الفاتح والداكن، وكيف تستخدمها وتغيّرها. للمرجع الكامل للـ tokens راجع متغيرات CSS في قسم البدء، وللتباين المقيس راجع إمكانية الوصول.

What this page coversما تغطيه هذه الصفحة

Baset UI has one color palette: the set of 19 color tokens below. There are no color utility classes (such as text or background helpers), no secondary color, and no tint/shade scale (for example a 100–900 ramp). Those are listed as not implemented at the end of the page.

لدى Baset UI لوحة ألوان واحدة: مجموعة 19 token لونيًّا أدناه. لا توجد أصناف مساعدة للألوان (مثل مساعدات النص والخلفية)، ولا لون ثانوي، ولا تدرّجات (مثل 100–900). وهذه مدرجة ضمن غير المنفَّذ في آخر الصفحة.

Default color paletteلوحة الألوان الافتراضية

Each swatch is painted with its own token, so it follows the theme you have selected in the top bar. Switch the theme and watch the palette change.

كل مربع مرسوم بالـ token الخاص به، لذلك يتبع الثيم الذي اخترته في الشريط العلوي. بدّل الثيم وراقب تغيّر اللوحة.

Text inside a tinted -subtle boxنص داخل صندوق -subtle--bui-color-textSee the warning below.راجع التنبيه أدناه.

Do not put semantic-colored text on its own subtle backgroundلا تضع نصًّا بلون دلالي على خلفيته الخفيفة

In the light theme, --bui-color-success on --bui-color-success-subtle measures 4.37:1 and --bui-color-warning on --bui-color-warning-subtle measures 4.41:1, both under 4.5:1 for normal-size text. Use --bui-color-text for the text inside such boxes and use the semantic color for the border or an icon. Danger, info and primary pass on their subtle backgrounds.

في الثيم الفاتح تبلغ نسبة --bui-color-success على --bui-color-success-subtle ‏4.37:1 و--bui-color-warning على --bui-color-warning-subtle ‏4.41:1، وكلتاهما أقل من 4.5:1 للنص بالحجم العادي. استخدم --bui-color-text للنص داخل هذه الصناديق، واستخدم اللون الدلالي للحد أو الأيقونة. أما الخطر والمعلومة والأساسي فتنجح على خلفياتها الخفيفة.

Never communicate state by color alone: add a word or an icon, as the status labels on these pages do.

لا تنقل الحالة بالألوان وحدها: أضف كلمة أو أيقونة، كما تفعل وسوم الحالة في هذه الصفحات.

Color customizationتخصيص الألوان

Colors are changed by overriding tokens, not by editing baset-ui.css. Override each token in :root (light) and in .bui-dark (dark). A full walkthrough with an interactive preview is in CSS Variables, How to customize variables; creating a whole theme is covered in Color Modes.

تُغيَّر الألوان بتعديل الـ tokens وليس بتعديل baset-ui.css. عدّل كل token في :root (الفاتح) وفي .bui-dark (الداكن). شرح كامل مع معاينة تفاعلية في متغيرات CSS، طريقة تخصيص المتغيرات، وإنشاء ثيم كامل في أوضاع الألوان.

Change the brand colorتغيير لون العلامة

  1. Pick a primary for each theme. A color that works on a light page is usually too dark on a dark page, so choose a lighter variant for dark.اختر لونًا أساسيًّا لكل ثيم. اللون المناسب للصفحة الفاتحة يكون عادة داكنًا جدًّا على الصفحة الداكنة، فاختر درجة أفتح للداكن.
  2. Set --bui-color-primary, --bui-color-primary-hover, --bui-color-on-primary and --bui-color-primary-subtle together.عيّن --bui-color-primary و--bui-color-primary-hover و--bui-color-on-primary و--bui-color-primary-subtle معًا.
  3. Measure on-primary on primary (4.5:1 for text) and primary on surface (4.5:1 when it colors text, 3:1 for a non-text indicator).قِس on-primary على primary (‏4.5:1 للنص) وprimary على surface (‏4.5:1 إن لوّن نصًّا، و3:1 لمؤشر غير نصي).
:root {
  --bui-color-primary: #7c3aed;
  --bui-color-primary-hover: #6d28d9;
  --bui-color-on-primary: #ffffff;
  --bui-color-primary-subtle: #ede9fe;
}
.bui-dark {
  --bui-color-primary: #a78bfa;
  --bui-color-primary-hover: #c4b5fd;
  --bui-color-on-primary: #1e1b4b;
  --bui-color-primary-subtle: #2e2a5c;
}

Use a token

Always use the variables instead of hard-coded hex values, so dark mode and re-theming keep working.

my-styles.css
.my-card {
  background: var(--bui-surface);
  color: var(--bui-ink);
  border: 1px solid var(--bui-line);
  border-radius: var(--bui-radius);
}
.my-card a { color: var(--bui-primary-fg); }

Change a color

Re-declare the token on :root after baset-ui.css. The Theme page explains every token, and the Token playground generates the CSS for you.

theme.css
/* load this AFTER baset-ui.css */
:root {
  --bui-primary-base: var(--bui-green-500);
}

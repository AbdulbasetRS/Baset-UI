Use a token

Always use the variables instead of hard-coded hex values, so dark mode and re-theming keep working.

my-styles.css
.my-card {
  background: var(--bui-surface);
  color: var(--bui-ink);
  border: 1px solid var(--bui-line);
  border-radius: var(--bui-radius);
}
.my-card a { color: var(--bui-primary); }

Override the defaults

Re-declare any token after baset-ui.css. Try it live in the Playground.

theme.css
/* load this AFTER baset-ui.css */
:root {
  --bui-primary: #0d9488;
  --bui-primary-dark: #0f766e;
  --bui-primary-soft: #ccfbf1;
  --bui-primary-text: #0f766e;
}

/* optional: dark mode values */
:root.bui-dark {
  --bui-primary-soft: #134e4a;
  --bui-primary-text: #5eead4;
}

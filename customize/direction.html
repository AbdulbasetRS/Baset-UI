Direction (RTL / LTR)

Baset UI follows the nearest dir attribute. Switch the whole documentation between right-to-left and left-to-right, and see how components mirror.

The RTL / LTR button in the top bar (next to the theme toggle) and the buttons above change dir on the whole page (sidebar included) and remember the choice in localStorage (bui-dir). The two panels below are always shown in a fixed direction, so you can compare them side by side.

Set the direction of the page

index.html
<html lang="ar" dir="rtl">
  <body>
    <!-- everything inside follows right-to-left -->
  </body>
</html>

Set it for one component or one value

Prefer dir on the smallest element that needs it. Keep code, URLs and CSS variable names in dir="ltr" inside Arabic text instead of forcing the whole component to LTR.

index.html
<div class="bui-card" dir="rtl">
  <p>مرحبا بكم</p>
  <code dir="ltr">--bui-primary</code>
</div>

Direction toggle (optional JS)

assets/js/baset-ui.js flips the direction from any element with id="dirToggle", and also handles any element with data-bui-dir="ltr" or data-bui-dir="rtl". It sets dir on <html> and saves it as bui-dir. Without the script, set dir by hand and everything still works.

baset-ui.js
/* Any element with data-bui-dir sets the direction of the page. */
<button class="bui-btn bui-btn-outline" data-bui-dir="ltr">LTR</button>
<button class="bui-btn bui-btn-outline" data-bui-dir="rtl">RTL</button>

/* The choice is saved in localStorage under "bui-dir". To apply it before paint, add to <head>: */
<script>try{var d=localStorage.getItem('bui-dir');if(d==='rtl'||d==='ltr')document.documentElement.dir=d}catch(e){}</script>

Write direction-safe CSS

Baset UI uses logical properties, so spacing, borders and alignment flip with dir. Do the same in your own styles.

your-styles.css
.my-card {
  margin-inline-start: 12px;      /* not margin-left */
  padding-inline: 16px;           /* not padding-left/right */
  border-inline-start: 3px solid var(--bui-primary);
  text-align: start;             /* not left */
  inset-inline-end: 0;             /* not right: 0 */
}
/* Direction arrows: mirror them only in RTL */
[dir="rtl"] .my-arrow { transform: scaleX(-1); }

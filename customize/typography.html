Typographyالخطوط

The typography tokens that exist today: two font stacks, eight sizes, four weights and two line heights, and how to change them.

tokens الخطوط الموجودة اليوم: مجموعتا خطوط، وثمانية أحجام، وأربعة أوزان، وارتفاعا سطر، وكيف تغيّرها.

Tokens, not classestokens وليست أصنافًا

Baset UI defines typography as CSS variables. It does not style <h1>–<h6>, <p> or any element, and it ships no text utility classes yet. You apply the tokens in your own CSS with var().

تعرّف Baset UI الخطوط كمتغيرات CSS. ولا تنسّق <h1>–<h6> ولا <p> ولا أي عنصر، ولا تشحن أصناف نصوص مساعدة بعد. تطبّق الـ tokens في CSS الخاص بك بـ var().

Which font you actually seeأي خط تراه فعليًّا

A system font stack renders differently on each operating system, so appearance and Arabic glyph shapes vary between devices. Rendering has not been compared across platforms.

مجموعة خطوط النظام تُعرض بشكل مختلف على كل نظام تشغيل، لذا يختلف المظهر وأشكال الحروف العربية بين الأجهزة. ولم تُقارَن النتائج بين المنصات.

Arabic needs more roomالعربية تحتاج مساحة أكبر

Arabic letters have taller ascenders, descenders and dots. This documentation site raises the base line height to 1.85 for Arabic (html[lang="ar"] body). Baset UI has no such rule, so add one if your content is Arabic.

للحروف العربية صواعد ونوازل ونقاط أعلى. يرفع موقع التوثيق هذا ارتفاع السطر الأساسي إلى 1.85 للعربية (html[lang="ar"] body). ولا توجد قاعدة كهذه في Baset UI، فأضفها إن كان محتواك عربيًّا.

Text utilitiesأصناف النصوص المساعدة

Not implemented yetغير منفَّذ بعد No bui- text utility classes exist (size, weight, alignment, transform, truncation). Do not use names such as bui-text-lg or bui-fw-bold; they are not defined. The project architecture also says the core should not become a large utility framework, so utilities will be added only when components need them.

Not implemented yetغير منفَّذ بعد لا توجد أي أصناف نصوص مساعدة بالبادئة bui- (الحجم والوزن والمحاذاة والتحويل والاقتطاع). لا تستخدم أسماء مثل bui-text-lg أو bui-fw-bold؛ فهي غير معرَّفة. كما تنص بنية المشروع على ألا يتحول الـ core إلى إطار أدوات ضخم، لذا ستُضاف الأدوات فقط عند حاجة المكونات إليها.

Until then, write a class of your own that reads the tokens:

إلى ذلك الحين اكتب صنفًا خاصًّا بك يقرأ الـ tokens:

.heading-lg {
  font-size: var(--bui-font-size-2xl);
  font-weight: var(--bui-font-weight-semibold);
  line-height: var(--bui-line-height-tight);
}

.prose p {
  font-size: var(--bui-font-size-md);
  line-height: var(--bui-line-height-base);
  text-align: start; /* logical: follows the direction */
}

Prefer text-align: start and end to left and right so alignment follows the direction.

فضّل text-align: start وend على left وright لتتبع المحاذاة الاتجاه.

Typography customizationتخصيص الخطوط

Use your own fontاستخدام خط خاص بك

Load the font yourself, then point the token at it. Keep the original stack as the fallback:

حمّل الخط بنفسك ثم وجّه الـ token إليه. وأبقِ المجموعة الأصلية كبديل:

@font-face {
  font-family: "My Font";
  src: url("fonts/my-font.woff2") format("woff2");
  font-display: swap;
}

:root {
  --bui-font-family-base: "My Font", system-ui, -apple-system, "Segoe UI", Tahoma, "Noto Sans Arabic", sans-serif;
}
  • Check that the font supports Arabic if your content is Arabic; otherwise the browser falls back for those letters.تأكد أن الخط يدعم العربية إن كان محتواك عربيًّا؛ وإلا استخدم المتصفح بديلًا لتلك الحروف.
  • A web font adds a download. Baset UI does not load one for you.الخط المحمَّل من الويب يضيف تنزيلًا. ولا تحمّل Baset UI أيّ خط عنك.

Change the size scaleتغيير سلّم الأحجام

:root {
  --bui-font-size-md: 1.0625rem;  /* slightly larger body text */
  --bui-line-height-base: 1.7;
}

/* Arabic content */
:lang(ar) {
  --bui-line-height-base: 1.85;
}

These overrides are not theme-dependent, so one :root block is enough (unlike colors).

هذه التعديلات لا ترتبط بالثيم، لذا تكفي كتلة :root واحدة (بخلاف الألوان).

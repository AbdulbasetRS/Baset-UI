Typography and shape

The font families, base font size, corner radius and shadow, and how to change them.

--bui-font-body
The quick brown fox jumps over the lazy dog
DM Sans · body text · weights 400, 500, 600, 700
--bui-font-heading
Build beautiful interfaces
Manrope · headings, numbers, brand · weights 400 to 800
--bui-radius
1rem (= --bui-radius-5) · cards and surfaces. Buttons and inputs use --bui-radius-3.
--bui-shadow
0 12px 32px, colored by --bui-shadow-color (light and dark)

Defaults

baset-ui.css
:root {
  --bui-font-body: 'DM Sans', sans-serif;
  --bui-font-heading: Manrope, sans-serif;
  --bui-font-size: .875rem;
}
:root {
  --bui-radius-3: .5rem;   /* buttons, inputs */
  --bui-radius-5: 1rem;    /* cards, surfaces */
  --bui-radius: var(--bui-radius-5);
  --bui-shadow: 0 12px 32px var(--bui-shadow-color);
}

Use another font (for example Cairo for Arabic)

theme.css
@import url('https://fonts.googleapis.com/css2?family=Cairo:wght@400;600;700&display=swap');

:root {
  --bui-font-body: 'Cairo', sans-serif;
  --bui-font-heading: 'Cairo', sans-serif;
}

Color Modesأوضاع الألوان

How Baset UI represents light and dark modes with tokens, how a page switches between them, how to remember the choice, and how to build your own theme.

كيف تمثّل Baset UI الوضعين الفاتح والداكن بالـ tokens، وكيف تبدّل الصفحة بينهما، وكيف تتذكر الاختيار، وكيف تبني ثيمك الخاص.

CSS only, no JavaScriptCSS فقط، بلا جافاسكربت

The library provides the token sets and the bui-dark / bui-light classes. It does not ship a theme switcher, a storage helper or a BUI theme API: no script exists yet. The switching and persistence code below is code you write, and the platform APIs it uses are standard browser APIs.

توفّر المكتبة مجموعات الـ tokens والصنفين bui-dark وbui-light. لكنها لا تشحن مبدّل ثيم ولا أداة تخزين ولا واجهة BUI للثيمات: لا يوجد أي سكربت بعد. شيفرة التبديل والحفظ أدناه تكتبها أنت، وهي تستخدم واجهات متصفح قياسية.

Light modeالوضع الفاتح

Light is the default. Its tokens are declared on :root and on .bui-light, so a page without any class is light, and a .bui-light region keeps the light look even inside a dark page.

الفاتح هو الافتراضي. تُعلَن tokens الخاصة به على :root وعلى .bui-light، فالصفحة بلا أي صنف فاتحة، والمنطقة .bui-light تحافظ على المظهر الفاتح حتى داخل صفحة داكنة.

Dark modeالوضع الداكن

Dark is activated by adding bui-dark to <html> (the whole page) or to any element (one region). It redefines the color and shadow tokens and sets color-scheme: dark so that native controls and scrollbars follow.

يُفعَّل الداكن بإضافة bui-dark إلى <html> (الصفحة كلها) أو إلى أي عنصر (منطقة واحدة). يعيد تعريف tokens الألوان والظلال ويضبط color-scheme: dark لتتبعه عناصر النماذج الأصلية وأشرطة التمرير.

The four boxes below are always shown in the same mode whatever the page theme is, because each one is scoped with its own class. The last two use a custom theme, described further down.

الصناديق الأربعة أدناه تُعرض دائمًا بالوضع نفسه مهما كان ثيم الصفحة، لأن كلًّا منها محصور بصنف خاص به. والأخيران يستخدمان ثيمًا مخصصًا يُشرح لاحقًا.

Theme switchingتبديل الثيم

Switching is adding or removing bui-dark. A minimal toggle, with the pressed state exposed to assistive technology:

التبديل هو إضافة bui-dark أو إزالتها. مبدّل بسيط مع إتاحة حالة الضغط لتقنيات المساعدة:

<button type="button" id="theme-toggle" aria-pressed="false">Dark mode</button>

var root = document.documentElement;
var button = document.getElementById('theme-toggle');

function setDark(on) {
  root.classList.toggle('bui-dark', on);
  button.setAttribute('aria-pressed', String(on));
}

button.addEventListener('click', function () {
  setDark(!root.classList.contains('bui-dark'));
});

To follow the operating system, read prefers-color-scheme and react when it changes:

لاتباع نظام التشغيل اقرأ prefers-color-scheme وتفاعل عند تغيّره:

var query = window.matchMedia('(prefers-color-scheme: dark)');
setDark(query.matches);
query.addEventListener('change', function (event) { setDark(event.matches); });

This is the same mechanism this documentation site uses for its theme button.

هذه هي الآلية نفسها التي يستخدمها زر الثيم في موقع التوثيق هذا.

Theme persistenceحفظ الثيم

Remembering the choice is also your code. Two rules avoid the common problems: wrap storage in try/catch because it can be blocked or unavailable, and apply the class in a small script in <head> so the page does not flash the wrong theme before it paints.

حفظ الاختيار أيضًا من شيفرتك. قاعدتان تتجنبان المشكلات الشائعة: لفّ التخزين بـ try/catch لأنه قد يكون محظورًا أو غير متاح، وطبّق الصنف في سكربت صغير داخل <head> كي لا تومض الصفحة بالثيم الخطأ قبل الرسم.

<head>
  <script>
    (function () {
      var saved = null;
      try { saved = localStorage.getItem('bui-theme'); } catch (e) {}
      var dark = saved === 'dark' ||
        (saved !== 'light' && window.matchMedia('(prefers-color-scheme: dark)').matches);
      document.documentElement.classList.toggle('bui-dark', dark);
    })();
  </script>
  <link rel="stylesheet" href="assets/css/baset-ui.css">
</head>

function saveTheme(mode) { // 'light' | 'dark'
  try { localStorage.setItem('bui-theme', mode); } catch (e) { /* ignore */ }
}

Key nameاسم المفتاح

bui-theme is the key the project has used so far. You are free to use your own key in your own site. Since no library script reads it, nothing breaks if you do.

bui-theme هو المفتاح الذي استخدمه المشروع حتى الآن. يمكنك استخدام مفتاحك الخاص في موقعك. وبما أنه لا يوجد سكربت في المكتبة يقرؤه فلن ينكسر شيء.

Custom theme creationإنشاء ثيم مخصص

A custom theme is a class that overrides tokens. Name it yourself; it is not a Baset UI class. Set the light values on the class and the dark values on the class combined with .bui-dark:

الثيم المخصص صنف يعدّل الـ tokens. سمِّه بنفسك؛ فهو ليس صنفًا من Baset UI. عيّن القيم الفاتحة على الصنف، والقيم الداكنة على الصنف مع .bui-dark:

/* my-themes.css, loaded after baset-ui.css */
.theme-ocean {
  --bui-color-bg: #f4f9fc;
  --bui-color-surface: #ffffff;
  --bui-color-text: #10222d;
  --bui-color-text-muted: #4a5f6c;
  --bui-color-border: #d3e2ec;
  --bui-color-primary: #0b5f94;
  --bui-color-primary-hover: #084a74;
  --bui-color-on-primary: #ffffff;
  --bui-color-primary-subtle: #dcecf7;
}

.theme-ocean.bui-dark {
  --bui-color-bg: #0b1820;
  --bui-color-surface: #11222c;
  --bui-color-text: #e6f0f6;
  --bui-color-text-muted: #9db3c1;
  --bui-color-border: #223743;
  --bui-color-primary: #5db8ee;
  --bui-color-primary-hover: #8fcff5;
  --bui-color-on-primary: #04202f;
  --bui-color-primary-subtle: #12354a;
}
  • .theme-ocean.bui-dark is more specific than .bui-dark, so it wins regardless of load order..theme-ocean.bui-dark أكثر خصوصية من .bui-dark، فيفوز بغض النظر عن ترتيب التحميل.
  • Override only what you need. Tokens you do not set keep the values of the base light or dark theme.عدّل ما تحتاجه فقط. الـ tokens التي لا تضبطها تحتفظ بقيم الثيم الفاتح أو الداكن الأساسي.
  • Apply it to <html> or to a region: <html class="theme-ocean bui-dark">.طبّقه على <html> أو على منطقة: <html class="theme-ocean bui-dark">.
  • Measure contrast of every pair you changed, in both modes.قِس تباين كل زوج غيّرته، في الوضعين.

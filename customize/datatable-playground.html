DataTable playground

Turn every DataTable feature on or off from the panel and watch the table change. The code below it lists only what differs from the defaults, ready to copy. Everything runs in your browser on sample data; the server-side mode uses a small fake API.

index.html

The script is assets/js/baset-datatable.js and the styles are section 21 of baset-ui.css. In server-side mode the demo hooks (fetch, add / edit / delete) run against fake in-page data; replace them with your API as shown in the Complete example. New needs editing on; Edit and Delete actions appear only when editing is on.

Theme

How the tokens are built, and how to change theme colors, scales, radius and spacing with CSS variables.

Baset UI is themed with CSS variables in three layers. Color scales (--bui-violet-100 … --bui-violet-900) feed the theme color tokens (--bui-primary-base, -bg, -bg-subtle, -fg, -border, -contrast), and components only read those. Because the tokens use light-dark(), dark mode needs no second set of values: adding class="bui-dark" to <html> flips them all.

Theme colors

Six theme colors, each with the same six tokens. Every chip shows the light value on the left and the dark value on the right.

baset-ui.css · primary
:root {
  --bui-primary-base: var(--bui-violet-500);
  --bui-primary-bg: var(--bui-primary-base);
  --bui-primary-bg-subtle: light-dark(var(--bui-violet-100), var(--bui-violet-900));
  --bui-primary-fg: light-dark(var(--bui-violet-600), var(--bui-violet-400));
  --bui-primary-border: light-dark(var(--bui-violet-300), var(--bui-violet-600));
  --bui-primary-contrast: #fff;
}

Change a theme color

Override tokens on :root, after baset-ui.css. Derived tokens (-bg, and the short --bui-primary, --bui-primary-soft, --bui-primary-text aliases) follow automatically.

1. Point to another color scale

theme.css
:root {
  --bui-primary-base: var(--bui-green-500);
  --bui-primary-bg-subtle: light-dark(var(--bui-green-100), var(--bui-green-900));
  --bui-primary-fg: light-dark(var(--bui-green-600), var(--bui-green-400));
  --bui-primary-border: light-dark(var(--bui-green-300), var(--bui-green-600));
}

2. Use your own brand color: set the base, and derive the others with color-mix().

theme.css
:root {
  --bui-primary-base: #0d9488;
  --bui-primary-bg-subtle: light-dark(
    color-mix(in srgb, var(--bui-primary-base) 12%, #fff),
    color-mix(in srgb, var(--bui-primary-base) 28%, #14152a));
  --bui-primary-fg: light-dark(
    color-mix(in srgb, var(--bui-primary-base) 78%, #000),
    color-mix(in srgb, var(--bui-primary-base) 62%, #fff));
  --bui-primary-border: light-dark(
    color-mix(in srgb, var(--bui-primary-base) 45%, #fff),
    color-mix(in srgb, var(--bui-primary-base) 70%, #000));
}

3. Scope a color to one section. Custom properties are resolved where they are declared, so when you change a color on an element instead of :root, re-declare the derived tokens too.

theme.css
/* Re-declare the derived tokens when you change a color on an element (not :root) */
.brand-section {
  --bui-primary-base: #e11d48;
  --bui-primary-bg: var(--bui-primary-base);
  --bui-primary: var(--bui-primary-base);
}

theme.css
:root {
  --bui-radius-3: .75rem;   /* rounder buttons and inputs */
  --bui-radius-5: 1.25rem;  /* rounder cards */
  --bui-spacer: 1.125rem;   /* more breathing room */
  --bui-font-size: .9375rem;
}

Dark mode

Dark mode is the class bui-dark on <html> (or <body>); it sets color-scheme: dark. Use light-dark(lightValue, darkValue) for your own colors. It is supported by current Chrome, Edge, Firefox and Safari (2024 and later).

dark mode
<!-- on <html> or any wrapper -->
<html class="bui-dark">

/* in your own CSS: pick the value per mode */
.my-banner {
  background: light-dark(#fff7ed, #3a2a1a);
}

QUICK START

Up and running in seconds

Download the package, then include the stylesheet and script in your page.

01 — 03
index.html
<link rel="stylesheet" href="assets/css/baset-ui.css">
<script src="assets/js/baset-ui.js"></script>
starter.html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>My project</title>
  <link rel="stylesheet" href="assets/css/baset-ui.css">
</head>
<body>
  <button type="button" class="bui-btn bui-btn-primary">Hello Baset UI</button>
  <script src="assets/js/baset-ui.js"></script>
</body>
</html>
Dark mode
<html class="bui-dark">

FlexboxFlexbox

Flex utilities set the flex properties of a container (direction, wrap, justification, alignment). They work on any element with bui-d-flex, and on bui-row, which is already a flex container.

تضبط أدوات flex خصائص flex لحاوية (الاتجاه والالتفاف والتوزيع والمحاذاة). وتعمل على أي عنصر عليه bui-d-flex، وعلى bui-row الذي هو حاوية flex أصلًا.

Files you needالملفات التي تحتاجها

Load both stylesheets: assets/css/baset-ui.css (the tokens; the layout uses its --bui-space-* values) and assets/css/baset-ui-layout.css. The layout file has no JavaScript, no colors, no reset and no !important.

حمّل ملفَّي الأنماط: assets/css/baset-ui.css (الـ tokens؛ فالتخطيط يستخدم قيم --bui-space-*) وassets/css/baset-ui-layout.css. ملف التخطيط بلا جافاسكربت ولا ألوان ولا reset ولا !important.

Direction and RTLالاتجاه وRTL

bui-flex-row already follows the page direction: items start at the inline-start side, so in RTL the first item is on the right. Switch the direction in the top bar and watch the stage. Use row-reverse only when you really want the opposite order, not to make RTL work.

bui-flex-row يتبع اتجاه الصفحة أصلًا: تبدأ العناصر من جهة البداية، فيكون العنصر الأول على اليمين في RTL. بدّل الاتجاه من الشريط العلوي وراقب المنصة. استخدم row-reverse فقط عندما تريد حقًّا الترتيب المعاكس، لا لتشغيل RTL.

Flex wrapالالتفاف

Classالصنف CSSCSS
bui-flex-wrapflex-wrap: wrap
bui-flex-nowrapflex-wrap: nowrap
bui-flex-wrap-reverseflex-wrap: wrap-reverse

A bui-row is already wrap. A plain bui-d-flex container is nowrap by default and can overflow: add bui-flex-wrap for toolbars and tag lists.

الـ bui-row هو wrap أصلًا. أما حاوية bui-d-flex العادية فهي nowrap افتراضيًّا وقد تفيض: أضف bui-flex-wrap لأشرطة الأدوات وقوائم الوسوم.

Responsive flex utilitiesأدوات flex المتجاوبة

Every class above has breakpoint variants: bui-flex-{breakpoint}-column, bui-justify-content-md-between, bui-align-items-lg-center. The example stacks on small screens and becomes a row from md:

لكل صنف أعلاه متغيرات لنقاط التوقف: bui-flex-{نقطة التوقف}-column وbui-justify-content-md-between وbui-align-items-lg-center. يتكدس المثال على الشاشات الصغيرة ويصبح صفًّا من md:

<div class="bui-d-flex bui-flex-column bui-flex-md-row bui-justify-content-md-between">
  <div>Logo</div>
  <div>Menu</div>
  <div>Actions</div>
</div>

Choose a width: the preview is a separate frame, so the breakpoints react to its width, not to your window. The preview wraps this markup in a bui-container.

اختر عرضًا: المعاينة إطار منفصل، فتستجيب نقاط التوقف لعرضه وليس لعرض نافذتك. تغلّف المعاينة هذا الكود بـ bui-container.

Displayالعرض

Display utilities set the CSS display value of an element, with a variant for every breakpoint. Together with bui-d-none they are also how you show or hide content responsively.

تضبط أدوات العرض قيمة display في CSS لعنصر ما، مع متغير لكل نقطة توقف. وهي مع bui-d-none الطريقة التي تُظهر بها المحتوى وتُخفيه بشكل متجاوب.

Files you needالملفات التي تحتاجها

Load both stylesheets: assets/css/baset-ui.css (the tokens; the layout uses its --bui-space-* values) and assets/css/baset-ui-layout.css. The layout file has no JavaScript, no colors, no reset and no !important.

حمّل ملفَّي الأنماط: assets/css/baset-ui.css (الـ tokens؛ فالتخطيط يستخدم قيم --bui-space-*) وassets/css/baset-ui-layout.css. ملف التخطيط بلا جافاسكربت ولا ألوان ولا reset ولا !important.

Visibility utilitiesأدوات الإظهار والإخفاء

bui-d-none is the visibility utility: it is the same as the native hidden attribute (the element is removed from the layout, from the accessibility tree and from keyboard focus). Other ways of hiding differ:

bui-d-none هي أداة الإخفاء: وهي مثل السمة الأصلية hidden (يُزال العنصر من التخطيط ومن شجرة إمكانية الوصول ومن تركيز لوحة المفاتيح). وهناك طرق أخرى للإخفاء تختلف:

Only bui-d-none exists. For the other techniques write your own CSS. A visually-hidden class would be a useful future addition, but it was not part of this work.

الموجود هو bui-d-none فقط. وللأساليب الأخرى اكتب CSS الخاص بك. صنف الإخفاء البصري إضافة مفيدة مستقبلًا لكنه لم يكن ضمن هذا العمل.

Hidden on small screens means missing thereالمخفي على الشاشات الصغيرة مفقود هناك

Hide only what is truly redundant, and make sure users of the hidden size have an equivalent way to reach the content. Do not hide focusable content with anything other than bui-d-none.

أخفِ ما هو مكرر فعلًا فقط، وتأكد أن مستخدمي الحجم المخفي لديهم طريقة مكافئة للوصول إلى المحتوى. ولا تُخفِ محتوى قابلًا للتركيز بغير bui-d-none.

Responsive displayعرض متجاوب

Mobile first: start with the small-screen state, then change it at a breakpoint.

بأسلوب mobile-first: ابدأ بحالة الشاشة الصغيرة ثم غيّرها عند نقطة توقف.

Choose a width: the preview is a separate frame, so the breakpoints react to its width, not to your window. The preview wraps this markup in a bui-container.

اختر عرضًا: المعاينة إطار منفصل، فتستجيب نقاط التوقف لعرضه وليس لعرض نافذتك. تغلّف المعاينة هذا الكود بـ bui-container.

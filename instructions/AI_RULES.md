# قواعد الذكاء الاصطناعي (إلزامية)

أي أداة AI تعمل على المشروع تلتزم بما يلي دون استثناء.

1. اقرأ [README.md](README.md) أولاً.
2. اقرأ الملفات المتعلقة بالمهمة قبل البدء (الجدول في README).
3. لا تنفذ أي تغيير خارج نطاق المهمة. إذا رأيت تحسيناً مفيداً خارج النطاق فاذكره في التقرير ولا تنفذه.
4. لا تضف Dependencies (npm أو CDN أو خطوط أو أيقونات خارجية) دون موافقة صريحة.
5. لا تنشئ ملفات أو مجلدات عشوائية. كل ملف جديد يجب أن يكون له مكان محدد في [ARCHITECTURE.md](ARCHITECTURE.md).
6. التزم بـ [NAMING_CONVENTIONS.md](NAMING_CONVENTIONS.md).
7. التزم بـ Namespace `BUI` فقط. ممنوع `BasetUI`.
8. **ممنوع Emojis نهائياً** في الكود والتوثيق والأمثلة والتقارير داخل المستودع.
9. استخدم أيقونات المكتبة فقط ([ICONS_SYSTEM.md](ICONS_SYSTEM.md)). إن لم تكن الأيقونة موجودة، اطلب إضافتها بدل استخدام بديل خارجي.
10. لا تكسر التوافق مع المكونات الأخرى. راجع الاستخدامات قبل تعديل أي Token أو Class مشترك.
11. حدّث Documentation عند تطوير أي Component ([COMPONENT_DOCUMENTATION.md](COMPONENT_DOCUMENTATION.md)).
12. حدّث [COMPONENTS_REGISTRY.md](COMPONENTS_REGISTRY.md) بعد كل مهمة.
13. شغّل الاختبارات المطلوبة ([TESTING.md](TESTING.md)) قبل اعتبار المهمة مكتملة.
14. لا تدّعِ أن ميزة تعمل قبل تنفيذها واختبارها فعلياً. اذكر بوضوح ما اختُبر وما لم يُختبر.

15. **التسليم:** بعد كل مهمة: Preview داخل Claude + ملف ZIP كامل للمشروع ([TASK_WORKFLOW.md](TASK_WORKFLOW.md)، قسم التسليم). لا تسلّم مهمة بدونهما.
16. **المصدر الأساسي هو المستودع على GitHub** وليس نسخة المحادثة. لا تدّعِ أنك نشرت أو رفعت شيئاً إلى GitHub أو فعّلت Pages.

## قواعد إضافية
- **اللغة:** الوثائق الداخلية بالعربية. الكود والتعليقات التقنية بالإنجليزية.
- **لا محتوى وهمي:** لا أمثلة أو صفحات أو بيانات "تجريبية" لملء الفراغ.
- **الشفافية:** عند الغموض في المتطلبات، اتخذ أبسط قرار متسق مع التعليمات ووثّقه، أو اسأل إن كان القرار مؤثراً معمارياً.
- **المسارات:** نسبية دائماً.
- **لا تعدّل `instructions/` ضمنياً:** أي تغيير في القواعد يُذكر صراحة في التقرير النهائي.
- **القرارات المستقبلية:** ما وُسم "مستقبلي" لا يُنفَّذ ولا يُوصَف كأنه موجود.

# Baset UI

A lightweight, responsive, Bootstrap-inspired UI starter library built with vanilla HTML, CSS, and JavaScript.

## Preview
Open `index.html` in a modern browser.

## Quick start
Include the CSS and optional JavaScript in your HTML:

```html
<link rel="stylesheet" href="assets/css/baset-ui.css">
<script src="assets/js/baset-ui.js"></script>
```

## Included in this starter
- Responsive documentation/demo page with sidebar and navigation
- Buttons and size variants
- Text inputs, select, checkbox
- Stat cards
- Success, info, and warning alerts with dismiss interaction
- Status badges
- Dark mode toggle
- Small copy-code interaction
- CSS variables and responsive breakpoints

## Naming convention
All library classes use the `bui-` prefix to reduce clashes with your own styles.

## Important
This is a first starter release. It is not a complete Bootstrap replacement yet. Components shown in the documentation are a foundation to expand in later versions.

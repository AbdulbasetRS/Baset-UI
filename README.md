# Baset-UI

مكتبة واجهات (CSS + JavaScript) تعمل مباشرة في المتصفح بدون Build Tools، مع موقع Documentation.

**الحالة: مرحلة التأسيس (`0.0.0-foundation`).** لا توجد مكونات أو JavaScript API أو Themes أو نظام ترجمة منفذة بعد. الموجود: الهيكل المعماري، مجلد التعليمات، وواجهة التوثيق الأساسية (Navbar, Sidebar, Footer).

## الروابط
- المستودع (المصدر الأساسي): https://github.com/AbdulbasetRS/Baset-UI
- موقع التوثيق (GitHub Pages): https://abdulbasetrs.github.io/Baset-UI/

## التشغيل محلياً
افتح `index.html` مباشرة، أو استخدم أي خادم ساكن، مثلاً `python3 -m http.server` ثم افتح `http://localhost:8000`.

## النشر
GitHub Pages من فرع `main` والمجلد الجذر.

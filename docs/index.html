Baset UI documentationتوثيق Baset UI

Baset UI is a framework-agnostic UI library built with standard HTML, CSS and vanilla JavaScript. This site documents what exists today and says plainly what does not exist yet.

Baset UI مكتبة واجهات مستقلة عن أي إطار عمل، مبنية بـ HTML وCSS وJavaScript خالصة. يوثّق هذا الموقع ما هو موجود اليوم، ويذكر بوضوح ما لم يُنفَّذ بعد.

Early stageمرحلة مبكرة

Baset UI is in its foundation phase. Today the repository provides design tokens (colors, typography, spacing, radius, shadows) with light and dark themes, plus this documentation site. There are no components, no JavaScript, no CDN files and no npm package yet.

Baset UI في مرحلة التأسيس. يوفّر المستودع اليوم Design Tokens (ألوان وخطوط ومسافات وزوايا وظلال) مع ثيمين فاتح وداكن، إضافة إلى موقع التوثيق هذا. لا توجد مكونات ولا جافاسكربت ولا ملفات CDN ولا حزمة npm بعد.

Layoutالتخطيط

A 12-column, mobile-first layout system with seven breakpoints: containers, rows, columns, gutters and utilities, in the optional baset-ui-layout.css.

نظام تخطيط من 12 عمودًا بأسلوب mobile-first وسبع نقاط توقف: حاويات وصفوف وأعمدة ومسافات وأدوات، في الملف الاختياري baset-ui-layout.css.

  • ContainersالحاوياتFixed and fluid containers.الحاويات الثابتة والسائلة.
  • Grid Systemنظام الشبكةContainers, rows, columns, gutters, offsets.الحاويات والصفوف والأعمدة والمسافات والإزاحات.
  • Breakpointsنقاط التوقفSeven mobile-first breakpoints.سبع نقاط توقف بأسلوب mobile-first.
  • DisplayالعرضDisplay and responsive show/hide.العرض والإظهار والإخفاء المتجاوب.
  • FlexboxFlexboxFlex utilities with a live playground.أدوات flex مع ساحة تجربة حية.
  • Spacing Utilitiesأدوات المسافاتGutter classes; margin and padding not implemented.أصناف المسافات؛ والهوامش والحشوة غير منفَّذة.

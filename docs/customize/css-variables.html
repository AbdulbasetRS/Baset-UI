Not variablesليست متغيرات

Breakpoints, a z-index scale, a secondary color, container widths, grid columns and component variables are not defined. They are listed on the Layout pages and on Colors.

element.style.setProperty('--bui-radius-md', '0.75rem');

// Read the value the browser computed

// Remove your override
element.style.removeProperty('--bui-radius-md');

Override colors in both themesعدّل الألوان في الثيمين

Setting a color token with style on <html> also wins over .bui-dark on the same element, so the dark theme would show your light value. For colors, use the two-block pattern in a stylesheet (:root and .bui-dark), or set the value again when the theme changes.

ضبط token لوني بـ style على <html> يتفوق أيضًا على .bui-dark على العنصر نفسه، فيعرض الثيم الداكن قيمتك الفاتحة. للألوان استخدم نمط الكتلتين في ملف أنماط (:root و.bui-dark)، أو اضبط القيمة من جديد عند تغيّر الثيم.

Fallback valuesالقيم الاحتياطية

var() accepts a fallback for when a variable is not defined, which helps if the stylesheet fails to load:

تقبل var() قيمة احتياطية عند عدم تعريف المتغير، وهذا يفيد إن لم يُحمَّل ملف الأنماط:

.card { padding: var(--bui-space-4, 1rem); }

Practical customization examplesأمثلة تخصيص عملية

Brand colorsألوان العلامة

:root     { --bui-color-primary: #7c3aed; --bui-color-primary-hover: #6d28d9; }
.bui-dark { --bui-color-primary: #a78bfa; --bui-color-primary-hover: #c4b5fd; }

Rounder cornersزوايا أكثر استدارة

:root {
  --bui-radius-md: 0.75rem;
  --bui-radius-lg: 1rem;
}

Stronger control bordersحدود عناصر أقوى

:root     { --bui-color-border-strong: #5c6058; }
.bui-dark { --bui-color-border-strong: #8a9a95; }

Disable motion for everyoneإيقاف الحركة للجميع

:root {
  --bui-duration-fast: 0ms;
  --bui-duration-base: 0ms;
}

Reduced motion is already respected: the two duration tokens become 0ms when the reader prefers reduced motion.

تقليل الحركة مُراعى أصلًا: يصبح الـ tokenان للمدة 0ms عندما يفضّل القارئ تقليل الحركة.

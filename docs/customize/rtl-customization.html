RTL Customizationتخصيص RTL

How direction works in Baset UI today, the logical CSS properties to use, what to know before direction-aware components exist, and how to customize direction in your own pages.

كيف يعمل الاتجاه في Baset UI اليوم، والخصائص المنطقية التي تستخدمها، وما يجب معرفته قبل وجود مكونات تراعي الاتجاه، وكيف تخصّص الاتجاه في صفحاتك.

Current stateالوضع الحالي

Baset UI has no direction tokens, no direction JavaScript and no components yet. What exists is a rule: use the standard dir attribute and logical CSS properties. RTL and LTR support for future components is a project requirement and is untested because there are no components to test. The layout module is the exception: its columns, offsets and alignment were checked in both directions (computed styles in Chromium).

لا توجد في Baset UI tokens للاتجاه ولا جافاسكربت للاتجاه ولا مكونات بعد. الموجود هو قاعدة: استخدم السمة القياسية dir والخصائص المنطقية في CSS. دعم RTL وLTR للمكونات المستقبلية شرط في المشروع وهو غير مختبر لعدم وجود مكونات لاختبارها. ووحدة التخطيط استثناء: فُحصت أعمدتها وإزاحاتها ومحاذاتها في الاتجاهين (أنماط محسوبة في Chromium).

RTL architectureبنية RTL

  • Direction is set by the HTML dir attribute (ltr, rtl or auto) on <html> or on any element. It is not a theme and not a class.يُضبط الاتجاه بالسمة dir في HTML (‏ltr أو rtl أو auto) على <html> أو أي عنصر. وهو ليس ثيمًا ولا صنفًا.
  • Styles are written with logical properties, so one stylesheet serves both directions. There is no separate RTL stylesheet and no automatic flipping step.تُكتب الأنماط بخصائص منطقية، فيخدم ملف واحد الاتجاهين. لا يوجد ملف RTL منفصل ولا خطوة قلب تلقائية.
  • Language and direction are independent. Arabic is usually RTL, but a page can show English in RTL or Arabic in LTR, as this site lets you try with the language and direction buttons.اللغة والاتجاه مستقلان. العربية عادةً RTL، لكن يمكن للصفحة عرض الإنجليزية بتخطيط RTL أو العربية بتخطيط LTR، كما يتيح هذا الموقع بزرّي اللغة والاتجاه.
  • Tokens are the same in both directions. A token such as --bui-space-4 is a size, not a side.الـ tokens نفسها في الاتجاهين. فالـ token مثل --bui-space-4 مقاس وليس جهة.
<html lang="ar" dir="rtl"> ... </html>

<!-- a region with a different direction -->
<p dir="ltr">Order #4821</p>

Logical CSS propertiesخصائص CSS المنطقية

Replace physical sides with logical ones. They map to left or right depending on dir.

استبدل الجهات الفيزيائية بمنطقية. فهي تتحول إلى يمين أو يسار حسب dir.

Instead ofبدلًا من Useاستخدم
margin-left / margin-rightmargin-inline-start / margin-inline-end
padding-left / padding-rightpadding-inline-start / padding-inline-end
margin: 0 1rem (both sides)margin-inline: 1rem
border-leftborder-inline-start
left / right (positioned)inset-inline-start / inset-inline-end
text-align: lefttext-align: start
border-top-left-radiusborder-start-start-radius
width / height (for flow-relative size)inline-size / block-size

Be careful with theseاحذر من هذه

Do not use flex-direction: row-reverse to fake RTL: it also reverses the keyboard and reading order. Flex and grid already follow dir. Do not force direction: ltr on text. Mirror directional icons (arrows, chevrons) but not logos, numerals, clocks or media controls.

لا تستخدم flex-direction: row-reverse لتقليد RTL: فهو يعكس ترتيب لوحة المفاتيح والقراءة أيضًا. flex وgrid يتبعان dir أصلًا. ولا تفرض direction: ltr على النص. اعكس الأيقونات الاتجاهية (الأسهم) ولا تعكس الشعارات والأرقام والساعات وأزرار الوسائط.

Browser support for logical properties has not been verified for Baset UI. See Browsers & Devices, where the support policy is still a proposal.

لم يُتحقق من دعم المتصفحات للخصائص المنطقية في Baset UI. راجع المتصفحات والأجهزة حيث ما زالت سياسة الدعم مقترحة.

Direction-aware componentsمكونات تراعي الاتجاه

Plannedمخطَّط No component exists yet, so there is nothing direction-aware to document. The project rules every future component must meet:

Plannedمخطَّط لا يوجد أي مكوّن بعد، فلا شيء يراعي الاتجاه لتوثيقه. هذه قواعد المشروع التي سيلتزم بها كل مكوّن قادم:

  • Layout uses logical properties and no hard-coded left or right. The layout module (baset-ui-layout.css) already follows this rule: it has no physical left/right property.يستخدم التخطيط خصائص منطقية دون left أو right ثابتة. ووحدة التخطيط (baset-ui-layout.css) تلتزم بهذه القاعدة أصلًا: لا توجد فيها خاصية left/right فيزيائية.
  • Directional icons mirror in RTL; non-directional ones do not.تنعكس الأيقونات الاتجاهية في RTL ولا تنعكس غير الاتجاهية.
  • Keyboard behavior is direction-aware where it matters (for example, which arrow key moves to the next item in a horizontal list).يراعي سلوك لوحة المفاتيح الاتجاه حيث يلزم (مثل أي سهم ينقل إلى العنصر التالي في قائمة أفقية).
  • Each component is reviewed with Arabic and English labels in both directions before it is called complete.يُراجع كل مكوّن بتسميات عربية وإنجليزية في الاتجاهين قبل اعتباره مكتملًا.

Mixed contentمحتوى مختلط

Wrap embedded text of the other direction in an element with its own dir (or dir="auto" for user-generated text), instead of reordering characters yourself.

غلّف النص المضمَّن ذا الاتجاه الآخر بعنصر له dir خاص (أو dir="auto" للنص الذي يكتبه المستخدمون)، بدل إعادة ترتيب الحروف بنفسك.

<p dir="rtl">رقم الطلب: <bdi dir="ltr">AB-4821</bdi></p>
<p><bdi dir="auto">user input</bdi></p>

Switching directionتبديل الاتجاه

function setDirection(dir) { // 'ltr' | 'rtl'
  document.documentElement.setAttribute('dir', dir);
}

Switching direction is a one-attribute change; nothing needs to be re-rendered. This site stores the choice in localStorage (bui-docs-dir), which is a docs-site feature only.

تبديل الاتجاه تغيير سمة واحدة؛ ولا حاجة لإعادة رسم أي شيء. يحفظ هذا الموقع الاختيار في localStorage (‏bui-docs-dir) وهي ميزة في موقع التوثيق فقط.

Fonts and line height for Arabicالخطوط وارتفاع السطر للعربية

:root:lang(ar) {
  --bui-line-height-base: 1.85;
}

The base font stack already lists Arabic-capable fonts. See Typography for changing it.

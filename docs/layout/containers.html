Containersالحاويات

A container limits the width of page content and keeps it centered with side padding. Baset UI has no container class yet; this page shows how to build the three common kinds with the tokens.

الحاوية تحدّ عرض محتوى الصفحة وتبقيه في الوسط مع حشوة جانبية. لا يوجد صنف حاوية في Baset UI بعد؛ وتعرض هذه الصفحة كيف تبني الأنواع الثلاثة الشائعة بالـ tokens.

No layout system exists yetلا يوجد نظام تخطيط بعد

Baset UI currently ships design tokens only (assets/css/baset-ui.css). There are no bui- layout classes, no breakpoints and no JavaScript. This page documents what is true today. Examples that use display, flex or grid are plain CSS that you write yourself with the tokens; the class names in them belong to your code, not to Baset UI.

تشحن Baset UI اليوم Design Tokens فقط (assets/css/baset-ui.css). لا توجد أصناف تخطيط بالبادئة bui- ولا نقاط توقف ولا جافاسكربت. توثّق هذه الصفحة ما هو صحيح اليوم. الأمثلة التي تستخدم display أو flex أو grid هي CSS عادي تكتبه أنت بالـ tokens؛ وأسماء الأصناف فيها تخص شيفرتك وليست من Baset UI.

Fixed containersالحاويات الثابتة

A fixed container has a maximum width and is centered. It never gets wider than the maximum, and it shrinks on small screens because max-inline-size is a limit, not a width.

للحاوية الثابتة أقصى عرض وتتوسط الصفحة. لا تتجاوز العرض الأقصى وتنكمش على الشاشات الصغيرة لأن max-inline-size حدّ وليس عرضًا.

.my-container {
  inline-size: 100%;
  max-inline-size: 72rem;
  margin-inline: auto;
  padding-inline: var(--bui-space-4);
}
Live: a container with max-inline-size: 24remعرض حي: حاوية بـ max-inline-size: 24rem
Content stays inside the limit and is centered.يبقى المحتوى داخل الحدّ ويتوسط.

Fluid containersالحاويات السائلة

A fluid container fills the available width and only keeps side padding.

تملأ الحاوية السائلة العرض المتاح وتحتفظ بالحشوة الجانبية فقط.

.my-container-fluid {
  inline-size: 100%;
  padding-inline: var(--bui-space-4);
}
Live: full widthعرض حي: العرض الكامل
Fills the whole width.يملأ العرض بالكامل.

Responsive containersالحاويات المتجاوبة

A responsive container changes its maximum width at your breakpoints. Write it mobile-first with min-width queries. The breakpoint values below are examples; see Breakpoints.

تغيّر الحاوية المتجاوبة أقصى عرض لها عند نقاط التوقف لديك. اكتبها بأسلوب mobile-first باستعلامات min-width. قيم نقاط التوقف أدناه أمثلة؛ راجع نقاط التوقف.

.my-container {
  inline-size: 100%;
  margin-inline: auto;
  padding-inline: var(--bui-space-4);
}
@media (min-width: 40rem) { .my-container { max-inline-size: 38rem; } }
@media (min-width: 64rem) { .my-container { max-inline-size: 60rem; } }
  • Use margin-inline: auto and padding-inline so the container behaves the same in RTL and LTR.استخدم margin-inline: auto وpadding-inline ليتصرف الحاوي بالطريقة نفسها في RTL وLTR.
  • Do not set a fixed width in pixels; it causes horizontal scrolling on small screens.لا تضبط width ثابتًا بالبكسل؛ فهو يسبب تمريرًا أفقيًّا على الشاشات الصغيرة.

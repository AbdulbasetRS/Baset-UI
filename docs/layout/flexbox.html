FlexboxFlexbox

Baset UI has no flex utility classes. Flexbox is a native CSS feature, so everything here works today in your own CSS; use gap with the spacing tokens, and it follows the page direction automatically.

لا توجد في Baset UI أصناف مساعدة لـ flex. وFlexbox ميزة CSS أصلية، فكل ما هنا يعمل اليوم في CSS الخاص بك؛ استخدم gap مع tokens المسافات، فيتبع اتجاه الصفحة تلقائيًّا.

No layout system exists yetلا يوجد نظام تخطيط بعد

Baset UI currently ships design tokens only (assets/css/baset-ui.css). There are no bui- layout classes, no breakpoints and no JavaScript. This page documents what is true today. Examples that use display, flex or grid are plain CSS that you write yourself with the tokens; the class names in them belong to your code, not to Baset UI.

تشحن Baset UI اليوم Design Tokens فقط (assets/css/baset-ui.css). لا توجد أصناف تخطيط بالبادئة bui- ولا نقاط توقف ولا جافاسكربت. توثّق هذه الصفحة ما هو صحيح اليوم. الأمثلة التي تستخدم display أو flex أو grid هي CSS عادي تكتبه أنت بالـ tokens؛ وأسماء الأصناف فيها تخص شيفرتك وليست من Baset UI.

Direction and row-reverseالاتجاه وrow-reverse

row already follows the page direction: items start at the inline-start side, so in RTL the first item is on the right. Switch the direction in the top bar and watch the stage. Use row-reverse only when you really want the opposite order, not to make RTL work.

row يتبع اتجاه الصفحة أصلًا: تبدأ العناصر من جهة البداية، فيكون العنصر الأول على اليمين في RTL. بدّل الاتجاه من الشريط العلوي وراقب المنصة. استخدم row-reverse فقط عندما تريد حقًّا الترتيب المعاكس، لا لتشغيل RTL.

Justify contentمحاذاة المحتوى (justify-content)

Distributes items along the main axis: flex-start, center, flex-end, space-between, space-around, space-evenly. flex-start and flex-end follow the direction, so they are start and end, not left and right.

يوزّع العناصر على المحور الرئيسي: flex-start وcenter وflex-end وspace-between وspace-around وspace-evenly. وتتبع flex-start وflex-end الاتجاه، فهما البداية والنهاية وليستا يسارًا ويمينًا.

Align itemsمحاذاة العناصر (align-items)

Aligns items on the cross axis: stretch (default), flex-start, center, flex-end, baseline. Use align-self on one item to override.

يحاذي العناصر على المحور العرضي: stretch (الافتراضي) وflex-start وcenter وflex-end وbaseline. استخدم align-self على عنصر واحد لتجاوزها.

Flex wrapالالتفاف (flex-wrap)

By default items stay on one line (nowrap) and can overflow. Use wrap for toolbars, tag lists and anything that must fit narrow screens.

افتراضيًّا تبقى العناصر في سطر واحد (nowrap) وقد تفيض. استخدم wrap لأشرطة الأدوات وقوائم الوسوم وكل ما يجب أن يتسع للشاشات الضيقة.

Flex utilitiesأدوات flex المساعدة

.row   { display: flex; flex-wrap: wrap; gap: var(--bui-space-4); align-items: center; }
.row > .grow   { flex: 1 1 0; min-inline-size: 0; }  /* take the remaining space */
.row > .push   { margin-inline-start: auto; }         /* push to the far end */
  • min-inline-size: 0 lets a flex child shrink below its content so long text does not overflow.min-inline-size: 0 يسمح للابن بالانكماش دون محتواه فلا يفيض النص الطويل.
  • margin-inline-start: auto pushes an item to the end in both directions.margin-inline-start: auto يدفع العنصر إلى النهاية في الاتجاهين.

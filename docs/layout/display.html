Displayالعرض

Baset UI has no display or visibility utility classes. This page shows the native CSS and HTML features that cover the same needs, and the accessibility effect of each way of hiding content.

لا توجد في Baset UI أصناف مساعدة للعرض أو الإظهار. تعرض هذه الصفحة ميزات CSS وHTML الأصلية التي تغطي الحاجات نفسها، وأثر كل طريقة إخفاء على إمكانية الوصول.

No layout system exists yetلا يوجد نظام تخطيط بعد

Baset UI currently ships design tokens only (assets/css/baset-ui.css). There are no bui- layout classes, no breakpoints and no JavaScript. This page documents what is true today. Examples that use display, flex or grid are plain CSS that you write yourself with the tokens; the class names in them belong to your code, not to Baset UI.

تشحن Baset UI اليوم Design Tokens فقط (assets/css/baset-ui.css). لا توجد أصناف تخطيط بالبادئة bui- ولا نقاط توقف ولا جافاسكربت. توثّق هذه الصفحة ما هو صحيح اليوم. الأمثلة التي تستخدم display أو flex أو grid هي CSS عادي تكتبه أنت بالـ tokens؛ وأسماء الأصناف فيها تخص شيفرتك وليست من Baset UI.

Display utilitiesأدوات العرض

Use the CSS display property in your own class. Try the values on the box below:

استخدم خاصية CSS display في صنفك الخاص. جرّب القيم على الصندوق أدناه:

ABC
.stage {
  display: block;
}

With none the box disappears and takes no space, which is what the demo shows (the dashed frame stays so you can see where it was).

مع none يختفي الصندوق ولا يحجز مساحة، وهذا ما يعرضه المثال (يبقى الإطار المتقطع لترى مكانه).

Use hidden for content that should be absent for everyone. For text that only assistive technology should read, use the visually-hidden pattern; this site has its own class for it, and Baset UI has none yet:

استخدم hidden للمحتوى الذي يجب أن يغيب عن الجميع. وللنص الذي تقرؤه تقنيات المساعدة فقط استخدم نمط الإخفاء البصري؛ ولدى هذا الموقع صنف خاص به ولا يوجد في Baset UI صنف بعد:

.my-visually-hidden {
  position: absolute;
  inline-size: 1px;
  block-size: 1px;
  margin: -1px;
  padding: 0;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
  border: 0;
}

Do not hide focusable content only visuallyلا تُخفِ المحتوى القابل للتركيز بصريًّا فقط

An element that is invisible but still focusable (for example opacity: 0 on a link) traps keyboard users on something they cannot see. Hide it with hidden or display: none instead.

العنصر غير المرئي لكنه قابل للتركيز (مثل opacity: 0 على رابط) يوقع مستخدم لوحة المفاتيح على شيء لا يراه. أخفِه بـ hidden أو display: none بدلًا من ذلك.

Responsive displayعرض متجاوب

Show or hide at a breakpoint with a media query in your own CSS. Start from the small-screen state:

أظهر أو أخفِ عند نقطة توقف باستعلام وسائط في CSS الخاص بك. ابدأ من حالة الشاشة الصغيرة:

.desktop-only { display: none; }

@media (min-width: 48rem) {
  .desktop-only { display: block; }
  .mobile-only { display: none; }
}

Hide only what is truly redundant: content hidden on small screens is missing for those users, so make sure there is an equivalent way to reach it.

أخفِ المكرر فعلًا فقط: المحتوى المخفي على الشاشات الصغيرة ينقص أصحابها، فتأكد من وجود طريقة مكافئة للوصول إليه.

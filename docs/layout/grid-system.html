Grid Systemنظام الشبكة

A mobile-first, 12-column layout system made of containers, rows and columns, with responsive classes for seven breakpoints, gutters tied to the spacing tokens, and the utilities that complete it. It is plain CSS: no JavaScript and no build step.

نظام تخطيط mobile-first من 12 عمودًا يتكوّن من حاويات وصفوف وأعمدة، بأصناف متجاوبة لسبع نقاط توقف، ومسافات مرتبطة بـ tokens المسافات، والأدوات التي تُكمله. هو CSS خالص: بلا جافاسكربت ولا خطوة بناء.

Introductionمقدمة

Files you needالملفات التي تحتاجها

Load both stylesheets: assets/css/baset-ui.css (the tokens; the layout uses its --bui-space-* values) and assets/css/baset-ui-layout.css. The layout file has no JavaScript, no colors, no reset and no !important.

حمّل ملفَّي الأنماط: assets/css/baset-ui.css (الـ tokens؛ فالتخطيط يستخدم قيم --bui-space-*) وassets/css/baset-ui-layout.css. ملف التخطيط بلا جافاسكربت ولا ألوان ولا reset ولا !important.

The system has three layers that you nest: a container centers the content and limits its width, a row holds the columns and creates the gutters, and columns take a share of the 12 available columns.

يتكوّن النظام من ثلاث طبقات تضعها داخل بعضها: الحاوية تُوسِّط المحتوى وتحدّ عرضه، والصف يحمل الأعمدة وينشئ المسافات بينها، والأعمدة تأخذ حصة من الأعمدة الاثني عشر.

<link rel="stylesheet" href="assets/css/baset-ui.css">
<link rel="stylesheet" href="assets/css/baset-ui-layout.css">

  <div class="bui-row">
    <div class="bui-col-12 bui-col-md-6">Half width from 768px</div>
    <div class="bui-col-12 bui-col-md-6">Half width from 768px</div>
  </div>

How it worksكيف يعمل

  • The row is a flex container that wraps. Its direct children are the columns: each gets side padding equal to half the gutter, and the row pulls itself out by the same amount with a negative inline margin so the content lines up with the container.الصف حاوية flex تلتف عناصرها. وأبناؤه المباشرون هم الأعمدة: يأخذ كل منهم حشوة جانبية بنصف المسافة، ويسحب الصف نفسه بالمقدار ذاته بهامش سالب فيتحاذى المحتوى مع الحاوية.
  • Column width is a percentage of the row: bui-col-6 is 50%, bui-col-4 is 33.333333%. If a row holds more than 12 columns, the extra ones wrap to a new line.عرض العمود نسبة من الصف: bui-col-6 يساوي 50% وbui-col-4 يساوي 33.333333%. وإن زادت أعمدة الصف عن 12 التفّت الزائدة إلى سطر جديد.
  • Any element works as a column because the gutter rule targets .bui-row > *. An element without a bui-col* class simply takes the full width.يصلح أي عنصر عمودًا لأن قاعدة المسافات تستهدف .bui-row > *. والعنصر بلا صنف bui-col* يأخذ العرض كاملًا.
  • All spacing is logical (margin-inline, padding-inline), so the same CSS works in LTR and RTL. The first column starts at the inline-start side.كل المسافات منطقية (margin-inline وpadding-inline)، فيعمل CSS نفسه في LTR وRTL. ويبدأ العمود الأول من جهة البداية.
  • The layout file contains no colors. In the examples on this page the columns are tinted only so you can see them; that tint comes from the documentation site, not from Baset UI.لا يحتوي ملف التخطيط أي ألوان. وتلوين الأعمدة في أمثلة هذه الصفحة لتراها فقط؛ وهو من موقع التوثيق وليس من Baset UI.

سبع نقاط توقف كلها min-width بأسلوب mobile-first. وتحت 480px لا يوجد استعلام: تلك هي الأنماط الأساسية ونقطة بداية كل تخطيط.

Responsive columnsأعمدة متجاوبة

Guttersالمسافات بين الأعمدة

Put a gutter class on the row. bui-g-* sets both directions, bui-gx-* only the horizontal gutter, bui-gy-* only the vertical one. The steps are tied to the existing spacing tokens:

ضع صنف المسافات على الصف. يضبط bui-g-* الاتجاهين، وbui-gx-* المسافة الأفقية فقط، وbui-gy-* الرأسية فقط. والدرجات مرتبطة بـ tokens المسافات الموجودة:

Stepالدرجة Tokenالـ token Sizeالمقدار
0noneلا شيء0
1--bui-space-10.25rem (4px)
2--bui-space-20.5rem (8px)
3--bui-space-41rem (16px)
4--bui-space-61.5rem (24px)
5--bui-space-123rem (48px)
default (no class)الافتراضي (بلا صنف)--bui-space-61.5rem horizontal, 0 vertical1.5rem أفقيًا و0 رأسيًا

Under the hood a gutter class only sets two local variables on the row, --bui-gutter-x and --bui-gutter-y. You may set them yourself, in your own class, with any length.

في الداخل يضبط صنف المسافات متغيرين محليين على الصف فقط هما --bui-gutter-x و--bui-gutter-y. ويمكنك ضبطهما بنفسك في صنف خاص بك بأي طول.

Order changes what you see, not the reading orderالترتيب يغيّر ما تراه لا ترتيب القراءة

Keyboard focus and screen readers follow the order in the HTML, not the visual order. Use order only when the two orders do not need to match, and keep the HTML in a meaningful sequence. This behavior has not been tested with assistive technology here.

يتبع تركيز لوحة المفاتيح وقارئات الشاشة ترتيب الـ HTML وليس الترتيب البصري. استخدم order فقط عندما لا يلزم تطابق الترتيبين، وأبقِ الـ HTML في تسلسل مفهوم. ولم يُختبر هذا السلوك هنا مع تقنيات المساعدة.

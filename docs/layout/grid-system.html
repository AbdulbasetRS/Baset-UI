Grid Systemنظام الشبكة

Baset UI has no grid system (no 12-column grid, no row or column classes). Native CSS Grid already solves most layouts; this page shows how to use it with the tokens.

لا يوجد في Baset UI نظام شبكة (لا شبكة 12 عمودًا ولا أصناف صفوف أو أعمدة). وCSS Grid الأصلية تحلّ معظم التخطيطات؛ وتعرض هذه الصفحة كيف تستخدمها مع الـ tokens.

No layout system exists yetلا يوجد نظام تخطيط بعد

Baset UI currently ships design tokens only (assets/css/baset-ui.css). There are no bui- layout classes, no breakpoints and no JavaScript. This page documents what is true today. Examples that use display, flex or grid are plain CSS that you write yourself with the tokens; the class names in them belong to your code, not to Baset UI.

تشحن Baset UI اليوم Design Tokens فقط (assets/css/baset-ui.css). لا توجد أصناف تخطيط بالبادئة bui- ولا نقاط توقف ولا جافاسكربت. توثّق هذه الصفحة ما هو صحيح اليوم. الأمثلة التي تستخدم display أو flex أو grid هي CSS عادي تكتبه أنت بالـ tokens؛ وأسماء الأصناف فيها تخص شيفرتك وليست من Baset UI.

Grid architectureبنية الشبكة

Native grid is built from a container with display: grid and the columns you define; children are placed automatically. It is direction-aware: columns start from the inline-start side, so the same CSS works in RTL.

تتكوّن الشبكة الأصلية من حاوية display: grid والأعمدة التي تعرّفها؛ وتُوضع العناصر الأبناء تلقائيًّا. وهي تراعي الاتجاه: تبدأ الأعمدة من جهة البداية، فيعمل CSS نفسه في RTL.

Columnsالأعمدة

.my-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr)); /* three equal columns */
  gap: var(--bui-space-4);
}

minmax(0, 1fr) lets columns shrink below their content width, which prevents horizontal overflow from long words or code.

minmax(0, 1fr) يسمح للأعمدة بالانكماش دون عرض محتواها، فيمنع الفيضان الأفقي من الكلمات الطويلة أو الشيفرة.

Rowsالصفوف

Rows are created automatically as items wrap. Size them with grid-auto-rows only if you need a fixed height.

تُنشأ الصفوف تلقائيًّا مع التفاف العناصر. اضبط حجمها بـ grid-auto-rows فقط إن احتجت ارتفاعًا ثابتًا.

Guttersالمسافات بين الأعمدة

Use gap (or column-gap / row-gap) with a spacing token. Gutters are not part of the item size, so there is no negative margin trick.

استخدم gap (أو column-gap / row-gap) مع token للمسافة. المسافات ليست جزءًا من حجم العنصر، فلا حاجة لحيلة الهوامش السالبة.

Responsive layoutsتخطيطات متجاوبة

Automatic: no breakpointsتلقائي: بلا نقاط توقف

.my-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 15rem), 1fr));
  gap: var(--bui-space-4);
}

The number of columns adapts to the available width. min(100%, 15rem) keeps a single column from overflowing on very narrow screens.

يتكيّف عدد الأعمدة مع العرض المتاح. وmin(100%, 15rem) يمنع العمود الواحد من الفيضان على الشاشات الضيقة جدًّا.

@media (min-width: 64rem) { .my-grid { grid-template-columns: repeat(4, minmax(0, 1fr)); } }

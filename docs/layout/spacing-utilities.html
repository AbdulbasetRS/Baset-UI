Spacing Utilitiesأدوات المسافات

Spacing utilities would be classes that set margin, padding or gap from the spacing scale. None exist today. The spacing scale itself does exist as tokens; it is documented under Customize.

أدوات المسافات هي أصناف تضبط الهامش أو الحشوة أو الفجوة من سلّم المسافات. لا يوجد أي منها اليوم. أما سلّم المسافات نفسه فموجود كـ tokens وهو موثّق في قسم Customize.

No layout system exists yetلا يوجد نظام تخطيط بعد

Baset UI currently ships design tokens only (assets/css/baset-ui.css). There are no bui- layout classes, no breakpoints and no JavaScript. This page documents what is true today. Examples that use display, flex or grid are plain CSS that you write yourself with the tokens; the class names in them belong to your code, not to Baset UI.

تشحن Baset UI اليوم Design Tokens فقط (assets/css/baset-ui.css). لا توجد أصناف تخطيط بالبادئة bui- ولا نقاط توقف ولا جافاسكربت. توثّق هذه الصفحة ما هو صحيح اليوم. الأمثلة التي تستخدم display أو flex أو grid هي CSS عادي تكتبه أنت بالـ tokens؛ وأسماء الأصناف فيها تخص شيفرتك وليست من Baset UI.

Class names such as bui-m-4, bui-p-2 or bui-gap-3 are not defined. Do not use them.

أسماء أصناف مثل bui-m-4 أو bui-p-2 أو bui-gap-3 غير معرَّفة. لا تستخدمها.

Marginالهامش

Use the tokens with logical properties in your own CSS. See the examples in Spacing.

استخدم الـ tokens مع الخصائص المنطقية في CSS الخاص بك. راجع الأمثلة في المسافات.

.stack > * + * { margin-block-start: var(--bui-space-4); }

Paddingالحشوة

.box { padding: var(--bui-space-4) var(--bui-space-6); }

Gapالفجوة

.cluster { display: flex; flex-wrap: wrap; gap: var(--bui-space-3); }

Responsive spacing utilitiesأدوات مسافات متجاوبة

Not implemented. For responsive spacing use clamp() or a media query in your own CSS, as shown in Spacing, Responsive spacing.

غير منفَّذ. للمسافات المتجاوبة استخدم clamp() أو استعلام وسائط في CSS الخاص بك، كما في المسافات، مسافات متجاوبة.

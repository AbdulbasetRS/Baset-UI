Spacing Utilitiesأدوات المسافات

The only spacing utilities Baset UI has are the gutter classes of the grid. Margin, padding and gap utility classes do not exist. The spacing scale itself is available as tokens.

أدوات المسافات الوحيدة في Baset UI هي أصناف مسافات الشبكة. أما أصناف الهامش والحشوة والفجوة فغير موجودة. وسلّم المسافات نفسه متاح كـ tokens.

Files you needالملفات التي تحتاجها

Load both stylesheets: assets/css/baset-ui.css (the tokens; the layout uses its --bui-space-* values) and assets/css/baset-ui-layout.css. The layout file has no JavaScript, no colors, no reset and no !important.

حمّل ملفَّي الأنماط: assets/css/baset-ui.css (الـ tokens؛ فالتخطيط يستخدم قيم --bui-space-*) وassets/css/baset-ui-layout.css. ملف التخطيط بلا جافاسكربت ولا ألوان ولا reset ولا !important.

أسماء أصناف مثل bui-m-4 أو bui-p-2 أو bui-gap-3 غير معرَّفة. لا تستخدمها.

Marginالهامش

Use the tokens with logical properties in your own CSS. See the examples in Spacing.

استخدم الـ tokens مع الخصائص المنطقية في CSS الخاص بك. راجع الأمثلة في المسافات.

.stack > * + * { margin-block-start: var(--bui-space-4); }

Paddingالحشوة

.box { padding: var(--bui-space-4) var(--bui-space-6); }

Gapالفجوة

.cluster { display: flex; flex-wrap: wrap; gap: var(--bui-space-3); }

For a flex container with gaps you can also use a grid row: bui-row bui-g-3. Responsive spacing is covered in Spacing, Responsive spacing.

ولحاوية flex بفجوات يمكنك استخدام صف الشبكة: bui-row bui-g-3. والمسافات المتجاوبة موضحة في المسافات، مسافات متجاوبة.

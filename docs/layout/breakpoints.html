Breakpointsنقاط التوقف

Baset UI defines no breakpoints today. This page explains why they are not CSS variables, shows the breakpoints this documentation site uses for itself, and gives a mobile-first pattern you can copy.

لا تعرّف Baset UI أي نقاط توقف اليوم. توضح هذه الصفحة لماذا لا تكون متغيرات CSS، وتعرض نقاط التوقف التي يستخدمها موقع التوثيق لنفسه، وتقدّم نمط mobile-first يمكنك نسخه.

Implemented breakpointsنقاط التوقف المنفَّذة

None in the libraryلا شيء في المكتبة

assets/css/baset-ui.css contains no @media width queries and no breakpoint tokens. The only media query in it is prefers-reduced-motion. There is no named scale (such as sm, md, lg).

لا يحتوي assets/css/baset-ui.css على أي استعلام عرض @media ولا tokens لنقاط التوقف. والاستعلام الوحيد فيه هو prefers-reduced-motion. ولا يوجد سلّم مسمّى (مثل sm وmd وlg).

للمرجع، يستخدم موقع التوثيق هذا (وليس المكتبة) هذه الأعراض الثلاثة في docs/assets/css/docs.css:

Responsive behaviorالسلوك المتجاوب

  • Everything in the library is already width-independent: tokens are plain values and carry no layout.كل ما في المكتبة مستقل عن العرض أصلًا: الـ tokens قيم عادية ولا تحمل تخطيطًا.
  • Spacing and type sizes use rem, so they follow the reader's font-size setting.المسافات وأحجام الخطوط بوحدة rem، فتتبع إعداد حجم الخط عند القارئ.
  • Responsive behavior of components will be written in each component's own stylesheet.سيُكتب السلوك المتجاوب للمكونات في ملف الأنماط الخاص بكل مكوّن.

Mobile-first approachأسلوب mobile-first

The project guidance is to design for narrow screens first where appropriate: write the small-screen styles without a query, then add min-width queries that enhance the layout as space allows.

توجيه المشروع هو التصميم للشاشات الضيقة أولًا حيث يناسب: اكتب أنماط الشاشة الصغيرة بلا استعلام، ثم أضف استعلامات min-width تحسّن التخطيط كلما اتسعت المساحة.

.layout { display: grid; gap: var(--bui-space-4); }      /* narrow: one column */

@media (min-width: 48rem) {
  .layout { grid-template-columns: 16rem minmax(0, 1fr); }  /* wider: sidebar + content */
}
  • Use rem (or em) in media queries so breakpoints respect zoom and font-size changes.استخدم rem (أو em) في استعلامات الوسائط لتحترم نقاط التوقف التكبير وتغيير حجم الخط.
  • Prevent horizontal overflow: avoid fixed pixel widths and use min-inline-size: 0 on flex or grid children that hold long content.امنع الفيضان الأفقي: تجنّب العروض الثابتة بالبكسل واستخدم min-inline-size: 0 على أبناء flex أو grid الذين يحملون محتوى طويلًا.
  • Keep touch targets comfortable on small screens.أبقِ مساحات اللمس مريحة على الشاشات الصغيرة.

Breakpoint customizationتخصيص نقاط التوقف

Why not a variable?لماذا ليست متغيرًا؟

CSS custom properties cannot be used inside a media query condition: @media (min-width: var(--bui-bp-md)) does not work. That is why there is no breakpoint token.

لا يمكن استخدام الخصائص المخصصة في شرط استعلام الوسائط: @media (min-width: var(--bui-bp-md)) لا يعمل. ولهذا لا يوجد token لنقاط التوقف.

Choose your own values and use them consistently. One way is to document them in a comment at the top of your stylesheet:

اختر قيمك وطبّقها باتساق. إحدى الطرق توثيقها في تعليق في أعلى ملف أنماطك:

/* My breakpoints (media queries cannot read CSS variables):
   small  40rem
   medium 48rem
   large  64rem */

Another technique avoids breakpoints for many cases: intrinsic layouts such as repeat(auto-fit, minmax(...)) in Grid System.

وتقنية أخرى تتفادى نقاط التوقف في حالات كثيرة: التخطيطات الذاتية مثل repeat(auto-fit, minmax(...)) في نظام الشبكة.

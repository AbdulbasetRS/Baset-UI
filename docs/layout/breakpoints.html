Breakpointsنقاط التوقف

Baset UI has seven official breakpoints. They are mobile first: base styles apply below 480px, and every breakpoint adds styles from its width upward.

لدى Baset UI سبع نقاط توقف رسمية. وهي mobile-first: تُطبَّق الأنماط الأساسية تحت 480px، وتضيف كل نقطة توقف أنماطًا من عرضها فصاعدًا.

Responsive behaviorالسلوك المتجاوب

  • Every responsive class has the same name pattern: bui-{name}-{breakpoint}-{value}, for example bui-col-md-6, bui-offset-lg-2, bui-d-xl-none, bui-flex-sm-column.لكل صنف متجاوب نمط التسمية نفسه: bui-{الاسم}-{نقطة التوقف}-{القيمة}، مثل bui-col-md-6 وbui-offset-lg-2 وbui-d-xl-none وbui-flex-sm-column.
  • Classes combine. When several apply, the one for the largest matching breakpoint wins.تجتمع الأصناف. وعندما ينطبق عدة منها يفوز صنف أكبر نقطة توقف مطابقة.
  • The infix does not mean "only at": bui-d-md-none hides from 768px up. To hide only in a range, combine classes, for example bui-d-md-none bui-d-xl-block.اللاحقة لا تعني "عند فقط": يخفي bui-d-md-none من 768px فصاعدًا. ولإخفاء نطاق محدد اجمع الأصناف، مثل bui-d-md-none bui-d-xl-block.
  • The grid itself does not cause horizontal scrolling (checked from 320px to 2400px). Wide content inside a column, such as a long code line or a table, can still overflow it: make that content scrollable or let it wrap.الشبكة نفسها لا تسبب تمريرًا أفقيًّا (فُحصت من 320px إلى 2400px). لكن المحتوى العريض داخل عمود، كسطر شيفرة طويل أو جدول، قد يفيض منه: اجعله قابلًا للتمرير أو دعه يلتف.

Mobile-first approachأسلوب mobile-first

Write the small-screen layout first, with no breakpoint, then add classes for larger screens. A single column that grows is the usual pattern:

اكتب تخطيط الشاشة الصغيرة أولًا بلا نقطة توقف، ثم أضف أصنافًا للشاشات الأكبر. والنمط المعتاد عمود واحد يتسع:

<div class="bui-col-12 bui-col-md-6 bui-col-xl-4">...</div>
<!-- under 768px: full width, 768px+: half, 1200px+: one third -->

Your layout must work below 480px too: that range has no query and is where every design starts.

يجب أن يعمل تخطيطك تحت 480px أيضًا: هذا النطاق بلا استعلام وهو نقطة بداية كل تصميم.

Where the values liveأين تُخزَّن القيم

CSS custom properties cannot be used in a media query condition, so the breakpoints are not variables. Instead they are defined once, in assets/css/baset-ui-layout.css:

لا يمكن استخدام الخصائص المخصصة داخل شرط استعلام الوسائط، لذا فنقاط التوقف ليست متغيرات. بل هي معرَّفة مرة واحدة في assets/css/baset-ui-layout.css:

  • A table in the header comment lists the seven values.جدول في تعليق رأس الملف يسرد القيم السبع.
  • Section 5 of the file has exactly seven @media (min-width: …) blocks, in ascending order, and every responsive class lives inside one of them. Each value appears once.يضم القسم 5 من الملف سبع كتل @media (min-width: …) بالضبط بترتيب تصاعدي، وكل صنف متجاوب داخل إحداها. وتظهر كل قيمة مرة واحدة.
/* excerpt from baset-ui-layout.css, section 5 */
@media (min-width: 768px) {
  .bui-container { max-inline-size: 720px; }
  /* ...every -md- class... */
  .bui-col-md-6 { flex: 0 0 auto; inline-size: 50%; }
}

Breakpoint customizationتخصيص نقاط التوقف

In your own CSSفي CSS الخاص بك

Use the same values so your components change at the same widths as the grid:

استخدم القيم نفسها لتتغير مكوناتك عند نفس عروض الشبكة:

@media (min-width: 480px)  { /* xs  */ }
@media (min-width: 576px)  { /* sm  */ }
@media (min-width: 768px)  { /* md  */ }
@media (min-width: 992px)  { /* lg  */ }
@media (min-width: 1200px) { /* xl  */ }
@media (min-width: 1600px) { /* xxl */ }
@media (min-width: 1920px) { /* xxxl */ }

Changing an official valueتغيير قيمة رسمية

Edit the value in its @media line and in the header table of baset-ui-layout.css. There is no other copy to keep in sync, but if you also use the value in your own CSS you must update that as well. If you ship a modified copy, tell your team: the documented widths on this site describe the file as delivered.

عدّل القيمة في سطر @media الخاص بها وفي جدول رأس baset-ui-layout.css. لا توجد نسخة أخرى تحتاج مزامنة، لكن إن استخدمت القيمة في CSS الخاص بك فعدّلها هناك أيضًا. وإن شحنت نسخة معدّلة فأخبر فريقك: فالعروض الموثقة في هذا الموقع تصف الملف كما سُلِّم.

This site uses other widths for itselfهذا الموقع يستخدم عروضًا أخرى لنفسه

The documentation site's own navigation changes at 75rem, 60rem and 48rem. Those are the docs site's choices, not Baset UI breakpoints. The grid examples on these pages follow the seven official breakpoints.

تتغير ملاحة موقع التوثيق نفسه عند 75rem و60rem و48rem. هذه اختيارات الموقع وليست نقاط توقف Baset UI. أما أمثلة الشبكة في هذه الصفحات فتتبع نقاط التوقف الرسمية السبع.
